# R-00000285 Codex 드라이버 명령에 gpt-6-sol 모델을 다시 적는다

## Work

W-00000285. 이 저장소 `.stage/settings.json`의 Codex 명령 여섯 개에 `--model gpt-6-sol`을 넣고, 모델 고정 시험의 기대값을 맞췄다.
외부 결과: 드라이버가 홈 설정과 상관없이 같은 Codex 모델로 돈다.
내부 결과: 2026-10-12부터 실패하던 Stage scripts 시험 6개가 다시 통과한다(659개 OK).

## Decision points

- 템플릿 규칙("모든 명령에 모델을 직접 적는다")과 2026-10-12 커밋(고정을 빼고 홈 설정을 따름)이 어긋났다. 사용자가 지금 홈 모델인 `gpt-6-sol`로 다시 고정하기로 정했다.

## Principles applied

SSOT: 드라이버가 쓸 모델은 프로젝트 설정 한곳에 있고, 시험이 그 값을 지킨다.
Honesty: 리뷰어가 글자 단위로 확인하지 못한 "나머지 문장은 그대로"를 Claude가 word diff로 확인했다(`--model gpt-6-sol` 6개만 추가).

## Context that helped

모델 고정 시험이 고정을 뺀 커밋을 바로 잡고 있었다. 다만 3일 동안 아무도 시험 실패를 보지 않았다.
