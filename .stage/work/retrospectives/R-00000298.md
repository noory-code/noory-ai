# R-00000298 실제 codex 플러그인으로 codex 명령 경로 찾기를 확인한다

## Work

W-00000298. 클라우드에서 가짜 companion 으로만 시험한 `stage/scripts/codex_companion.py` 경로를 이
컴퓨터의 실제 Codex 플러그인 1.0.6 으로 끝까지 돌렸다.
외부 결과: W-00000288 의 Codex 실행 한 판과 Codex 닫기 리뷰 한 번이 이 경로로 끝났고, 실행 보고와
판정 파일(`approved: true`)이 남았다.
내부 결과: 경로를 찾는 순서 가운데 "Claude Code 설치 기록" 단계가 실제로 쓰였다.

## Decision points

- 시험용 가짜 작업을 만들지 않고, 실제로 남아 있던 `codex` venue 카드(W-00000288)를 드라이버로 돌려
  확인했다. 같은 실행이 W-00000288 을 끝내고 이 카드의 근거도 된다.

## Principles applied

Fail Fast: 큰 실행 전에 `status --json` 으로 companion 을 찾는지 먼저 확인했다.
Honesty: 증거 파일이 git 밖에 있어 핵심 내용을 카드에 옮겨 적었다.

## Context that helped

- W-00000289 가 경로를 찾는 순서를 문서로 적어 두어, 어느 단계가 쓰였는지 바로 확인할 수 있었다.

## Context that was missing

- 환경 변수(`STAGE_CODEX_COMPANION`)와 캐시 단계는 이번 실행에서 쓰이지 않아 실제로 확인하지 않았다.
