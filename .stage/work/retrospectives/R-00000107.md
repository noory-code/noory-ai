# R-00000107 카드 백 장을 v5 로 옮긴다

## Work

스키마 v5 활성화, 일지 기반 가역 마이그레이션, 이 저장소 기록 110장 전부 이동. 감사가 처음으로
오류 0 · 경고 0. 도중에 들어온 novel-workspace 실전 결함 보고 셋을 기준으로 올려 함께 닫았고,
재현이 회귀 시험이 됐다. 플러그인 0.54.1. 에픽의 마지막 스토리.

## Decision points

- **실전 보고를 회차 사이에 기준으로 흡수했다.** 1회차가 이사를 끝낸 뒤 보고가 도착했고, 커밋으로
  경계를 만든 다음 셋을 기준에 올려 3회차가 닫았다. 밖에서 온 결함 보고가 도는 카드의 기준이
  되기까지 반나절이 안 걸렸다.
- **0.54.0 을 바로 push 하지 않았다.** v5 강제 플러그인이 결함 셋 수정 전에 나가면
  novel-workspace 가 갇힌다. 수정이 실린 0.54.1 까지 묶어서 내보낸다.
- **코덱스 플러그인을 한 회차 껐다.** 2회차에서 설치본(0.53.0, v4 강제)이 v5 가 된 이 저장소의
  쓰기를 전부 막았다. P-00000001 의 선례를 따라 껐고, 회차가 끝나자마자 켰다.
- **리뷰 지적 셋 중 하나만 받았다.** 기준선 서명의 잠복 경계는 관측(O-00000008)으로, 나머지 둘은
  "그 상황이 이 저장소에 오나"로 갈라 안 받았다. git 이 추적하는 트리라는 사실이 한 건의 거절
  근거가 됐다.

## Principles applied

- **Fail Fast — 단, 탈출구와 함께.** 같은 모양의 갇힘을 하루에 세 번 봤다. 기존 빚이
  마이그레이션을 막는데 그 빚은 마이그레이션 없이 못 고침(보고 ①), 실패 표식이 복구 시도까지
  막음(보고 ③), 설치본의 스키마 강제가 앞서간 저장소를 잠금(우리 2회차). 전부 "고치려면 X 가
  필요한데 X 가 그 고침을 요구한다". fail-closed 는 탈출구가 있을 때만 안전이고, 없으면 감금이다.
- **SSOT** — 스캐너가 한 모양만 안다. 옛 모양 분기를 남기지 않으려고 백 장을 옮긴 결정
  (DE-00000035)이 이 카드로 완성됐다.
- **Honesty** — 실행자가 두 번(범위 충돌, 가드 잠금) 우회하지 않고 멈춰 이유를 보고했고, 그
  보고가 매번 정확한 다음 수를 만들었다.
- **MECE** — 이동 규칙이 겹침도 빠짐도 없이 적용됐다. 옛 카드는 독립 스토리로, `parent` 를 가진
  카드는 부모 폴더 밑으로, 열려 있는 에픽의 완료된 자식은 에픽 안으로.

## Context that helped

- **실전 사용자가 하나 있었다.** novel-workspace 가 우리보다 먼저 마이그레이션을 실전에서 밟아
  줬다. 우리 저장소만으로는 KIND001 류의 빚이 없어서 ① 을 영영 못 봤을 것이다. 재현 시나리오를
  갖춘 보고 하나가 회귀 시험 셋이 됐다.
- **우리 저장소 자체가 ② 의 재현 환경이었다.** 7월 v3→v4 일지가 그대로 남아 있어서, 옛 일지
  무시 로직을 실제 낡은 일지로 시험할 수 있었다.

## Context that was missing

- **설치본과 저장소의 스키마 어긋남을 아무도 안 셌다.** DE-00000035 의 적용 자리 표는 코드·설정·
  문서·실패 경로를 셌지만, "이 플러그인을 설치해서 쓰는 다른 프로젝트"와 "이 저장소를 읽는 다른
  설치본"은 축에 없었다. 마이그레이션 카드가 도는 동안 마켓플레이스에는 중간 버전이 계속
  나가고 있었다. 배포가 걸린 변경은 **버전 어긋남의 겪는 쪽**을 적용 자리로 세야 한다.
- **드라이버 시간 제한이 또 짧았다** (1회차, O-00000003 재발). 45분도 이 카드에는 모자랐다.

## Next changes

- novel-workspace 재마이그레이션을 지켜본다. 기준선 오탐(O-00000008)이 나오면 카드로 세운다.
- P-00000003(드라이버 계약)을 열 때 이 카드의 드라이버 관측 둘(시간 제한 재발, 설치본 스키마
  어긋남 잠금)을 입력에 넣는다.
- 에픽이 닫히면 이 스토리는 에픽과 통째로 보관된다 — 이 카드가 만든 규칙의 첫 적용.

## Promotion decision

**official 로 안 올린다.** 계약은 DE-00000035 가 쥔다. 에픽과 함께 보관된다.
