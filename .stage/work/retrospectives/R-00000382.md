# R-00000382 드라이버가 저장소 상태를 볼 때 띄우는 git 프로세스를 줄인다

## Decision points

- **서브세션(session_018VXR6PenXB1UzzSA9HXNWt)이 만들고 메인 세션이 닫았다(DE-00000094).** 서브세션 브랜치는 W-00000381 과
  W-00000384 가 main 에 들어가기 전에 갈라졌지만, squash 할 때 `stage/CHANGELOG.md` 는 union 으로 충돌 없이 합쳐졌다.
- **세 번 부르던 git 을 `ls-files -t` 한 번으로 합쳤다.** git 문서는 `-t` 를 "semi-deprecated" 라고 적는다. 서브세션이 이것을
  사용자 확인 거리로 올렸다. 메인 세션은 받아들이자고 권했다. 지금 git 에서 동작하고, 바뀌면 새 시험이 실패한다.
- **`--git-path index` 를 루트마다 기억해 두지 않았다.** 실행 중에 저장소가 만들어지거나 지워지면 틀린 답을 준다. 대신 첫 명령이
  실패했을 때만 부른다.
