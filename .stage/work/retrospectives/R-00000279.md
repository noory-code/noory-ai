# R-00000279 운영체제별 CI에서 드러난 문제를 고쳤습니다

## Work

W-00000279. 배포 CI가 드러낸 경로 정렬, 테스트 명령, 인코딩, CRLF 보존과 SQLite 연결 정리 문제를 고쳤습니다.
외부 결과: Linux·macOS·Windows에서 PR 검사 30개가 모두 통과했고 수정한 버전을 배포했습니다.
내부 결과: 새 회귀 테스트에서 실패를 재현한 뒤 통과를 확인했습니다. Claude가 세 차례 수정 내용을 검토했습니다.

## Decision points

첫 실패를 고친 뒤 CI를 다시 실행했습니다. 다음 단계에서 드러난 Windows 실패도 원인을 나누어 고쳤습니다.
실패한 테스트를 건너뛰지 않았습니다. 수정한 소스는 기존 작업 폴더와 분리한 배포 브랜치에 보존했습니다.

## Principles applied

Fail Fast: CI 실패가 있는 동안 병합하지 않았습니다.
SSOT: 경로를 표시하는 함수와 테스트용 명령 생성 함수를 각각 한 곳에서 고쳤습니다.
Honesty: 첫 세 CI 실행의 실패 로그와 세 차례의 Claude 리뷰를 보존했습니다.
Completion: 로컬 회귀 테스트와 전체 scripts 테스트 659개를 통과했고 네 번째 CI의 운영체제별 검사도 모두 통과했습니다.

## Context that helped

Windows CI 로그가 공통 원인을 드러냈습니다. PureWindowsPath, ASCII 파이프와 CRLF 입력으로 로컬에서도 네 가지 실패를 재현했습니다.

## Context that was missing

앞선 macOS 검사만으로는 Windows 셸의 명령 분리와 파일 잠금 문제를 찾지 못했습니다. 첫 CI는 hooks에서 멈춰 scripts의 문제를 가렸습니다.

## Next changes

추가 코드 수정은 남지 않았습니다. 부모 작업에서 릴리스와 실제 호스트의 실행 증거를 함께 확인합니다.
