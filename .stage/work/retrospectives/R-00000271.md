# R-00000271 지침 적용과 한국어 품질 분석을 구분한다

## Work

W-00000271. 1차 검증안을 실제 플러그인에 적용하고 한국어 자료를 조사하여 새 응답 45개를 분석했다.
이후 명사 구조를 중심으로 응답 36개를 분석했다. 사용자가 어휘와 문장 길이를 추가로 지적하여 두 수정안으로 응답 40개를 더 비교했다.
사용자가 지침 강화를 승인한 뒤 응답 76개를 더 비교하고 최종 한국어 지침을 본체에 적용했다.

## Decision points

- 사용자가 직접 적용을 승인하여 현재 세션에서 수정했다. 기존 작업은 보존하고 커밋하지 않았다.
- 2차 요청은 연구와 분석이므로, 결과만 보고 한국어 규칙을 더 바꾸지는 않았다.
- 짧아짐, 자연스러움, 의미 보존을 따로 판단했다. 버튼 글자 수 위반을 문법 오류로 세지 않았다.
- 후속 수정안은 긴 문장을 줄였지만 단어 선택과 뜻 보존에 문제가 남았다. 일부 개선만 보고 전체 수정안을 본체에 적용하지 않았다.
- 사용자의 후속 승인 뒤 남은 문제를 보완했다. 마지막 비교에서 재사용·미측정 효과·버튼 길이를 두 번씩 확인하고 적용했다. 주체가 모호한 표현까지 해결됐다고 주장하지 않았다.

## Principles applied

- Honesty: 모델 내부 사고 과정이나 한국어 전체 능력을 관측한 것처럼 주장하지 않았다.
- SSOT: 실제 스타일 파일 하나를 수정하고 상세 판정은 실험 폴더의 ANALYSIS.md에 남겼다.
- MECE: 규칙·예시·검사·설명 문서의 영향을 O-00000048에 열거했다.
- Completion: 사용자에게 보여 줄 적용 결과와 분석은 준비했다. 독립 리뷰와 공식 종료는 별도로 남긴다.

## Context that helped

- 실제 Claude 초기 응답의 모델·스타일·플러그인 경로와 원시 로그.
- 국립국어원 자료의 문맥상 생략, 조사 기능, 어휘 결합, 높임법 설명.
- 사용자가 한국어 특성을 조사한 뒤 응답을 보라고 명시한 방향.

## Context that was missing

- 초기 2차 분석에서 영어 명사구를 한국어 문장으로 다시 구성하는 능력을 충분히 시험하지 않았다. 사용자가 이를 짚은 뒤 연구와 응답 36개를 추가했다.
- 실제로 사용자가 답답하게 느꼈던 Opus 문장의 원문 묶음.
- 여러 한국어 화자가 조건을 모른 채 비교한 평가와 긴 실제 작업 세션.

## Next changes

- 명사에 담긴 행동·상태·조건을 풀어 쓰는 절차는 시험했다. 동사 개수만 늘리거나 익숙한 한자어를 억지로 풀지 않는 원칙은 유지한다.
- 국내 해당 분야에서 쓰는 단어와 문맥에 맞는 결합도 확인한다. 사전의 뜻이 맞는다는 이유만으로 자연스럽다고 판정하지 않는다.
- 문장을 나눈 뒤 반복을 덜어내고, 어휘를 바꾼 뒤 행동과 효과의 방향이 달라졌는지 확인하는 절차를 다듬는다.
- 문장 안에서 누가 수정했고 누가 확인하는지 모호해지는 사례는 남았다. 실제 사용 사례를 다음 분석의 근거로 삼는다.
- 짧은 UI 문구의 길이 조건을 별도로 확인한다.
- 후속 릴리스 요청에 따라 0.7.1을 커밋·푸시했다. 첫 확인은 OAuth 만료로 응답 생성에 실패했다. 사용자 재로그인 뒤 새 세션에서 실제 응답까지 확인했다. 독립 리뷰와 공식 종료는 남아 있다.
