# R-00000278 원격 배포와 실제 호스트 로드를 함께 확인합니다

## Work

W-00000278. 사용자가 요청한 세 플러그인의 푸시·병합·배포를 마쳤습니다. 결과는 integration/release-status.md에 모았습니다.
외부 결과: Stage 0.63.3, Avatar 0.1.2, Distill 1.10.0을 원격 main에 병합하고 릴리스를 게시했습니다. 두 호스트의 새 세션에서 세 버전을 실제로 불러왔습니다.

## Decision points

원본 작업 폴더의 변경을 섞지 않도록 최신 원격 main에서 배포 가지를 만들었습니다. 제품 커밋만 적용했습니다.
CI가 실패했을 때 원인을 고치는 액션 W-00000279를 등록했습니다.
Codex는 임시 이름으로 설치한 플러그인만 시험했습니다. 시험 후 제거했고 기존 설정 파일의 바이트가 같음을 확인했습니다.

## Principles applied

SSOT: 변경 기록과 Claude·Codex manifest의 버전을 맞추고 원격 커밋으로 확인합니다.
Honesty: 푸시·병합·릴리스 게시·실제 로드를 구별해 기록합니다. 성공했다고 답한 문장뿐 아니라 실제 도구 호출과 읽은 파일도 확인했습니다.
Completion: 병합 후 main의 파일과 새 호스트가 읽은 파일을 다시 대조했습니다.
SoC: 제품 배포와 개인 기준 DB, 연구에서만 사용하는 명령을 구별했습니다.
