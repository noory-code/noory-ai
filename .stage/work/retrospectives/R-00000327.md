# R-00000327 등급 표 설계와 Agent 훅 실측 결과를 카드에 남긴다

## Work

W-00000327 본문에 등급 표(`model_tiers`)·`tier_routing`·카드 `tier:`·드라이버 환경 변수·Agent 훅·감사가 각각 무엇을 읽고 쓰는지 적었다. 오케스트레이터 세션의 실측 다섯 가지에 이 세션에서 `claude -p` 로 두 번 더 실측한 결과를 더했다. 확인하지 않은 사실 세 가지는 따로 적었다.

## Decision points

- 빠진 model·effort: 사용자가 "카드 등급으로 채움" 을 골랐다. 열린 카드 등급이 둘 이상이면 채울 값을 고를 수 없어 막는다(Fail Fast).
- 비싼 모델의 이유 자리: 사용자가 `description` 의 `[over-tier: 이유]` 를 골랐다.
- 열린 카드가 여럿일 때 상한은 그중 가장 비싼 등급으로 정했다. 사람이 동시에 여러 카드를 열어 둔 것은 그 범위의 일을 허락한 것이기 때문이다.
- 템플릿에는 claude 칸만 싣는다. codex·agy 모델 이름은 확인한 값이 없어서 지어내지 않았다(Honesty).
- W-00000330 의 `claude -p` 실측 기준은 Codex 실행기가 닿을 수 없는 기준이라 에픽을 닫을 때 Claude 가 맡도록 옮겼다.

## Principles applied

SSOT(설정 한 곳, 공용 모듈 하나, 설계는 이 카드 하나), Fail Fast(채울 값이 모호하면 막음), Honesty(실측하지 않은 것을 따로 적음), MECE(구현 story 넷이 설정·드라이버·훅·감사로 겹치지 않게 나눔).

## Context that helped

- 오케스트레이터의 실측이 훅 입력 모양과 `updatedInput` 동작을 이미 보여 줬다.
- 드라이버가 리뷰어 venue 를 이미 구하고 있었다(`resolve_independent_reviewer_venue`).

## Context that was missing

- `effort` 채움이 적용되는지 몰랐다. `low` 한 번만으로는 부모 값과 구별되지 않아서 `high` 로 한 번 더 돌려 구별했다.
