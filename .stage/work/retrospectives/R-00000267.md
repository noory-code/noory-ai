# R-00000267 플레인리를 릴리스하고 새 세션에서 한국어 답을 확인한다

## Work

플레인리를 output style 로 낸 0.6.0 을 릴리스하고, 새 세션에서 스타일이 불러와지는 것을 확인했다.
사람의 판정은 한 달 넘게 남아 있다가 2026-11-16 에 나왔다. 그날 사용자는 긴 작업 세션에서
Claude 의 한국어를 여러 번 고쳐 줬고, 그 지적으로 지침을 두 번 더 고쳐 0.7.3 까지 냈다. 그 뒤
사용자가 "충분한듯"이라고 판정했다.

## Decision points

- **판정을 사람에게 남겨 두었다.** 정적 검사나 문장 수 세기로는 한국어가 자연스러운지 판정할 수
  없다. 이 카드는 그 판정이 나올 때까지 열려 있었다.
- **0.7.3 을 켠 새 세션에서 다시 읽어 보는 일은 하지 않고 닫았다.** 사용자가 지금 수준으로
  충분하다고 했다.

## Principles applied

- Honesty — 판정이 무엇을 보고 나온 것인지, 무엇을 다시 보지 않았는지 카드에 적었다.
- Completion — 버전이 불러와지는 것과 사람의 판정을 따로 확인했다.

## Context that helped

- 사용자가 고쳐 준 문장들. "실측해 보면 → 실제로 측정해 보면"처럼 고친 예가 지침의 예문이 됐다.

## Context that was missing

- 판정을 "다른 곳에서 써 보겠다"로 미루면 그 판정이 언제 나오는지 아무도 챙기지 않는다. 한 달 넘게
  열려 있었다.

## Next changes

- 긴 작업 세션에서도 지침이 통하는지는 세션 기록이 쌓인 뒤 다시 센다.
