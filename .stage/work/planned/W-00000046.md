## Source

## User value

## Scope

### Included

- 시도 상한·무진전·진동 감지 → blocked 전환 + pending decision 생성
- 전역 자원 실링(반복·토큰·시간) 백스톱

### Excluded

- 드라이버 루프 골격 자체(W-00000047); 여기선 정지·에스컬레이션 정책만
