# 계획된 작업 인덱스

이 문서는 계획된 작업 카드의 현재 인덱스를 소유한다.

카드 본문은 `work/planned/`에 있다. 이 문서는 순서, 상태, 링크만 관리한다. 작업을 시작한 카드는
`work/current/`로 이동하고(`scripts/start_work.py`), 그 행은 이 인덱스를 떠나
`work/active.md`로 간다.

## 계획된 작업

| ID | 제목 | 종류 | 상태 | 우선순위 | 부모 | 항목 |
|---|---|---|---|---|---|---|
| W-00000243 | 결정을 세우기 전에 최소 구현으로 확인하는 걸음을 넣는다 | design | captured |  |  | [W-00000243/_story.md](W-00000243/_story.md) |
| W-00000251 | 실행하는 쪽이 자기 카드의 파일 목록을 못 넓히게 한다 | design | captured |  |  | [W-00000251/_story.md](W-00000251/_story.md) |

## 상태 값

- `captured`: 캡처되었지만 아직 정리되지 않음.
- `triaged`: 목적과 영향이 확인됨.
- `ready`: 실행 후보가 될 만큼 구체화됨.
- `selected`: 현재 또는 다음 작업으로 선택됨.
- `deferred`: 보류.
- `rejected`: 하지 않기로 결정.
