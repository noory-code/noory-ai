# 계획된 작업 인덱스

이 문서는 계획된 작업 카드의 현재 인덱스를 소유한다.

카드 본문은 `work/planned/`에 있다. 이 문서는 순서, 상태, 링크만 관리한다. 작업을 시작한 카드는
`work/current/`로 이동하고(`scripts/start_work.py`), 그 행은 이 인덱스를 떠나
`work/active.md`로 간다.

## 계획된 작업

| ID | 제목 | 종류 | 상태 | 우선순위 | 부모 | 항목 |
|---|---|---|---|---|---|---|
| W-00000087 | codex 리뷰 명령에도 기준 판정 계약을 넘긴다 | development | captured |  |  | [W-00000087.md](W-00000087.md) |
| W-00000089 | 리뷰어가 리뷰를 못 했는데 통과로 끝난다 | fix | captured |  |  | [W-00000089.md](W-00000089.md) |
| W-00000090 | 세션 안에서 돌린 드라이버가 세션 환경을 리뷰어에게 흘린다 | fix | captured |  |  | [W-00000090.md](W-00000090.md) |

## 상태 값

- `captured`: 캡처되었지만 아직 정리되지 않음.
- `triaged`: 목적과 영향이 확인됨.
- `ready`: 실행 후보가 될 만큼 구체화됨.
- `selected`: 현재 또는 다음 작업으로 선택됨.
- `deferred`: 보류.
- `rejected`: 하지 않기로 결정.
