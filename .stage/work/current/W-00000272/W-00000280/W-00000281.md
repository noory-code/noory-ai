# W-00000281 기록 분석과 페르소나 내보내기를 Avatar 웹에서 연결한다

## Purpose

사용자가 Avatar 기록에서 자신을 돌아보고 닮고 싶은 작업 방식을 AI 규칙으로 가져갑니다

## User value

Avatar에 쌓인 기록을 직접 살펴보고, 선택한 작업 방식을 AI에 전달할 수 있습니다.

## Scope

### Included

로컬 웹 화면, Avatar show JSON 가져오기, 명시한 로컬 DB 읽기, 근거가 연결된 기록 요약, 캐릭터와 배지, 리포트와 규칙 파일 내려받기를 구현합니다.
사용자가 고른 기록과 전송 내용을 확인한 뒤 Claude로 분석합니다. 해석에는 근거와 다른 설명의 가능성을 붙입니다.

### Excluded

공개 서버, 결제, 자동 대화 수집과 개인 기준 덮어쓰기는 포함하지 않습니다. 언어 모델로 성격을 진단하거나 분석 정확도를 검증했다고 주장하지 않습니다.
