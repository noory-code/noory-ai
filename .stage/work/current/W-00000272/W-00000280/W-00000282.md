# W-00000282 다시나 제품 소스를 Avatar 플러그인과 별도 레포로 옮긴다

## Purpose

다시나가 독립된 제품 레포에서 로컬 기록을 읽고 일기와 주간 화면을 제공하면서 Avatar 플러그인은 선택과 기준 기록을 독립적으로 유지합니다

## Source

사용자는 플러그인과 제품 소스를 분리할지 물은 뒤 “그래요 진행해봐요”라고 요청했습니다. 앞서 제품 이름을 다시나로 정하고 Novel로 제품을 설계하자고 했습니다.

## User value

사용자는 Avatar 플러그인을 설치하지 않아도 다시나의 가상 예시를 살펴볼 수 있습니다. 자신의 기록을 열 때는 Avatar가 내보낸 파일을 직접 고르거나 로컬 CLI 경로를 지정합니다.

## Scope

### Included

다시나의 웹 화면, 로컬 서버, 공개 가상 예시, 제품 검사와 사용법을 독립 저장소로 옮깁니다. Avatar의 기록·기준 저장 기능은 원래 저장소에 둡니다. 별도 Novel 프로젝트를 만듭니다.

### Excluded

대화 원문 자동 수집, 클라우드 동기화, 광고 연결, 공개 배포와 실제 개인 기록 시험은 포함하지 않습니다. 이름을 바꾸기 위해 기존 Avatar JSON 형식을 깨뜨리지 않습니다.

## Dependencies

기존 Avatar CLI의 `show --json` 형식을 읽습니다. 로컬 저장소를 직접 열 때는 사용자가 Avatar CLI와 저장소의 경로를 지정해야 합니다. Novel 프로젝트의 목적 문구는 사용자가 “넵”으로 확인했습니다.

## Risks

새 저장소는 로컬 커밋만 있고 원격 저장소가 없습니다. `.stage/work/planned/W-00000001/W-00000002/_story.md`에 개인 경로가 있어 공개 원격에 올리기 전에 지워야 합니다. 웹 화면의 가상 사례는 실제 대화 분석 결과가 아닙니다. 사용자가 로컬 서버에 `--ai claude`를 명시하고 전송 내용을 확인한 경우에만 선택한 기록을 Claude CLI로 보냅니다.

## Success criteria

- 다시나 로컬 화면과 공개 예시가 별도 레포에서 실행되고 기존 가상 자료 검사와 브라우저 흐름이 통과합니다
- Avatar 플러그인이 다시나 제품 파일 없이도 선택과 기준을 읽고 내보내며 기존 검사에 통과합니다
- 두 레포의 연결은 사용자가 명시적으로 요청한 기록만 읽고 대화 원문을 자동으로 외부에 보내지 않습니다

## Next action

Novel에서 나머지 제품 기준과 실제 참여자의 역할을 사용자와 정합니다. 원격 연결은 별도로 결정합니다. 일반 대화 분석과 클라우드 동기화는 후속 작업으로 남깁니다.

## Related truth

SSOT, SoC, Honesty, Completion. Avatar가 개인 기준의 원본을 소유하고 다시나는 화면과 가상 예시를 소유합니다. 두 저장소 사이에서 원본 DB를 직접 공유하지 않습니다.
