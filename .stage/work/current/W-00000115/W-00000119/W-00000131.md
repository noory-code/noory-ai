# W-00000131 상한 되돌리기가 --reason 을 받는 명령이 된다

## Purpose

시도 상한에 닿아 사람에게 올라온 카드를 사람이 고친 뒤 다시 돌리려면, 지금은 시도 기록 JSON 의 세 자리(attempt_count, last_fingerprint, started_at_unix)를 손으로 맞춰야 한다(O-00000007, 두 번 밟음). 되돌리기를 드라이버의 명령으로 만들고 --reason 을 필수로 받아 카드의 공유 작업 로그에 남긴다 — 상한은 안전 장치이므로 푸는 일에 근거가 붙는다.
