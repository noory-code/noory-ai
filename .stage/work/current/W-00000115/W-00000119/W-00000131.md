# W-00000131 상한 되돌리기가 --reason 을 받는 명령이 된다

## Purpose

시도 상한에 닿아 사람에게 올라온 카드를 사람이 고친 뒤 다시 돌리려면, 지금은 시도 기록 JSON 의 세 자리(attempt_count, last_fingerprint, started_at_unix)를 손으로 맞춰야 한다(O-00000007, 두 번 밟음). 되돌리기를 드라이버의 명령으로 만들고 --reason 을 필수로 받아 카드의 공유 작업 로그에 남긴다 — 상한은 안전 장치이므로 푸는 일에 근거가 붙는다.

## Scope

`stage/scripts/drive.py` 의 되돌리기 명령과 그 테스트, CHANGELOG 미출시 절.

## Success criteria

리뷰가 통과시킨 그대로를 기록한다 — 등록 때 비워 둔 것이 지적이었고(리뷰어가 Purpose 에서
재구성해야 했다), 뒤 액션 둘은 돌리기 전에 채웠다.

- 되돌리기가 드라이버 명령이고 `--reason` 없이는 거절한다.
- 시도 수·지문·시작 시각을 명령이 맞추고, 사람이 JSON 을 열 일이 없다.
- 그 실행에 역할이 살아 돌고 있으면(`running_role`) 거절한다 — 도는 시도의 기록을 밑에서
  바꾸지 않는다.
- 되돌린 사람·대상·이유가 카드의 공유 작업 로그에 남는다.
- 스크립트 스위트가 통과한다.
