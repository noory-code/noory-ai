# W-00000193 코덱스가 판정할 때 판정 파일을 쓸 수 있게 한다

## Purpose

코덱스 판정 명령이 읽기 전용으로 돌아 판정 파일을 못 쓰고, 클로드 몫 카드는 드라이버로 못 돈다.

## Source

2026-08-03, W-00000188 을 드라이버에 넘겼다가 걸렸다. 이 저장소에서 클로드 몫 카드를 드라이버로
돌린 첫 사례다.

## User value

클로드 몫 카드도 드라이버로 돈다. 지금은 설계·문서 카드를 전부 손으로 해야 한다.

## Scope

### Included

- 코덱스 판정 명령이 판정 파일을 쓸 수 있게 한다.
- 클로드 몫 카드를 실제로 한 바퀴 돌려 확인한다.

### Excluded

- 실행자 명령. 이미 쓸 수 있다.
- 플러그인이 배포하는 설정 틀. 그 틀에는 이 명령이 아예 없다(확인함) — 이 저장소가 손으로
  적은 것이다.

## Dependencies

없다.

## Risks

- **판정하는 쪽에 쓰기를 주면 판정자가 결과물을 고칠 수 있다.** 판정자는 판정 파일과 공유
  로그만 쓰면 된다. 더 넓게 열리는지 보고, 넓으면 그렇게 적는다.

## Success criteria

- 클로드 몫 카드를 드라이버로 돌리면 코덱스 판정이 판정 파일을 쓰고 바퀴가 끝까지 간다.
- 판정하는 쪽이 얻는 쓰기 범위가 무엇인지 카드에 적혀 있다.

## 2바퀴 — 판정이 찾은 것

### 실행자 지시문의 백틱이 단어를 지운다

설정의 명령 문자열은 셸로 돈다(`close_work.run_check` 가 `shell=True`). 그래서 지시문 안의
백틱이 **명령 치환으로 읽혀 그 안 단어가 사라진다.** 실측:

```
$ sh -c 'echo "use `not_applicable` only when"'
not_applicable: command not found
use  only when
```

`executors.claude` 와 `executors.codex` 둘 다 이 모양이다. 지금 실행자들은 승격 값 다섯
단어(`not_applicable`·`approved`·`deferred`·`rejected`·`promoted`)가 **다 빠진** 지시를 받는다.

**그 문장은 오늘 W-00000178 이 넣었다.** 오늘 세운 계약이 오늘부터 깨진 채로 전달됐다.
이 카드의 실행자 자신도 그 깨진 지시로 돌았다.

백틱을 없애거나 셸이 안 먹게 한다. 그리고 **다시는 이렇게 안 들어가게 무엇으로 막을지** 적는다 —
설정의 명령 문자열은 셸을 거친다는 것이 어디에도 안 적혀 있다.

### 클로드 실행자가 API 호스트를 못 찾아 멈췄다

인프라 실패로 판정됐고 시도를 안 썼다. **2026-08-03 에 연결이 돌아온 것을 확인했다**(`claude -p`
가 응답함). 이번 바퀴에서 실제로 한 바퀴가 도는지 본다.

## 3바퀴 — 판정이 찾은 것

### 백틱 그물이 이 파일의 셸 명령 일곱 중 둘만 덮는다

새 회귀 시험이 실행자 명령 둘만 훑는다. 판정 명령 둘과 판정 강도 셋은 안 본다. 지금 그 다섯에
백틱은 없어서 깨진 데는 없다.

**다만 카드가 "다시는 이렇게 안 들어가게 무엇으로 막을지"를 적겠다고 했다.** 그 다섯이 바로
기준 1이 통과하려면 반드시 도는 판정 경로다. 그물을 이 파일의 셸 명령 전부로 넓힌다.
