# W-00000189 카드를 등록할 때 안 센 것을 장치가 잡게 한다

## Purpose

세고 나서 쓰라는 규칙이 기억에 적혀 있는데 하루에 다섯 번 어겼다.

## Actions

- W-00000190 — 이 변경이 닿는 자리를 카드에 세게 한다
- W-00000191 — 범위와 성공 기준이 서로 덮는지 본다
- W-00000192 — 마일스톤에 걸 때 그 완료 기준을 보여준다

## User value

카드를 쓰는 순간에 안 센 것이 드러난다. 지금은 판정이 잡거나 사람이 물어야 드러나고, 그때는
이미 한 바퀴를 돌린 뒤다.

## Scope

### Included

- 카드를 등록할 때 이 변경이 닿는 자리를 세게 한다.
- 범위에 적은 것과 성공 기준이 서로 덮는지 본다.
- 마일스톤에 걸 때 그 마일스톤의 완료 기준을 보여주고 움직이는지 묻는다.

### Excluded

- **기억이나 문서에 규칙을 더 적는 일.** 이미 적혀 있고 그래서 이 카드가 있다.
- 습관으로 남는 셋 — 도구가 있는지 먼저 찾기, 표본을 넓히고 비율 말하기, 목록 말고 파일을
  열어 보기. 장치를 둘 자리가 없다.
- 드라이버가 도는 중에 사람이 체크아웃을 만지는 것. O-00000013 의 감독 실행 몫이다.

## Risks

- **칸을 늘리면 아무 말이나 채우고 넘어간다.** 세라고 시키는 것과 실제로 세는 것은 다르다.
  각 액션이 "이 칸이 채워졌는지"가 아니라 "센 흔적이 있는지"를 어떻게 볼지 정해야 한다.
- **카드 쓰는 값이 오른다.** 카드 하나를 만드는 데 드는 시간이 늘면 카드를 안 쪼개게 된다.
  늘어난 값을 재고 적는다.

## Success criteria

- 닿는 자리를 안 세고 쓴 카드가 등록에서 드러난다.
- 범위에는 있는데 기준에 없는 결말이 등록에서 드러난다. W-00000185 가 그렇게 반려됐다.
- 마일스톤에 걸 때 그 완료 기준이 눈앞에 온다.
- 사람이 겪는 결과: **판정이 "이 자리를 안 세셨네요"를 말하는 횟수가 준다.** 2026-08-03 에
  다섯 번이었다.

## Next action

  다섯 번 다 판정이 잡았고 내가 먼저 센 적은 없다. 나머지는 범위와 기준이 어긋난 것 하나,

  알고도 체크아웃을 만진 것 하나다.
