# W-00000079 드라이버와 닫기 도구의 실패 처리·기록을 마무리한다

## Purpose

실전 실행에서 드러난 남은 결함들을 닫는다. 드라이버의 색인 처리 실패 경로 넷과, 닫기 도구가 리뷰 판정과 검증 개수를 기록하는 방식이다.

## Scope

실전 실행에서 드러난 남은 결함 둘을 자식으로 둔다.

- W-00000077 — 드라이버의 색인 처리 주변 실패 넷. 진전 판정이 실패를 삼키고, 색인 파일이 없는
  저장소에서 잘못 막히고, 색인 처리가 실패하면 실행자 출력이 사라지고, Windows 셸 특수 문자가
  감사 명령을 깬다.
- W-00000078 — 닫기 도구가 통과한 리뷰의 판정 내용을 남기지 않고, 실행한 검증 개수를 잘못 센다.

이 카드 자체는 코드를 고치지 않는다. 두 자식을 드라이버로 실행하고 결과를 기록한다.

## Success criteria

- 두 자식이 완료 상태가 된다.
- `python3 stage/scripts/audit_stage.py --project-root .` 오류 0.

## Related truth

- 발견 경위: W-00000069, W-00000073, W-00000075 의 실전 실행과 닫기 리뷰.

**위험**: 두 자식이 서로 다른 파일을 고치므로 순서에 얽힘은 없다. 다만 W-00000078 은 닫기
도구 자체를 고치는데, 그 도구가 이 카드들을 닫는 데 쓰인다. 고치는 도중의 상태로 다른 카드를
닫지 않도록 W-00000078 은 자기 변경을 커밋한 뒤에 닫을 것.
