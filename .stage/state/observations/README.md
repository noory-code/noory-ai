# 관측

이 디렉터리는 현재 관측의 SSOT를 소유한다.

## 규칙

- 관측 하나는 파일 하나를 가진다.
- `opened:` 에 처음 적은 날짜를 `YYYY-MM-DD` 로 넣는다. 세션 시작 목록이 이 값으로 며칠째
  열려 있는지를 말한다. 파일 시각으로는 대신할 수 없다 — 새로 받거나 워크트리를 만들면 모든
  기록이 오늘 날짜가 된다.
- 검증된 관측은 `official/`로 승격될 수 있다.
- 오래된 관측은 상태를 바꾼다. 삭제하지 않는다.
- 닫힌 관측은 제목 바로 아래에 무엇이 그것을 닫았는지 적는다. 기록은 남으므로 파일만 열어도
  아직 살아 있는지가 읽혀야 한다. 목록에만 적으면 파일이 거짓을 말한다.
