# O-00000048 Plainly의 한국어 지침은 뜻 보존과 자연스러움을 따로 확인해야 한다

## Observation

사용자가 명사 중심의 영어를 동사 중심의 한국어로 풀지 못하는 문제를 추가로 지적했다.
번역과 새 설명 작성까지 열거를 넓혔다. 짧은 번역에서는 잘 풀었으나 설명을 감싸는 긴 틀이
남았다. 동사만 강조하면 어색한 어휘 결합도 생겨 구조 변경과 의미 보존을 함께 확인해야 한다.

교정 예시 두 개가 수량의 대상과 원인을 바꾸고 있었다. 기존 검사는 문구 존재를 확인하므로
실제 답변의 자연스러움까지 보장하지 않는다. 이 종류의 영향을 단일 스타일 전체에서 확인했다.
