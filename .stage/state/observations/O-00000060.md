# O-00000060 열린 카드가 없으면 관문이 머지 커밋도 막는다

## Observation

커밋 관문은 머지 커밋을 보통 커밋과 구분하지 않는다. 카드를 닫고 보관한 뒤에 PR 이 main 과 충돌하면, 충돌을
푼 머지 커밋을 만들 수 없다. 열린 카드가 없기 때문이다.

## Evidence

- 2026-11-20, W-00000358 을 닫고 보관한 뒤 PR 이 main 과 충돌했다. 머지 커밋을 관문이 막았고, 사용자가 카드를
  새로 등록하는 쪽을 골라 W-00000360 으로 풀었다.
- 관문 코드에서 머지 커밋을 다루는 자리를 찾아 읽지는 않았다. 겪은 일만 적는다.

## Impact

충돌을 풀려고 카드를 한 장 더 등록하고 닫아야 한다. 카드를 닫기 전에 main 을 먼저 합쳐 충돌이 있는지 보면
피할 수 있다.

## Status

열림. 관문을 고칠지는 사용자에게 아직 묻지 않았다.

## Next action

관문이 머지 커밋을 따로 다뤄야 하는지 사용자에게 묻는다. 그 전에는 카드를 닫기 전에 main 을 합쳐 본다.
