# 현재 상태

이 문서는 현재 프로젝트 관측의 인덱스를 소유한다.

관측 본문은 `observations/`에 있다.

## 현재 관측

- [O-00000002](observations/O-00000002.md) — 사람에게 넘기는 커밋이 카드 범위 안의 `.stage`
  파일을 함께 담는다. 지금은 해가 없어 받지 않는다.
- [O-00000012](observations/O-00000012.md) — 설명 문서 갱신의 기본 실행이 다른 프로젝트의 관측
  인덱스 22행을 지웠다. DE-00000042 가 규칙을 정했고 코드에는 아직 안 실렸다.
- [O-00000013](observations/O-00000013.md) — 드라이버가 도는 동안 사람이 같은 체크아웃을 만지면
  그 변경이 실행자 몫으로 섞여 성공한 실행이 실패로 판정된다. 우회는 있고 아직 안 받았다.
- [O-00000014](observations/O-00000014.md) — 초기화 스킬이 손 작업 대비 문장에서 한 세대 전
  템플릿 트리를 가리킨다. 같은 파일의 구조 블록은 현재 세대다.
- [O-00000015](observations/O-00000015.md) — `.stage/` 기록을 고치는 카드를 드라이버에 넘기면
  실행자가 목적 게이트에 한 번 막힌다. 다시 시도하는지 실패로 보고하는지 아직 안 봤다.
- [O-00000016](observations/O-00000016.md) — 보관 명령의 `--all-completed` 가 계층을 만나면
  중간에 죽고, 되돌리는 길이 하니스 안에 없다. 최상위 id 하나만 넘기면 정상이다.
- [O-00000017](observations/O-00000017.md) — 드라이버가 판정 도중 죽으면 이어 갈 명령이 없다.
  다시 돌리면 실행자부터라 "변화 없음"으로 죽는다. 사람이 대신 검증하게 된다.
- [O-00000018](observations/O-00000018.md) — 목적을 보여 주는 장치가 카드를 막 만든 직후에는
  보여 줄 것이 없다. 본문이 비어 있는데 그 한 번을 거기서 써 버린다.
- [O-00000020](observations/O-00000020.md) — 만든 쪽이 카드의 파일 목록을 스스로 넓히면 넘었다는
  기록이 카드에서 사라진다. 보고에만 남는다.
- [O-00000021](observations/O-00000021.md) — 도구 없이 말로 물으면 아무 게이트도 안 걸린다.
  목적을 안 보고 사람에게 판단을 떠넘겨도 아무 데도 안 남는다.
- [O-00000023](observations/O-00000023.md) — 사람이 판정을 읽고 정하는 시간이 드라이버의 실행
  한도를 갉아먹는다. 오래 논의할수록 그 카드를 못 돌린다.
- [O-00000024](observations/O-00000024.md) — 판정하는 쪽이 실행하는 쪽보다 값을 더 쓴다
  (72 바퀴 실측: 출력 2.9배, 입력 1.3배). 판정을 어디에 맡길지의 기준.
- [O-00000025](observations/O-00000025.md) — 승격했다는 말을 감사가 검사할 수 없다. 새 기록을
  만드는 승격은 잡히고, 기존 공식 문서를 고치는 승격은 못 잡는다.
- [O-00000026](observations/O-00000026.md) — 되돌리기가 표시를 든 카드가 아니라 다음 실행할
  카드를 겨눈다. 손 되돌림 길이 흔한 경우에만 열려 있다.
- [O-00000028](observations/O-00000028.md) — 병렬 worktree 에서 실행 환경이 카드마다 다르게
  깨진다. 넷은 되고 셋은 각각 다른 이유로 멈췄다. 미리 알 방법이 없다.
- [O-00000030](observations/O-00000030.md) — 시간 한도로 잘린 바퀴에서 일이 끝나면 드라이버가
  그 카드를 영영 못 닫는다. 네 고리가 이어져 빠져나갈 길이 없다.
- [O-00000031](observations/O-00000031.md) — 액션이 없는 스토리는 크기가 안 잡혀 시간 한도가
  최소값 900초로 떨어진다. O-00000030 의 첫 고리를 당긴다.
- [O-00000032](observations/O-00000032.md) — 허가증을 보관함으로 옮기다 원본 삭제만 실패하면
  같은 기록이 두 자리에 살고, 대기본이 이겨서 다 쓴 허가증이 다시 통과한다.
