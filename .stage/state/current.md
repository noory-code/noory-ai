# 현재 상태

이 문서는 현재 프로젝트 관측의 인덱스를 소유한다.

관측 본문은 `observations/`에 있다.

## 현재 관측

- [O-00000002](observations/O-00000002.md) — 사람에게 넘기는 커밋이 카드 범위 안의 `.stage`
  파일을 함께 담는다. 지금은 해가 없어 받지 않는다.
- [O-00000003](observations/O-00000003.md) — **닫힘.** 명령당 시간 제한은 규모에서 나오고
  (W-118), 인프라 실패는 두 모드 다 시도를 안 쓴다(W-133).
- [O-00000004](observations/O-00000004.md) — **닫힘.** 판정을 산문에서 읽는 자리가 없어졌다 —
  리뷰어가 쓰는 JSON 판정 파일이 통과를 정한다(W-117). 하루 일곱 번 걸린 자리였다.
- [O-00000005](observations/O-00000005.md) — **닫힘.** 드라이버가 자기가 넘긴 로그 경로를
  대조에서 뺀다(W-116).
- [O-00000006](observations/O-00000006.md) — **닫힘.** 대조 범위가 카드 누적으로 통일됐고
  사람의 편집은 실행자 몫에 안 섞인다(W-116·121).
- [O-00000007](observations/O-00000007.md) — **닫힘.** 되돌리기가 `--reason` 을 받는 명령이
  됐다(W-131).
- [O-00000008](observations/O-00000008.md) — 마이그레이션 감사 기준선이 메시지에 박힌 경로에
  약하다. 그런 빚을 가진 프로젝트는 오탐으로 막힐 수 있다(fail-closed 라 데이터는 안전).
  novel-workspace 재마이그레이션을 지켜본다.
- [O-00000009](observations/O-00000009.md) — 계층 게이트가 계획 인덱스 손 편집을 막았다.
  W-00000114 가 고쳤고 W-00000092 반려로 확인했다.
- [O-00000010](observations/O-00000010.md) — 시간이 다 됐을 때 무엇이 돌던 중인지를 로그
  제목으로 짐작한다. 실행자가 보고를 쓰고도 계속 돌면 엉뚱한 쪽을 거둔다. 만드는 쪽
  (`running_role` 기록)은 W-00000118 이 넣었고, 병렬 쪽이 읽게 바꾸는 것이 남았다.
- [O-00000011](observations/O-00000011.md) — 에이전트 세션 안에서 손으로 돌린 인수 검사는
  가짜 실패 8개를 보인다. 세션의 프로젝트 변수가 훅 스폰 테스트를 오염시킨다. 드라이버
  경유는 깨끗하다(W-00000134). 테스트 헬퍼가 변수를 스스로 걷는 것이 원인 자리 수정이다.
