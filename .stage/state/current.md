# 현재 상태

이 문서는 현재 프로젝트 관측의 인덱스를 소유한다.

관측 본문은 `observations/`에 있다.

## 현재 관측

- [O-00000002](observations/O-00000002.md) — 사람에게 넘기는 커밋이 카드 범위 안의 `.stage`
  파일을 함께 담는다. 지금은 해가 없어 받지 않는다.
- [O-00000003](observations/O-00000003.md) — 드라이버가 카드 크기와 무관하게 명령당 15분에
  끊는다. 실행자는 계속 돌아서 일은 끝났는데 판정만 실패로 남는다.
- [O-00000004](observations/O-00000004.md) — 리뷰 판정의 기계 판독이 `CRITERIA VERDICT:` 의
  콜론 하나에 걸린다. 전부 통과여도 실패로 기록되고 시도를 하나 쓴다.
- [O-00000005](observations/O-00000005.md) — 실행자가 지시대로 작업 로그를 바뀐 파일에 넣으면
  주장·관측 검사에 걸린다. 그 로그를 git 이 안 본다. 정직할수록 실패한다.
- [O-00000006](observations/O-00000006.md) — 재시도하면 앞 시도의 변경이 관측에서 빠져 불일치가
  난다. 아무도 안 틀렸는데 실패로 기록된다.
- [O-00000007](observations/O-00000007.md) — 사람이 카드를 바꾼 뒤 드라이버를 다시 돌릴 명령이
  없다. 시도 기록 JSON 의 세 자리를 손으로 맞춰야 하고, 되돌린 근거가 안 남는다.
- [O-00000008](observations/O-00000008.md) — 마이그레이션 감사 기준선이 메시지에 박힌 경로에
  약하다. 그런 빚을 가진 프로젝트는 오탐으로 막힐 수 있다(fail-closed 라 데이터는 안전).
  novel-workspace 재마이그레이션을 지켜본다.
- [O-00000009](observations/O-00000009.md) — 계층 게이트가 계획 인덱스 손 편집을 막았다.
  W-00000114 가 고쳤고 W-00000092 반려로 확인했다.
- [O-00000010](observations/O-00000010.md) — 시간이 다 됐을 때 무엇이 돌던 중인지를 로그
  제목으로 짐작한다. 실행자가 보고를 쓰고도 계속 돌면 엉뚱한 쪽을 거둔다. 시도 기록에 도는
  역할을 적어야 제대로 풀린다(`drive.py` 몫).
