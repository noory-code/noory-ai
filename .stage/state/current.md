# 현재 상태

이 문서는 현재 프로젝트 관측의 인덱스를 소유한다.

관측 본문은 `observations/`에 있다.

## 현재 관측



- [O-00000038](observations/O-00000038.md) — 쉬고 있는 팀원이 쌓인 메시지를 안 집고, "할 일
  없음" 알림이 실제 작업보다 먼저 온다. 감독이 한 번 더 보내야 움직인다. 종료 요청도 그렇다.
- [O-00000058](observations/O-00000058.md) — 닫기 리뷰는 맨 위 커밋이 고친 파일만 본다. 코드 커밋 뒤에
  기록만 고친 커밋을 올리면 리뷰어가 코드를 보지 않는다.
- [O-00000059](observations/O-00000059.md) — 드라이버가 닫는 카드는 바로 보관되지 않고, 판 사이의 리뷰가
  카드에 남지 않는다. 드라이버를 다시 쓸 때 맞춘다.
- [O-00000060](observations/O-00000060.md) — 열린 카드가 없으면 관문이 머지 커밋도 막는다. 카드를 닫기 전에
  main 을 합쳐 충돌을 먼저 본다.
- [O-00000062](observations/O-00000062.md) — 사용자의 기계나 사용자 자신만 할 수 있어 미뤄 둔 확인을 한 곳에 모은다. 사용자가
  줄마다 확인하고 표시한다.
