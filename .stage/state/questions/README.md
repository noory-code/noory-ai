# 질문

이 디렉터리는 미해결 질문의 SSOT를 소유한다.

## 규칙

- 질문 하나는 파일 하나를 가진다.
- 질문은 필요한 결정, 막고 있는 작업, 답변 소유자를 가진다.
- 답이 나오면 `official/decisions/` 또는 해당 진실로 승격한다.
- 옮길 수 없으면 제목 바로 아래에 답이 나왔다는 것과 그 답이 어디 있는지 적는다. 보관된 기록이
  그 질문을 가리키면 못 옮긴다. 이때 `## Status` 절의 첫 토큰을 `answered`로 둔다. 세션의 열린
  질문 목록은 이 토큰이 있는 기록만 빼며, 다른 화면에는 이 디렉터리의 기록으로 남을 수 있다.
