# DE-00000026 W-49 실행 주체 venue 예외 (claude)

## Question

W-00000049(kind development, 정책상 venue codex)을 누가 실행하는가?

## Options

- A. codex — 정책 기본이나, 무인-루프 관련 빌드 위임이 auto-mode 분류기에 계속 차단됨.
- B. claude — 예외. W-00000048과 동일 상황.

## Principles applied

- User intent — 사용자가 수정 착수를 지시.
- Honesty — 차단 상황과 검토 방식을 명시.
- DE-00000016(실행자 ≠ 검토자) — 실행이 claude이므로 재검토는 codex(사람 Codex 창) 또는 사람.

## Chosen direction

B. claude가 W-00000049(Codex 리뷰 지적 수정)을 실행한다. venue를 claude로 한다. 수정 후 독립 재검토는 사람 Codex 창에서 수행한다(W-48과 동일 경로).

## Reason

무인-루프 구현/수정의 Codex 위임(codex:rescue)이 분류기에 차단되어 있어 claude가 직접 수정한다. 실행자 ≠ 검토자를 유지하기 위해 재검토는 사람이 Codex 창에서 수행한다.

## Follow-up

- codex:rescue 빌드 위임 차단의 복구 여부.
