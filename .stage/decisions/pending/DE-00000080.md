# DE-00000080 커밋의 실행 보고를 작업 로그로 옮기는 도구는 Claude Code 클라우드 세션에서 만든다

## Question

W-00000290 은 `kind: fix` 라 정책상 codex 몫이다. 사용자는 이 클라우드 세션에서 "여기서는 코덱스가
하는 일을 니가 해야 한다"고 지시했고, 이 카드를 다음 일로 승인했다. **이 카드를 어느 자리에서
실행하는가.**

## Options

1. **로컬 codex 드라이버에 넘긴다** — 사용자 지시와 어긋난다.
2. **이 클라우드 세션이 실행한다** — DE-00000079 와 같은 모양의 예외를 한 장 더 세운다. (선택)

## Principles applied

- **User intent** — 사용자가 이 세션이 codex 몫까지 하라고 지시했다.
- **만든 쪽 ≠ 보는 쪽** — 카드에 `review: pending` 을 건다. 닫기 리뷰는 실행 맥락이 없는 별도
  세션이 한다.
- **Fail Fast** — 이 도구가 고치는 문제는 오늘 W-00000287 을 닫을 때 실제로 터졌다.

## Chosen direction

**2번.** W-00000290 은 Claude Code 클라우드 세션이 `claude/w268-cloud` 브랜치에서 실행한다. 이 결정은
W-00000290 한 장만 허가한다. 실행 계약은 DE-00000075 의 세 변경을 그대로 쓴다.

## Where this applies

| 자리 | 무엇을 하는가 |
|---|---|
| W-00000290 카드 `venue` · `decision_refs` | `claude` 와 이 결정을 가리킨다 |
| `.stage/work/active.md` W-00000290 행 | Venue 칸을 `claude` 로 둔다 |

`settings.json` 의 `venue_routing` 은 바뀌지 않는다. 카드가 보관될 때 이 결정도 함께 소진된다.

## Reason

DE-00000075 의 실행 계약은 커밋 본문의 실행 보고를 로컬에서 작업 로그로 옮기라고 하지만 그 일을 손으로
한다. 손으로 옮기다 칸이 잘린 일이 오늘 있었다.

## 이 규칙이 틀렸다는 것을 무엇으로 알게 되나

닫기 리뷰가 클라우드에서 놓친 것을 잡으면 이 경로의 비용이 이득보다 크다.

## Follow-up

- 카드마다 예외를 세우는 일이 오늘만 여섯 번째다(DE-00000075~080).
