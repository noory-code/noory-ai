# DE-00000077 클라우드 세션이 먼저 실행한 W-00000270 을 claude venue 로 기록한다

## Question

W-00000270 은 `kind: fix` 라 정책상 codex 몫이다. 그런데 2026-10-31 Claude Code 클라우드 세션이
`claude/w268-cloud` 브랜치에서 이 카드를 먼저 실행했다(커밋 `558ac6e7`). 그 세션의 실행 보고는
"클라우드에서 실행할 수 있는 카드를 모두 실행하라는 사용자의 직접 지시" 에 따랐다고 적고, venue
예외 결정이 없으니 기록은 로컬에 남긴다고 적었다. **이미 실행된 이 카드를 어떤 venue 로 기록하고
닫는가.**

## Options

1. **venue 를 `codex` 로 둔 채 닫는다** — 실제로 실행한 쪽과 카드 기록이 어긋난다.
2. **실행을 버리고 Codex 드라이버로 다시 돌린다** — 이미 시험을 통과한 작업을 버리고 같은 일을 두 번 한다.
3. **venue 를 `claude` 로 바꾸고 이 결정으로 예외를 기록한 뒤, 로컬에서 검증·Codex 리뷰·닫기를
   한다** — (선택)

## Principles applied

- **Honesty** — 카드 기록은 실제로 실행한 쪽을 말해야 한다. 이 예외는 실행 뒤에 기록한다는 점을
  숨기지 않는다.
- **만든 쪽 ≠ 보는 쪽** — 클라우드의 Claude 가 고쳤고, 닫기 리뷰는 로컬의 Codex 가 한다.
- **SSOT** — 클라우드 실행 방식은 DE-00000075 가 소유한다. 이 결정은 그 방식이 이 카드에도
  적용됐음을 기록한다.

## Chosen direction

**3번.** W-00000270 의 venue 를 `claude` 로 기록한다. 이 결정은 W-00000270 한 장만 허가한다.
"사용자의 직접 지시" 는 클라우드 실행자의 커밋 보고에 적힌 내용이며, 로컬 세션이 그 대화를 직접
본 것은 아니다.

## Where this applies

| 자리 | 무엇을 하는가 |
|---|---|
| W-00000270 카드 `venue` · `decision_refs` | `claude` 와 이 결정을 가리킨다 |
| `.stage/work/active.md` W-00000270 행 | Venue 칸을 `claude` 로 둔다 |
| 로컬 마무리 | 범위 대조, 인수 명령과 전체 시험, Codex 닫기 리뷰, 회고, 닫기 |

`settings.json` 의 `venue_routing` 은 바뀌지 않는다. 카드가 보관될 때 이 결정도 함께 소진된다.

## Reason

실행은 이미 끝났고 클라우드에서 시험을 통과했다고 보고됐다. 남은 일은 기록을 사실에 맞추고 독립
검증을 하는 것이다.

## Follow-up

- 클라우드 세션에 카드를 맡길 때는 venue 예외를 먼저 기록한 뒤 보낸다(DE-00000075 의 순서).
