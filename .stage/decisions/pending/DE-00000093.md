# DE-00000093 회고에는 결정한 자리, 모자랐던 맥락, 규칙 후보 세 칸만 남긴다

## Question

회고(R-*)의 여덟 칸 가운데 나중에 실제로 읽히는 칸은 무엇이고, 나머지를 없애도 되는가.
DE-00000089 가 덜어낼 것 다섯 가지 가운데 4번(회고의 칸)을 이 질문으로 미뤘다.

## Options

| 선택지 | 남는 칸 | 빠지는 칸 |
|---|---|---|
| 셋만 남긴다 | Decision points, Context that was missing, Rule candidate | Work, Principles applied, Context that helped, Next changes, Promotion decision |
| 넷만 남긴다 (DE-00000089 안) | 위 셋과 Next changes | Work, Principles applied, Context that helped, Promotion decision |
| 중복만 뺀다 | Work 와 Promotion decision 을 뺀 여섯 칸 | Work, Promotion decision |
| 고치지 않는다 | 여덟 칸 | 없음 |

### 칸마다 누가 읽는가

보관된 회고 373장에서 칸은 거의 모두 채워져 있다. 채워졌다는 것은 읽혔다는 뜻이 아니어서, 칸을 읽는 자리를 셌다.

| 칸 | 읽는 자리 | 같은 사실을 가진 다른 자리 |
|---|---|---|
| Work | 없음 | 카드의 `## Purpose` 와 실행 보고의 `What changed:` |
| Decision points | 2026-11-21 메인 세션이 R-00000248 에서 거절된 재설계를 찾았다 | 실행 보고의 `Decisions made:` 는 실행자의 선택만 적는다 |
| Principles applied | 없음 (감사 `WORK021`/`WORK022` 는 결정 기록의 같은 이름 칸을 본다) | 결정 기록의 `## Principles applied` |
| Context that helped | 없음 | 없음 |
| Context that was missing | 2026-11-21 메인 세션이 R-00000360 에서 "닫기 전에 main 을 합친다"를 찾았다 | 없음 |
| Next changes | `rule-promotion.md` 가 규칙 후보와 나누는 칸으로만 쓴다. R-00000364 에서 규칙을 찾는 데 쓰이지 않았다 | 계획된 카드, 관측 기록 |
| Rule candidate | `rule-promotion.md`. R-00000364 가 규칙을 찾은 유일한 칸이다 | 없음 |
| Promotion decision | 없음 | 카드의 `promotion:` 과 `## Promotion decision` |

## Principles applied

- SSOT — Work 와 Promotion decision 은 카드가 이미 가진 사실을 다시 적는다. 다음 할 일은 계획된 카드가 가진다.
- YAGNI — 아무도 읽지 않는 칸을 매번 채우게 하지 않는다.
- Honesty — 읽는 자리를 센 근거는 코드와 절차와 이 세션의 사용 두 번이다. 사람이나 AI 가 따로 읽은 것은 세지 못했다.

## Chosen direction

셋만 남긴다. 사용자가 2026-11-22 에 골랐다("2는 1번").

- 회고 양식은 `## Decision points`, `## Context that was missing`, `## Rule candidate` 세 칸이다.
- 다음에 할 일은 회고에 적지 않는다. 카드로 등록하거나 관측·질문 기록으로 보낸다.
- 원칙 인용은 결정 기록의 `## Principles applied` 가 계속 맡는다. 회고에서는 묻지 않는다.
- 이미 보관된 회고는 고치지 않는다. 옛 칸이 남은 회고도 계속 읽힌다.

반대 관점: Principles applied 는 나중에 읽히지 않아도 쓰는 순간 원칙을 다시 대 보게 만드는 장치일 수 있다. 이 결정은
그 효과를 결정 기록이 받는다고 본다. 회고마다 원칙을 다시 대는 것이 결정의 질을 높였다는 근거는 찾지 못했다.

## Where this applies

| 종류 | 자리 | 이 결정으로 바뀌는 것 |
|---|---|---|
| 양식 | `stage/templates/project-stage/present/work/retrospectives/_template.md`, `stage/templates/v4/project-stage/work/retrospectives/_template.md` | 세 칸만 남긴다. |
| 코드 | `stage/scripts/driver_lifecycle.py` 의 `RETRO_SECTIONS` 와 드라이버 회고 문구 | 세 칸만 쓴다. |
| 코드 | `stage/scripts/drive.py` | `driver_lifecycle` 에서 가져온 `RETRO_SECTIONS` 를 똑같이 다시 정의한 것을 지운다. |
| 계약 | `stage/operations/retrospective.md` | 기록할 것을 셋으로 줄인다. |
| 절차 | `stage/skills/stage-retrospective/SKILL.md`, `stage/skills/stage-retrospective/rule-promotion.md` | Next changes 를 가리키던 곳을 "카드나 기록으로 보낸다"로 고친다. |
| 점검 규칙 | 없음 | 감사는 회고의 칸을 보지 않는다. |

## Reason

남는 세 칸은 이 세션과 R-00000364 에서 실제로 다시 읽혔다. 빠지는 다섯 칸은 읽는 자리가 없거나 다른 자리가 같은 사실을
가진다. 회고가 짧아지면 M-00000005 의 "카드 한 장에 드는 문서가 줄었다"에 바로 닿는다.

이 결정이 틀렸다고 볼 일: 빠진 칸에만 있던 사실을 찾지 못해 같은 실수를 되풀이한 회고가 나온다. 또는 다음 할 일이
카드로 가지 않고 사라진다.
