# 연구자료와 결과

이 폴더에는 연구자료와 분석 결과, 후속 시제품의 시험 기록을 보관합니다.
연구 중인 해석과 가설을 공식 결정으로 취급하지 않습니다.
한국어 작업 문서를 두는 프로젝트 규칙에 따라 `.stage/` 아래에 두었습니다.
`.runtime/`과 달리 Git에서 제외하지 않는 경로입니다.

## 외부 자료의 자리

연구에서 읽은 바깥 글은 그 연구의 `research/<주제>/sources.md` 한 파일에 적습니다(DE-00000100).
원문은 저장소에 두지 않습니다. 이 저장소는 공개되어 있고 남의 글을 통째로 둘 수 없기 때문입니다.

글 한 편마다 아래 다섯 가지를 적습니다.

| 적을 것 | 내용 |
|---|---|
| 주소 | 글의 URL |
| 글쓴이와 날짜 | 글쓴이, 글이 나온 날 |
| 읽은 날 | 이 요약을 쓴 사람이나 세션이 글을 읽은 날. 주소의 글이 나중에 바뀌었는지 가릴 때 씁니다 |
| 요약 | 글이 말한 것을 옮겨 쓴 것. 우리 해석은 따로 적고 가설이라고 밝힙니다 |
| 인용 | 원문 그대로의 문장. 요약이 틀렸는지 대조할 수 있는 유일한 자리입니다 |

알고 둔 약점: 주소가 죽으면 요약과 인용만 남고, 요약이 틀렸는지 원문과 맞춰 볼 수 없습니다.
이 규칙보다 먼저 쓴 `sources.md` 에는 읽은 날이 따로 없는 것이 있습니다. 고칠 일이 생길 때 더합니다.
