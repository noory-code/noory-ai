# Avatar / Clone — 개인의 판단 기준과 선택을 돌아보는 아이디어

**최신 상태: 2026-10-05 사용자가 Stage·Distill·Avatar의 첫 연결 흐름 구현에 동의했습니다. [구현 작업](../../work/current/W-00000272/_epic.md)을 등록했습니다.**
이번에는 Avatar라는 이름으로 로컬 기록·조회·기준 수정부터 구현합니다. 아래 내용은 구현을 보류했던 당시의 아이디어와 경계를 보존합니다.

사용자는 개인의 판단 기준을 한 프로젝트 밖에서 모으는 플러그인을 별도로 만들자고 제안했습니다.
처음 제안한 이름은 `avatar`이며, 이후 `clone`도 후보로 언급했습니다.
이어 본래 연구에서 벗어나고 있다며 우선 모두 기록해 두라고 요청했습니다.
새 플러그인 코드, 매니페스트, 작업 카드나 릴리스를 만들지 않았습니다.
이후 사용자가 본래 연구를 계속하자고 요청했습니다. Avatar / Clone 구현을 재개하라는 뜻으로 확대하지 않습니다.

## 사용자가 말한 목적

> 근데 한 프로젝트를 벗어나서 한 인간의 의사결정 기준을 모아두는 것도 난 엄청난 의미가 있다고 생각해요. ㅎㅎ

> 위 목적을 위해서는 avatar 라는 플러그인을 따로 만듭시다.

> 구분해요. 미안 혼란스럽게 하는 것 같은데..

> avatar 혹은 clone? 같은 내가 어떤 의사결정을 하는지 모아두면 메타인지 할수 도 있잖아요.

사용자는 AI가 기준을 활용하는 쓰임새에 더해, 본인이 자신의 선택을 돌아보는 쓰임새도 제안했습니다.
판단 기록을 모으면 메타인지가 실제로 개선되는지는 아직 연구하거나 시험하지 않았습니다.

## Stage·Distill과 어떻게 구분하나요

| 대상 | 이번 논의에서의 역할 | 상태 |
|---|---|---|
| Stage | AI가 목적을 붙잡고 자유롭게 일하는 무대입니다. 프로젝트의 작업·결정·결과를 연결하고 세션이 바뀌어도 이어갈 수 있게 합니다. | 기존 기능이 있으며, 세 가지 개선을 연결하는 방안을 연구했습니다. |
| Avatar / Clone | 프로젝트를 넘어 한 사람의 선택과 판단 기준을 모읍니다. AI가 관련 기준을 활용하고, 사람이 자기 선택을 돌아보는 쓰임새를 검토합니다. | 사용자가 별도 플러그인을 제안했습니다. 명칭과 구현은 미정입니다. |
| Distill | 사용자가 설명한 초기 목적은 룰 생성입니다. 현재 수집·규칙 생성·검색 구현을 비교 자료로 확인했습니다. | 기존 플러그인입니다. Avatar로 이름을 바꾸거나 코드를 이전하기로 정하지 않았습니다. |

Stage에서 개인의 기준을 쓸 수 있다는 이유만으로 그 기록을 한 프로젝트 안에 가둘 필요는 없습니다.
어떤 기능이나 코드를 공유할지는 아직 정하지 않았습니다.
앞서 제안한 ‘궁극적 목적 → Distill → 사용자’ 순서에 Avatar를 어떻게 연결할지도 미정입니다.
기존 논의의 명칭을 일괄 교체하지 않습니다.

## 기록해 둘 쓰임새

아래는 사용자 제안을 구체화한 연구 질문이며, 구현 기능이나 입증한 효과가 아닙니다.

- 다른 프로젝트나 AI를 쓸 때도 이미 밝힌 기준을 다시 설명하는 수고를 줄일 수 있나요?
- 본인이 중요하다고 말한 기준과 실제로 선택한 결과를 함께 살펴볼 수 있나요?
- 서로 달라 보이는 선택이 모순인지, 상황에 따른 예외인지 구별할 수 있나요?
- 생각이 바뀐 시점과 이유를 확인할 수 있나요?
- 기록을 돌아본 뒤 본인이 기준을 수정하고, 다음 선택에 적용할 수 있나요?

사람이 직접 밝힌 이유, AI가 추정한 이유와 나중에 확인한 결과를 구별해야 합니다.
한 프로젝트의 제약 때문에 한 선택을 그 사람의 일반적인 성향으로 확대하지 않습니다.
사용자 침묵이나 AI 자신의 반복 행동을 사용자의 기준으로 확정하지 않습니다.
조건·예외·변경을 다루는 자세한 제안은 [판단 기준 연구](decision-criteria.md)가 소유합니다.

## 본래 연구와의 관계

[본래 연구](purpose.md)는 AI가 일하는 과정을 나눠 보고, 더 잘하거나 덜 반복할 방법을 찾는 일입니다.
이 문서는 그 과정에서 나온 파생 아이디어를 보존합니다.
Avatar의 새 기능을 설계하거나 구현하는 일이 본래 연구의 완료 조건을 계속 늘리게 하지 않습니다.

사용자의 마지막 요청은 다음과 같습니다.

> 아 이건 연구가 좀 어긋난다. 일단 다 기록해두고

따라서 이번에는 기록과 문서 간 구분까지만 마칩니다.
Avatar / Clone의 새 구현, 추가 자료 수집과 모델 실험은 시작하지 않습니다.
본래 연구에서 수행한 후속 실험은 [세션 인계 연구](findings/2026-10-05-context-handoff.md)에 따로 남깁니다.
