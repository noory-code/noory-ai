## 테스트와 리뷰에서 고친 문제

- Distill이 읽는 도중 다른 연결이 기준을 바꾸면 서로 다른 시점의 정보가 섞였습니다. SQLite 읽기 트랜잭션으로 같은 시점의 결과를 돌려주게 했습니다.
- AI가 사용자의 기준을 바꾸거나 빈 출처를 저장할 수 있었습니다. 변경 근거와 발언 주체를 검사합니다. 이 검사가 사람을 인증하는 것은 아닙니다.
- Avatar에 이력을 첨부할 때 서로 다른 기준을 같은 기록처럼 처리할 수 있었습니다. 기준 ID별로 비교하고, 예전 이력이 철회를 덮지 못하게 했습니다.
- 개인 기준을 수정하면 앞 버전의 사용자 확인 근거가 새 제안에 남았습니다. 새 근거를 받지 않은 수정은 확인되지 않은 제안으로 기록합니다.
- Stage에서 `app`과 `app/`을 다르게 읽어 하위 파일에 적용할 기준을 놓쳤습니다. 기존 Stage 카드의 경로 규칙에 맞췄습니다. 생산자가 파일인지 디렉터리인지 모호하게 적은 조건은 적용하지 않습니다.
- 날짜나 글머리 기호를 붙인 적용 기록을 놓쳤습니다. 해당 기록과 잘못 적힌 참조를 인계 글에서 볼 수 있게 했습니다.
- ASCII 출력 환경에서 한국어 JSON이 실패했습니다. 세 CLI가 UTF-8로 출력하도록 하고 파이프 시험을 통과했습니다. 이것만으로 Windows 전체 호환을 주장하지 않습니다.

실패를 먼저 확인한 뒤 고쳤습니다. Distill의 마지막 한국어 출력 시험은 `UnicodeEncodeError`로 실패했습니다.
Stage의 경로·기록 시험은 세 메서드에서 일곱 번 실패했습니다. 뒤이은 리뷰에서는 아직 없는 경로와
파일을 디렉터리로 적은 예외를 놓치는 경우를 찾았습니다. 추가 시험에서 다섯 번 실패했고, 수정 뒤
집중 검사 18개를 통과했습니다. 마지막 독립 리뷰도 이 수정을 승인했습니다.
리뷰 원본과 Stage 전체 시험 로그는 [보존한 증거](evidence/2026-10-06-reviews/manifest.json)에 있습니다.

첫 시도는 시험 코드의 기대값이 틀려 멈췄습니다. v1을 적용한 카드에서 v2의 철회 상태까지 기대했습니다.
실제로는 v1의 `superseded`가 맞습니다. 제품은 바꾸지 않았습니다. 철회한 v2를 직접 조회하도록 검사 코드를

시험할 때만 훅을 끄고 읽기 도구만 허용했습니다. Distill의 자동 추출은 실행하지 않았습니다.
Codex에서도 [로컬 Avatar 0.1.0을 찾았습니다](evidence/2026-10-06-host-loading/codex-avatar-excerpt.json).
이는 사용 가능한 목록을 확인한 결과이며 설치하거나 스킬을 실행한 결과가 아닙니다.

실제 인계 기록이 없어서 완료 주장을 막았습니다. 10월 7일의 초기 검사는 종료 코드 0이었지만,
독립 리뷰가 누락을 찾아 검사를 강화했습니다. 원래 실행은 이제 종료 코드 1입니다. 실패 원본은 보존합니다.

[파일 검사기](check_host_result.py)는 받은 세션이 만든 함수를 직접 실행합니다. 앞선 파일의 digest,

잘못 구현하고 끝났다고 적은 사례, 앞선 파일을 바꾼 사례, 참조를 빼먹은 사례를 실패로 잡았습니다.

각 실패를 재현한 뒤 검사를 고쳤습니다. Avatar의 이력 참조 검사까지 포함해 테스트 10개를 통과했습니다.
원래 잘못된 판정과 재검사 결과를 모두 보존했습니다. AI를 다시 호출하지 않았고 합성 사례를 실제 실행 횟수에 넣지 않았습니다.

## 남은 검증과 제한

1. 실제 시험에서는 두 AI가 파일 해시를 자유로운 문장으로 적었습니다. Stage가 요구하는 JSON 형식이 아니어서
   인계 글은 증거가 없다고 표시했습니다. 첫 시험에서 Stage의 자동 대조가 성공했다고 주장하지 않습니다.
   후속 시험에는 문서에 적힌 JSON 형식을 전달했습니다. Stage가 여섯 인계 글에서 앞선 파일 해시를 `matches`로 대조했습니다.
2. 공개 CLI 사용법을 명시한 시험입니다. 설치 뒤 스킬을 자연스럽게 고르는 동작과 무인 드라이버까지 검증하지 않았습니다.
3. 재질문·중복 작업·비용이 줄었다고 주장하지 않습니다. 제품은 작업 브랜치에 커밋했으며 배포는 아직 하지 않았습니다.

완료를 막지 않는 리뷰 의견도 남아 있습니다. Distill의 일부 길이 오류 코드는 일반 입력 오류이며,
CLI와 MCP가 빈 참조 목록을 다루는 방식에 차이가 있습니다. Avatar의 선택 필터는 모든 종류의 기록을
한꺼번에 좁히지 않습니다. 과도하게 깊은 JSON과 SQLite 정수 범위를 넘는 입력도 별도 보강 후보입니다.
두 번째 시험은 정상 종료가 다섯 사례였습니다. 세 번째 시험에서는 여섯 사례 모두 정상 종료했고 전체 검사도 통과했습니다.
W-00000277의 독립 리뷰와 검사기 보완 확인을 마쳤고 제품 소스도 커밋했습니다. 작업별 회고와 카드 완료 절차가 남았습니다.
회고에는 검사기 누락, 시간 제한, 기록 절차를 묶은 결과를 나누어 기록합니다.
**SSOT·TDD·Honesty·Completion**을 적용합니다.
