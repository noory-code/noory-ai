# Avatar 화면 시안 다섯 가지

2026-10-09. 사용자가 “드래프트를 1개만 만들려고 하지만ㄹ고 여러개를 만들어서 보여주세요. 5개 정도?”라고 요청한 뒤 만든 로컬 화면입니다. 목적은 유형, 실제 대화, AI와 일한 방식을 어떤 순서로 보면 자신을 알아가는 경험이 되는지 비교하는 것입니다.

| 시안 | 첫눈에 보이는 것 | 기대하는 경험 | 살필 위험 |
|---|---|---|---|
| 거울 | 잠정적인 유형과 아바타 | 나에 관한 짧은 설명에서 출발 | 근거가 적은데도 성격을 확정한 듯 보일 수 있음 |
| 대화 지도 | 서로 다른 대화 장면 | 상황에 따라 부탁이 달라지는 모습을 따라 읽음 | 결과를 빨리 보고 싶은 사람에게 느릴 수 있음 |
| 작은 책 | 대화를 읽어 쓴 한 장 | 나에 관한 이야기를 다시 열어봄 | 기록에 없는 동기나 사건 순서를 넣기 쉬움 |
| 대화 코치 | 사용자 요청, AI 누락, 모르는 결과 | 다음 대화에서 한 가지를 시험해 봄 | AI의 잘못을 사용자 점수로 돌리기 쉬움 |
| 자라는 아바타 | 기록이 없을 때의 첫 만남 | 기록을 고른 뒤 조금씩 알아감 | 기록을 많이 내도록 재촉할 수 있음 |

첫 네 시안은 가상 인물 K의 K1·K2·K4를 사용합니다. K1은 아이디어 다섯 가지를 요청한 요약이고, K2는 아이디어 하나를 고른 뒤 범위를 지켜 달라는 발언입니다. K4에서는 AI가 조건 하나를 놓쳐 K가 두 조건을 다시 요청했습니다. 세 기록의 순서와 K4 이후 결과는 알 수 없습니다. 화면에서도 이 한계를 밝힙니다. 다섯째 시안은 기록이 없는 상태와 같은 가상 기록을 읽은 뒤의 상태를 전환해 봅니다.

시안은 `avatar/web/drafts.html`에서 열 수 있습니다. 정적 공개 미리보기에서는 `http://127.0.0.1:4174/drafts.html`입니다. 개인 기록을 받거나 분석하지 않습니다. 유형은 성격 진단이 아니며 점수도 계산하지 않습니다. 실제 대화 분석, 사용자 만족도, 광고 수익은 이 화면으로 검증되지 않습니다.

검증: Python 제품 검사 47개, 플러그인 계약 검사 7개, Node 검사 25개와 `git diff --check`가 통과했습니다. 브라우저에서 시안 다섯 개의 표시, 390px 화면의 가로 넘침 없음, 근거 열기, 다섯째 시안의 상태 전환을 확인했습니다. 브라우저 오류·경고는 없었습니다. 처음 쓴 “아이디어를 다섯 가지 받아본 뒤”와 “이후 한 가지를 고르고”는 자료가 보장하지 않는 순서를 암시해 지웠습니다. 수정한 화면에서 새 문구를 확인했습니다. 로컬 GET 요청은 200을 반환했습니다.

다음 판단: 사용자가 다섯 안 가운데 어느 시작 방식에서 자신을 가장 잘 이해하는지 확인합니다. 고른 안을 실제 개인 기록 흐름에 연결할 때는 기록 선택, 해석 수정, 전송 범위를 따로 검토합니다.
