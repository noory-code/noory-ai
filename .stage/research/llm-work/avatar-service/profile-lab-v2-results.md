# 분석 지침을 고친 두 번째 실행

2026-10-07. 첫 실험에서 발견한 오류를 고치는 중입니다.

## Changed

제목은 관찰한 차이를 말하도록 했습니다. 요청한 말투와 실제 말투를 구별하고, 주어가 바뀌면 문장을 나누도록 적었습니다.
모르는 사건 순서와 원인을 덧붙이지 않게 했습니다. 한국어는 영어 단어를 바꾸는 데 그치지 않고 동작을 풀어 쓰도록 했습니다.
지침은 `profile-lab-prompt-v2.txt`에 보관했습니다.

빈 문자열이 아닌 `placeholder`도 거절하도록 실행기를 고쳤습니다.
리뷰 실행기는 현재 편집 중인 자료 대신, 각 호출 때 보관한 입력과 지침을 읽습니다.
보관한 입력을 바꿨거나 같은 묶음에 서로 다른 자료가 들어가면 검토 호출 전에 멈춥니다.

## Runs

`2026-10-07-profile-lab-v2`에서 첫 한국어 카드 2개를 확인했습니다.
제목이 실제 부탁을 더 구체적으로 가리켰습니다. 그러나 migration을 “이전 작업”으로 옮겨 뜻이 모호한 문장은 남았습니다.
이어 실행한 영어 카드 1개는 제목의 70자 제한을 넘었습니다. 모델 호출은 성공했지만 검사는 실패했습니다.
이 실패를 그대로 남기고 실행을 중단했습니다.

원인을 보니 JSON 스키마는 제목에 240자를 허용하고, 지침과 검사만 70자로 제한하고 있었습니다.
스키마도 70자로 맞춘 뒤 `2026-10-07-profile-lab-v2b`에서 새로 실행했습니다.
새 묶음의 카드 16개는 생성과 형식 검사를 통과했습니다.

## Remaining failures

새 묶음의 첫 두 한국어 카드를 읽은 결과입니다. 전체 카드의 내용 검토는 아직 끝나지 않았습니다.

- `J-ko-1`은 “요청했다”, “말했다”처럼 반말로 관찰을 썼습니다. 높임말 지침을 따르지 않았습니다.
- 같은 카드가 “위험이 큰 이전 작업”이라는 모호한 번역을 썼고, 한 관찰에 서로 다른 상황 두 개를 합쳤습니다.
- `K-ko-1`은 다른 설명에서 “조건 요청이 길어진 이유”라고 했습니다. K4에는 요청의 길이를 비교할 자료가 없습니다.
- 제목을 사실에 가깝게 쓰려다가 “아이디어 요청, 범위 고정 요청…”처럼 명사를 나열하기도 했습니다.
- 해석을 조심스럽게 쓰라고 하자, 관찰을 반복한 뒤 “잠정적인 해석입니다”만 붙이는 결과도 나왔습니다.

따라서 지침을 늘려 문제가 해결됐다고 결론 내리지 않습니다.
원래 자료에 있는 사실을 보여주는 일과, 여러 사실을 연결해 해석하는 일을 나눠 시험할 이유가 생겼습니다.
다음에는 코드가 원문·발언자·상황을 보여주고, 모델은 근거를 연결하는 짧은 해석만 쓰는 안을 비교합니다.
처음 보는 한국어 자료에서도 확인해야 합니다. 이 안의 정확도와 비용은 아직 측정하지 않았습니다.

## Product preview

가상 대화 화면에는 검토한 문장을 직접 편집해 넣었습니다.
이는 자동 생성 결과를 검증 없이 제품에 붙인 것이 아니며, 일반 대화 분석기가 완성됐다는 뜻도 아닙니다.
관찰과 해석, 원문, 사용자가 고친 문장을 구별하는 경험을 시험합니다.

## Verification

연구 실행기 검사 3개가 실패한 뒤 통과했습니다.
기존 실패 응답의 `placeholder` 거절, 당시 보관한 입력 읽기, 바뀐 입력 거절을 확인합니다.
이 코드는 연구용이며 기존 제품의 AI 분석기는 아직 바꾸지 않았습니다.

## Principles

Honesty: 일부 제목이 좋아졌어도 남은 오류를 함께 기록합니다.
SSOT: 각 호출의 입력·지침·출력을 보존합니다.
AHA: 지침만 늘리지 않고 실패가 생기는 단계를 나눠 확인합니다.
Completion: 형식 통과와 내용 통과를 구별합니다.
