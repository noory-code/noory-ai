# 내가 고친 해석을 다시 여는 실험

2026-10-08. W-00000280·W-00000281. 가상 기록만 사용했습니다.

## Why

로컬 뷰어는 기록을 가져온 탭에서 메모를 남길 수 있었지만, 탭을 닫으면 메모가 사라졌습니다.
리포트는 읽을 수 있어도 뷰어에서 다시 이어갈 수는 없었습니다. 다시 열어볼 이유를 만들려면
내가 고친 내용이 다음 방문에도 보여야 합니다.

## What works

사용자는 리포트에서 이어보기 JSON 파일을 직접 내려받습니다. 저장 전에 원문, 외부 이력,
출처 경로, 기준 변경 이력, 가져온 파일의 추가 정보, 메모와 AI 해석이 담길 수 있다고 알립니다.
확인 체크박스를 눌러야 내려받을 수 있습니다. 다음에 파일을 직접 골라 작업을 다시 엽니다.
서버로 업로드하거나 자동으로 저장하지 않습니다. 원본 Avatar DB나 확인한 개인 기준도 바꾸지 않습니다.

파일 형식은 `avatar-session/1`입니다. 처음 가져온 기록의 출처를 파일 스스로 가상 예시라고
표시해도, 다시 열 때는 중립적인 ‘이어보기 파일’로 표시합니다. 기준은 저장 당시 모습일 수
있으므로 최신 여부는 Avatar에서 다시 확인해야 합니다.

## What we checked

- 새 검사 2개는 모듈이 없어 실패했고 구현 후 통과했습니다. 첫 통과 시도에는 검사 코드가
  반복 기준의 정렬 순서를 잘못 가정해 1개가 실패했습니다. 순서 가정을 고쳐 다시 통과했습니다.
- 출처 표시를 중립으로 바꾸기 전에는 새 검사에서 가상 예시로 읽히는 실패를 관측했습니다.
  수정 후 통과했습니다. 외부 이력과 추가 필드 보존을 확인하는 검사도 더했습니다.
- 최종 제품 검사 Python 47개, 플러그인 계약 7개, Node 25개로 총 79개가 통과했습니다.
  두 체크아웃의 `git diff --check`도 통과했습니다.
- Chrome에서 가상 선택 8개와 메모를 저장한 뒤 화면을 지우고 파일로 다시 열었습니다.
  선택 8개와 메모가 돌아왔습니다. HTML처럼 보이는 메모는 글자로만 표시됐습니다.
  다른 기준을 가리키는 메모가 든 파일은 거절했고, 기존 화면과 메모는 그대로 남았습니다.
- 가상 AI 해석과 수정 메모를 넣은 파일도 다시 열었습니다. 원문에 적은 HTML 문장이
  실제 요소가 되지 않았고, AI 해석과 메모가 화면과 리포트에 남았습니다.
- 가상 예시라고 주장하는 파일의 원문을 바꾼 뒤 다시 열었습니다. 화면과 리포트는
  예시라고 단정하지 않았습니다. 저장·다시 열기 중 새 네트워크 요청도 없었습니다.
- 390px 화면에서 안내, 체크박스, 대화상자의 가로 넘침을 확인했습니다. 콘솔 오류는 없었습니다.

Claude Opus의 첫 독립 검토는 REVISE였습니다. 내려받는 파일에 들어가는 외부 이력·출처·추가
필드를 안내하지 않았고, AI 해석이 있을 때 조사도 틀렸습니다. 화면과 README를 고쳤습니다.
마지막 검토는 두 수정과 위조된 예시 표시의 중립화를 PASS로 확인했습니다. 검토자는 테스트와
브라우저를 직접 실행하지 않았습니다. 첫 검토는 136.75초·정가 기준 0.6971274달러,
마지막 검토는 22.56초·0.124648달러를 CLI가 보고했습니다. 실제 청구액은 확인하지 않았습니다.
원문과 실행 기록은 `evidence/2026-10-08-avatar-resume-review/`와
`evidence/2026-10-08-avatar-resume-final/`에 있습니다. 마지막 검토 뒤 안내 문장을 더 자연스럽게
다듬었고 Chrome에서 다시 확인했습니다.

## Limits and next action

이어보기 파일은 개인 원문과 해석을 담을 수 있습니다. 사용자가 기기에서 보관하고 공유 전에
확인해야 합니다. 파일은 최대 8 MiB입니다. 다른 컴퓨터에서 자동으로 이어지지는 않습니다.
열어 둔 대화상자의 미완성 글과 공개 가상 이야기에서 고친 문장은 저장하지 않습니다.
일반 대화 파일을 분석해 Avatar 기록으로 바꾸는 기능도 아직 없습니다.

다음 연구는 명시적으로 고른 가상 대화 파일에서 발언자와 인용의 주인을 가려낼 수 있는지
시험하는 것입니다. 모델이 지어낸 정보는 개인 기준으로 만들지 않습니다. 기존 실험에서
발언자·인용 표시는 작성자가 미리 달아 주었습니다. 실제 대화 형식을 지원하려면 이 빈틈을
먼저 확인해야 합니다. 파일을 자동으로 탐색하거나 개인 DB를 읽지 않습니다.

Honesty: 가상 자료의 재개 동작을 확인한 결과와 일반 대화 지원을 구별합니다.
SSOT: 원본 선택과 개인 기준은 Avatar DB가 소유합니다.
Completion: 저장, 닫기, 다시 열기, 잘못된 파일 거부를 함께 확인합니다.
