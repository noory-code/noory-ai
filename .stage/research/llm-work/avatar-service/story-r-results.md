# 한국어 원문으로 읽는 세 번째 가상 인물

## Changes

R의 회의용 답변 요청과 휴대폰 알림용 요약 요청을 나란히 읽습니다. 동료가 늘 길게 말한다고 평가한 기록은 별도 장면에 둡니다. 실제 말 길이를 측정하지 않았으므로 성향으로 확정하지 않습니다.

한국어 원문은 언어를 바꾸어도 유지합니다. 영어 화면에서는 번역을 따로 표시합니다. J·K의 영어 원문과 한국어 요약도 유지합니다. 모델이 고른 관찰에서 출발했지만 화면의 제목·해석·번역은 직접 편집한 예시입니다. 새 기록을 자동 분석하는 기능이 아닙니다.

모바일에서 인물 선택지가 세 개로 늘자 글자가 잘게 줄바꿈됐습니다. 화면을 보고 세 개의 칸에 이름과 설명을 위아래로 배치했습니다. 작은 아바타는 선택지 위에 남겼습니다.

## Verification

- 새 인물과 원문 언어 검사 2개가 `Unknown fictional person`으로 실패한 뒤 통과했습니다. 기존 화면 검사 4개도 통과했습니다.
- 전체 제품 검사: Python 44개, 플러그인 계약 7개, Node 22개가 통과했습니다. 총 73개입니다.
- Chrome의 별도 가상 자료 탭에서 한국어·영어 × R의 장면 3개를 확인했습니다. 인물의 근거가 섞이지 않았습니다.
- 원문 문장, `lang=ko`, 영어 번역 표시를 DOM에서 확인했습니다. 한국어 화면에서는 원문을 중복 번역하지 않습니다.
- R의 수정이 J로 넘어가지 않았고, R의 같은 장면으로 돌아오면 복원됐습니다. 영어로 바꿔도 유지됐습니다.
- `<img src=x onerror=alert(1)> R 메모`는 문자로만 표시됐습니다. 새 이미지 요소는 생기지 않았습니다.
- 1280px에서 장면 6개에 가로 넘침이 없었습니다. 처음 `resize_page`는 기존 에뮬레이션을 바꾸지 못해 390px 검사가 아니었습니다. 이후 `emulate`로 실제 `innerWidth=390`을 확인하고 장면 6개를 다시 검사했습니다. 가로 넘침이 없었습니다.
- 모바일 화면의 실제 이미지를 확인하고 인물 선택지 배치를 고쳤습니다. 최종 390px 화면도 직접 확인했습니다.
- 새로고침 뒤 로컬 파일 요청 7개가 모두 200이었습니다. API·외부 요청과 콘솔 오류·경고는 관측되지 않았습니다.
- 원어민 사용성 평가나 실제 스크린리더 청취는 하지 않았습니다.

## Independent review

R의 내용·번역, 원문 언어 표시, 인물 분리를 대상으로 Claude에 소스 검토를 맡겼습니다. 기존 J·K 기능 전체를 다시 검토하도록 요구하지 않았습니다. 응답과 소스 스냅샷은 `evidence/2026-10-08-stories-r-review/`에 남깁니다. 모바일 CSS 수정은 감독 세션이 실제 화면에서 확인했습니다.

첫 판정은 REVISE였습니다. 한국어 관찰 문장에서 평가한 사람과 평가받은 사람이 뒤바뀌어 읽힐 수 있다는 지적을 받아들였습니다. R의 보고라는 점, 동료가 말한 사람이라는 점, R이 평가 대상이라는 점을 모두 밝혔습니다. “평소에도”의 불필요한 전제도 “평소에”로 고쳤습니다.

최종 검토는 이 두 수정을 확인하고 PASS를 반환했습니다. 원문은 `evidence/2026-10-08-stories-r-final/response.md`입니다. 첫 리뷰는 118.58초·정가 기준 $0.4828814, 마지막 확인은 8.11초·$0.0394792를 보고했습니다. 실제 청구액은 아닙니다. 검토자는 소스만 읽었고 브라우저와 검사는 감독 세션이 실행했습니다.

문구 수정 후 장면 검사 6개를 다시 통과했습니다. 브라우저에서도 고친 문장과 R3의 정확한 한국어 원문을 확인했습니다. 최종 1280px 화면에는 가로 넘침이 없었습니다. 두 체크아웃의 `git diff --check`와 Stage 감사도 통과했습니다. 감사에는 기존 WORK029 경고 32개만 남았습니다.
