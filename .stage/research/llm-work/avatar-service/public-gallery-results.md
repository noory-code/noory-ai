# 공개 가상 예시와 로컬 뷰어를 나눈 결과

2026-10-08. W-00000280·W-00000281. 이 결과는 로컬 시제품에서 확인한 범위만 다룹니다.

## What changed

가상 인물 J·K·R의 이야기를 정적 파일로 따로 만들었습니다. 공개용 묶음에는 개인 기록 가져오기,
AI 실행 코드, DB 읽기 기능이 없습니다. 한국어·영어로 로컬 뷰어 시작 방법을 설명합니다.
로컬 뷰어는 이전과 같이 직접 고른 기록을 읽고 가상 이야기의 해석을 수정할 수 있습니다.
공개 화면은 수정 기능을 제공하지 않습니다. 광고 스크립트도 넣지 않았습니다.

정적 파일을 만들 때 이미 있는 출력 폴더를 덮어쓰지 않습니다. 이번에 확인한 마지막 묶음은
`.stage/.runtime/avatar-public-v4/`입니다. 로컬 공개 예시는 `http://127.0.0.1:4174/`,
개인 기록 뷰어는 `http://127.0.0.1:4173/`에서 열었습니다.
이 주소는 해당 컴퓨터에서 서버가 실행 중일 때만 열립니다. 공개 배포 주소가 아닙니다.

## What passed

- 새 공개용 검사는 모듈이 없을 때 실패했습니다. 구현 후 3개가 통과했습니다. 공개 파일 목록,
  상대 경로 모듈, 두 HTML의 CSP, 기존 폴더 보호, 기록 API 거부를 확인합니다.
- 제품 전체 검사는 Python 47개, 플러그인 계약 7개, Node 22개로 총 76개가 통과했습니다.
  `git diff --check`도 통과했습니다.
- Chrome에서 가상 인물 3명 × 장면 3개 × 언어 2개, 총 18개 조합을 확인했습니다.
  390px에서는 입력창·수정 버튼·가로 넘침이 없었고, 공개 갤러리가 요청한 파일은 같은 출처의
  정적 파일 7개뿐이었습니다. 초기 화면에는 콘솔 메시지가 없었습니다.
- 시작 안내를 390px와 1280px에서 확인했습니다. 영어 링크가 영어 화면으로 이어졌고,
  처음 온 사람에게 소스가 아직 배포되지 않았다는 점을 표시했습니다. 안내 화면은 외부 요청을 하지 않았습니다.
- 로컬 주소 링크를 직접 누르자 새 탭이 열렸습니다. 새 탭에서 opener와 referrer가 비어 있었고,
  로컬 뷰어가 가상 기록으로 열렸습니다. 공개 페이지가 로컬 주소로 자동 접속하지는 않았습니다.
- 공개 화면에서 로컬 기록 API로 fetch를 시도했을 때 CSP가 요청을 막았습니다.
  이 고의적인 시험 뒤에 남은 콘솔 오류는 결함으로 세지 않습니다.
- 로컬 `/stories`에서는 수정 글이 HTML로 실행되지 않고, J와 K의 수정 내용이 섞이지 않았습니다.
  서버를 다시 켠 뒤 새 `text.mjs`도 정상으로 불러왔습니다.
- 영어 화면에서 로고를 누르면 한국어로 돌아가는 오류를 브라우저에서 재현했습니다.
  수정한 정적 묶음에서는 영어가 유지되는 것을 확인했습니다.

## Independent review

Claude Opus가 변경한 소스를 별도 CLI에서 검토하고 PASS를 반환했습니다.
검토자는 테스트와 브라우저를 직접 실행하지 않았습니다. 원문과 실행 기록은
`evidence/2026-10-08-public-gallery-review/`에 있습니다. 검토는 106.96초가 걸렸고,
CLI는 정가 기준 사용량 0.51802달러를 보고했습니다. 실제 청구액은 확인하지 않았습니다.

검토자는 처음에 받지 않은 두 파일 때문에 안내 문구와 공개용 문구 키를 조건부로 남겼습니다.
`app.mjs`의 ‘기록 가져오기’, `story-content.mjs`의 두 언어 `publicStart`·`publicMethod`를
직접 확인했습니다. 이후 로고 언어와 두 HTML의 CSP 검사도 보완했습니다.
전체 검사를 다시 실행했고, 최종 정적 묶음에서 로고 동작을 확인했습니다.
검토자가 최종 두 줄을 다시 읽었다고 주장하지 않습니다.

## Limits and next action

현재 개인 뷰어는 한국어이며, 소스를 가진 사람만 실행할 수 있습니다. 일반 대화 파일을
자동으로 읽지 않습니다. 실제 사용자의 기록·DB는 읽지 않았습니다. 광고 연결과 심사,
공개 호스팅, 수익 측정도 하지 않았습니다. `business-model.md`의 단가와 비용은 가정입니다.

다음에는 로컬에서 고친 해석과 메모를 사용자가 직접 파일로 저장한 뒤 다시 열 수 있는지
가상 자료로 확인합니다. 저장 파일에 원문이 담길 수 있음을 화면에 보여줘야 합니다.
개인 규칙이나 원본 DB에는 자동으로 반영하지 않습니다.

Honesty: 테스트 결과와 시제품 밖의 주장을 구별합니다.
SSOT: 코드와 실행 기록을 각각 소유한 위치에 둡니다.
Completion: 공개 이야기, 시작 안내, 로컬 뷰어까지 브라우저에서 확인합니다.
