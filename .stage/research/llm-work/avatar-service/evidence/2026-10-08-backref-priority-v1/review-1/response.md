## 검토 결론
제공된 기록 안에서는 24/24, 실행 시간, 비용이 모두 맞습니다. 다만 이 결과는 고정 자료 하나에서 개선을 시사할 뿐, 개선을 입증하지는 않습니다. 저는 코드를 실행하거나 모델을 호출하지 않았고, 주신 기록만 대조했습니다.

**1. 원시 라벨 24개, gold, summary 대조**
- 8개 run 모두에서 `structured_output`, `result` 문자열, `model_labels`, summary의 `rows`가 서로 같습니다.
- A 4회: Z1은 `user_report`/none, Z2는 `user_task_constraint`/none, Z3는 `request_apply_constraint`/Z1. 사전등록 gold와 같습니다.
- B 4회: Z2는 `user_report`/none, Z1은 `user_task_constraint`/none, Z3는 `request_apply_constraint`/Z2. 역시 gold와 같습니다.
- 불일치 0건, 실패한 run 0건입니다.

**2. A·B 자료 일치 여부**
- 세 문장의 한국어 원문과 순서는 A와 B에서 같습니다.
- 바뀐 것은 다음뿐입니다.
  - 메시지 ID: Z-m1과 Z-m2
  - target ID: Z1과 Z2
  - Z3의 기대 참조: A는 Z1, B는 Z2
- Z3와 Z-m3는 그대로입니다.
- `input_sha256`도 같은 케이스 안에서는 4회 모두 같고, A와 B 사이에서만 다릅니다. ID 맞바꿈과 들어맞습니다.

**3. 실행 시간과 정가 비용**
- 실행 시간: 4.33 + 3.88 + 11.48 + 3.48 + 13.17 + 3.9 + 3.97 + 4.1 = **48.31초**로 summary와 같습니다.
  - 각 run의 시작·종료 시각 차이와도 맞습니다.
  - 다만 이 값은 CLI 실행 전체의 소요 시간입니다. 모델 응답 시간만 잰 것이 아니므로, 11.48초와 13.17초가 튄 원인은 기록만으로 알 수 없습니다.
- 비용: A 합계 0.0499012, B 합계 0.049842, 전체 **0.0997432 USD**로 summary와 같습니다.
  - 각 run의 `costUSD`, `total_cost_usd`, `reported_list_cost_usd`가 서로 같습니다.
  - 모두 `costBasis: "list"`(정가 기준)입니다.

**4. 모델이 고른 값과 코드가 정한 값**
- **모델이 고른 값:** `id`, `act`, `constraint_ref` 세 가지뿐입니다.
- **코드가 정한 값:** `case_id`, `message_id`, `exact_text`, `confirmed_personal_rule: false`, `status`, `input_sha256`, `fixed_gold_comparison`, `seconds`.
- `accepted_structure` 상태는 두 가지를 코드가 검사했다는 뜻입니다. 참조 대상이 앞쪽 문구인지, 그리고 조건 유형인지입니다.
- summary는 병합 후 파일인 `result.json`으로 채점합니다. 병합할 때 act와 참조값을 그대로 복사하므로 원시 모델 출력으로 채점한 결과와 같습니다.

**5. 고친 지침 평가**
- **해결한 부분:** "앞 문구에 의존하면 `request_apply_constraint`를 우선한다"는 규칙이 지난번 충돌을 직접 다룹니다. 지난번 충돌은 "순서"라는 말이 들어 있다는 이유로 Z3를 직접 조건으로 분류한 것이었습니다. 반대 방향의 실수도 이번에는 없었습니다. 부록 문구는 8회 모두 직접 조건으로 남았습니다.
- **새로 생긴 애매한 경계 두 가지:** 둘 다 "의존한다"가 정의되지 않은 데서 나옵니다.
  1. 기존 조항 "`user_report`는 사용자가 명시적으로 적용을 요청할 때만 참조 대상이 된다"가 그대로 남아 있습니다. 그런데 Z3("제가 읽는 순서로")는 Z1을 암묵적으로만 가리키고, gold도 이것을 Z1 참조로 인정합니다. 새 우선순위 규칙과 이 조항이 서로 부딪힙니다.
  2. 조건 내용이 앞 문구에 의존하는데 가리킬 target 문구가 없거나, 대상이 target이 아닌 문장에 있는 경우가 있습니다. 이 경우는 직접 조건도 아니고 참조할 대상도 없어서 어느 분류에도 깔끔하게 들어가지 않습니다.

**6. 지난 결과 보존**
