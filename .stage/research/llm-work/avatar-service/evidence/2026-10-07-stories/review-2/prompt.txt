1: # Avatar
2: 
3: Avatar is a local CLI and host skill for reviewing explicitly recorded choices and
4: user-confirmed personal criteria. It keeps quoted reasons, provenance, versions, revocations, and
5: read-only Distill history projections in SQLite.
6: 
7: Avatar does not collect conversations automatically, infer personality, authenticate speakers, or
8: promote project exceptions into personal criteria. It works without Stage or Distill.
9: 
10: ## Requirements
11: 
12: - Python 3.9 or newer
13: - No third-party packages
14: 
15: The default database is `~/.avatar/avatar.db`. Override it with `--home <directory>` or the
16: `AVATAR_HOME` environment variable. The database stays outside the plugin installation cache.
17: 
18: ## Commands
19: 
20: Run commands from this repository with `python3 avatar/scripts/avatar.py`. From an installed host
21: plugin, resolve `scripts/avatar.py` from the plugin root.
22: 
23: ```text
24: avatar choice add --idempotency-key <key> --payload-file <json>
25: avatar criterion propose --idempotency-key <key> --payload-file <json>
26: avatar criterion confirm <PC-id> --version <N> --idempotency-key <key> --payload-file <json>
27: avatar criterion revise <PC-id> --idempotency-key <key> --payload-file <json>
28: avatar criterion revoke <PC-id> --idempotency-key <key> --payload-file <json>
29: avatar source attach --idempotency-key <key> --file <distill-history.json>
30: avatar show [--choice <CH-id> | --criterion <PC-id>] [--json]
31: avatar export
32: avatar check --refs <avatar-ref,...>
33: ```
34: 
35: All mutating commands require an idempotency key. Replaying the same request returns the original
36: result with `replayed: true`. Reusing the key for different content returns
37: `E_IDEMPOTENCY_CONFLICT` and writes nothing.
38: 
39: Confirmation creates a new immutable version and returns its ref. For example, confirming
40: proposal `@1` returns confirmed version `@2`. Use the returned ref. Revision creates a new
41: unconfirmed proposal; it does not reuse the earlier user's confirmation as its source.
42: 
43: ## Data boundaries
44: 
45: - `CH-` records belong to Avatar and describe one explicit choice.
46: - `PC-` records belong to Avatar and describe versioned personal criteria.
47: - Distill `CR-` history is stored as a read-only projection. `show` labels it historical and does
48:   not claim that it is current.
49: - `export` emits `criteria-snapshot/1` with `scope: personal`. It includes only the current
50:   `user_confirmed` versions.
51: - `check` returns `eligible_current`, `proposed`, `superseded`, `revoked`, `scope_mismatch`, or
52:   `unknown`. Consumers must apply only `eligible_current` refs.
53: 
54: ## Local web preview
55: 
56: Run `python3 avatar/scripts/avatar_web.py` from the repository root, then open
57: `http://127.0.0.1:4173`. The first screen uses clearly marked fictional records.
58: Import a file created with `python3 avatar/scripts/avatar.py show --json > avatar-records.json`.
59: Files are processed in the browser tab. Import alone does not upload them. The preview does not persist imported
60: records or reflection notes; download the report before closing or refreshing the tab.
61: 
62: To explicitly connect a local store, start the viewer with `--home <avatar-directory>` and click
63: the local-record button. The server reads that store only after the request. It never writes records.
64: Without `--home`, local-store access is disabled, including the default `~/.avatar` store.
65: 
66: The preview summarizes linked criteria, differing choices, and wording revisions deterministically.
67: It does not infer fixed personality traits or validate psychological constructs. Imported
68: criteria reflect the file's capture time; use the CLI `check` before relying on them for a decision.
69: Limits: 8 MiB per imported file and 2,000 choices or criteria. External history projections are not
70: treated as current criteria. Reports include private source text, so review them before sharing.
71: 
72: To enable optional AI reflection, install and sign in to Claude Code CLI, then start with
73: `python3 avatar/scripts/avatar_web.py --ai claude`. Select 1–60 records in the viewer, inspect the
74: exact payload, and confirm before sending. Questions, choices, quoted reasons, project names,
75: conditions, and referenced criterion versions go to Claude using the signed-in account's usage.
76: Origin paths and unrelated record metadata are excluded. Imported criteria are marked with their
77: confirmation, current-version, and revocation status; they are not silently adopted.
78: 
79: The CLI runs Sonnet without tools, skills, MCP servers, or saved sessions. Each interpretation cites
80: supplied choice IDs and includes an alternative explanation. Unknown evidence IDs fail validation.
81: This checks references, not whether an interpretation is correct. Users can add corrections to the
82: downloaded report; these notes do not update the underlying criteria. No analysis runs on page load.
83: AI requests are limited to one at a time and a 90-second timeout. The browser accepts up to 55,000
84: JavaScript string units in serialized input; the server separately limits its JSON representation
85: to 60,000 characters. Individual input text fields are limited to 20,000 characters.
86: 
87: Working-style downloads are user-selected experiments. Public articles are attributed and adapted;
88: they are not the authors' own AI configurations or endorsements. Downloads do not install themselves
89: or overwrite project instructions. Attach the file to the intended AI conversation and state its scope.
90: 
91: This localhost preview has no accounts, payments, or public deployment. Do not expose this stdlib
92: development server through a public proxy. The Korean UI is a first product preview.
93: 
94: ### Fictional conversation preview
95: 
96: Open `http://127.0.0.1:4173/stories` to read two fictional people in Korean or English.
97: The records and interpretations are edited examples, not a live conversation-analysis feature.
98: Read three scenes, inspect the source text and context, compare interpretations across scenes,
99: and edit an interpretation. Reading order does not establish when the conversations occurred.
100: Edits and unfinished drafts stay in memory, separately for each person and scene. Reloading clears them. The page has
101: no AI calls, uploads, analytics, or ad scripts. Its entry link opens a new tab to preserve records
102: already imported in the main viewer. The rest of the viewer remains in Korean.
