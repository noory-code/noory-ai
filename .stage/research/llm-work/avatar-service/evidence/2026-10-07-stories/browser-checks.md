# 브라우저 확인

2026-10-07. Chrome DevTools로 `http://127.0.0.1:4173/stories`를 확인했습니다.
모든 입력은 가상 자료와 시험용 문장입니다.

- J의 세 번째 장면까지 읽었습니다. 인물을 K로 바꾸면 첫 장면으로 돌아가며 J의 수정 문장이 보이지 않았습니다.
- J의 세 번째 장면으로 돌아가면 그 장면의 수정 문장이 유지됐습니다.
- `<img src=x onerror=alert(1)>`를 수정 문장에 넣었습니다. 글자로 표시됐고 이미지 요소가 생기지 않았습니다.
- 언어를 바꾸면 같은 장면의 같은 출처가 보였습니다. 수정 문장도 유지됐습니다.
- 수정 지우기를 누르면 처음 제안한 해석이 돌아왔습니다.
- 데스크톱에서 가로 넘침이 없었습니다.
- 390px 화면에서 인물 2명 × 언어 2가지 × 장면 3개의 조합 12개를 확인했습니다. 가로 넘침이 없었습니다.
- 추가한 비교 영역에서 J는 J2, K는 K1의 원문을 표시했습니다. 다른 인물의 출처는 섞이지 않았습니다.
- 이 화면의 요청 7개는 모두 로컬 정적 파일 GET이었고 200을 반환했습니다. API·외부 요청은 관측되지 않았습니다.
- 콘솔 오류와 경고가 없었습니다.

화면을 직접 캡처해 데스크톱과 모바일 배치도 확인했습니다.
스크린샷을 이 폴더에 저장하려던 요청은 Chrome 도구의 경로 제한으로 거절됐습니다.
저장 경로를 지정하지 않고 도구가 반환한 이미지를 보았습니다. 이 폴더에 PNG가 저장됐다고 주장하지 않습니다.

이 검사는 현재 가상 예시 페이지에 한정합니다. 배포한 사이트의 네트워크나 실제 개인 분석 정확도를 확인한 결과는 아닙니다.

## Review repairs

독립 리뷰 뒤 다음 동작을 실제 브라우저에서 다시 확인했습니다.

- 저장하지 않은 메모가 언어 전환 뒤에도 남았습니다. 인물을 바꿔도 다른 인물에게 보이지 않았고 원래 장면에 돌아오면 다시 나타났습니다.
- 수정 중에 초기화하면 폼이 닫히고 수정 버튼에 초점이 돌아갔습니다.
- 이미 고른 인물을 다시 눌러도 읽던 장면을 유지했습니다.
- 나란히 보는 영역에 J1~J5, K1~K4의 각 원문과 상황이 표시됐습니다.
- 맨 아래에서 다음 장면으로 넘어가면 편지의 위쪽이 화면 위로 왔습니다.
- 진행 표시의 `role=img`와 `읽은 장면 3 / 3`이라는 이름을 확인했습니다. 실제 스크린리더 프로그램으로 읽힌 소리를 들은 것은 아닙니다.
- 비교와 근거를 펼친 채 390px에서 조합 12개를 다시 확인했습니다. 모두 가로 넘침이 없었습니다. 1280px에서도 확인했습니다.
- 기존 기록 화면의 링크를 눌렀습니다. 예시가 새 탭으로 열렸고 원래 탭의 URL은 그대로였습니다.

최종 수정 뒤, 첫 장면에 입력한 문장이 세 번째 장면의 비교 영역에 표시됐습니다.
“내가 고쳐 쓴 해석” 라벨과 “처음 제안한 해석 보기”가 함께 나왔습니다.
수정 문장에 넣은 HTML은 비교 영역에서도 글자로 표시됐습니다. 언어 전환 버튼의 `lang`도 확인했습니다.
