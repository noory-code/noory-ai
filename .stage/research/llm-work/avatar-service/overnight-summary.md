## 연구에서 확인한 것

첫 가상 인물 J·K 카드 16개는 형식 검사를 통과했지만, 사건 순서·
동기·말투를 잘못 표현했습니다. Claude의 독립 검토를 받아 원인을
기록했습니다. 원문과 발언자를 코드로 보존한 뒤에도 모델의 해석에는
없는 이유와 횟수가 끼어들었습니다. R의 화면은 이런 문제를 검토한
뒤 직접 편집한 가상 예시입니다.

추가로 사용자가 직접 말한 조건, 다른 사람의 말을 옮긴 문구, 앞의
조건을 다시 적용하라는 부탁을 구별하는 실험을 했습니다. 지난
ID 교환 시험은 고정 판정 12개 중 11개가 맞았습니다. 앞 조건 우선
지침으로 같은 자료를 다시 돌렸을 때 24개가 맞았지만, 처음 보는
가상 사례 C·D에서는 두 지침이 모두 24개를 맞혔습니다. 참조 ID를
확정해야 하는 E·F에서도 두 지침이 모두 16개를 맞혔습니다.
따라서 새 지침의 일반적인 이득은 확인되지 않았습니다. 일반 대화의
발언자와 인용 범위를 자동으로 가르는 기능도 아직 없습니다.

원본과 한계는 `profile-lab-results.md`, `split-lab-results.md`,
`comparison-lab-results.md`, `id-swap-results.md`,

## 남은 판단

- 개인 대화 파일을 사용자가 골라 가져올 수 있게 할지, 그러려면
  발언자·인용·상황을 어느 수준까지 확인해야 할지 결정해야 합니다.
- 개인 분석을 사용자의 기기와 기존 AI 계정에서 실행하는 구성이
  설치 부담을 감수할 만큼 쓸모 있는지 실제 사용자와 확인해야 합니다.
  운영자가 업무 원문과 개인 해석을 모으지 않는 원칙은 유지합니다.
- 공개 예시가 다시 방문할 만큼 가치 있는지 확인해야 합니다. 광고
  계정·단가·방문량·승인은 모두 미검증입니다.
- 가상 자료의 통과를 실제 분석 정확도로 설명하지 않습니다.
  사용자 확인 전에는 AI의 추론을 개인 규칙으로 적용하지 않습니다.
