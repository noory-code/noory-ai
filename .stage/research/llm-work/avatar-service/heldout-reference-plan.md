# 처음 보는 가상 문구에서 두 지침 비교

2026-10-08. W-00000280. 지난 지침을 바꾸는 데 쓴 A·B 문장은 다시
쓰지 않습니다. `heldout-reference-fixture.json`의 C·D와 판정은 호출 전에
고정합니다. C는 앞의 자기 보고와 “결론”이 겹쳐도 마지막 부탁이
“결론부터”라는 조건을 스스로 말합니다. C3의 기대 판정은 직접 조건입니다.
D는 본인과 동료의 읽는 순서가 다릅니다. 마지막 부탁은 어느 사람을
뜻하는지 말하지 않습니다. D3는 앞 조건을 적용해 달라는 부탁이지만
참조 대상은 `unresolved`입니다.

지난 A·B 배치에 기록된 이전 지침과 현재의 앞 조건 우선 지침을 같은
가상 문구에 각각 두 번씩 실행합니다. 총 여덟 번의 호출에서 24개
문구를 채점합니다. 같은 문구의 지침만 바뀌었는지 실행 전에 검사합니다.
모델에는 기대 판정을 주지 않습니다. 도구와 개인 설정을 끈 Claude
Sonnet low를 씁니다. 실제 모델 버전·인자·결과·CLI 경과 시간·정가
기준 사용량을 기록합니다.

새 지침이 C3를 앞 문구 적용으로 바꾸거나 D3에서 특정 사람을 고르면
실패입니다. 이전 지침도 같은 판정을 낸다면 이번 자료만으로 새 지침의
우위를 주장하지 않습니다. 두 문구와 반복 횟수가 적고, 작성자가
지침을 알고 가상 사례를 만들었으므로 실제 대화 정확도를 추정하지
않습니다. 실제 대화나 개인 DB는 읽거나 보내지 않고, 개인 규칙도
만들지 않습니다.
