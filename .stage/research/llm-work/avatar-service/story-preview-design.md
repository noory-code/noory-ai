# 대화 한 장 더 읽기

## Purpose

가상 인물의 자료를 하나씩 더 읽으며 첫인상이 어떻게 달라지는지 체험합니다.
기록을 모은 수와 성격 점수 대신, 실제 부탁과 해석이 바뀌는 순간을 보여줍니다.
문장을 읽는 재미와 오해를 고칠 수 있다는 신뢰를 함께 시험합니다.

## Design

- 바탕 `#f5f1ff`, 글자 `#332a4e`, 종이 `#fffef9`, 민트 `#cae7d7`, 살구 `#f6d8bd`를 씁니다.
- 한국어는 기기의 한글 고딕체를 씁니다. 외부 폰트를 요청하지 않습니다.
- 왼쪽의 작은 아바타와 오른쪽의 펼친 편지가 한 장면을 이룹니다. 모바일에서는 아바타를 작게 줄입니다.
- 제목은 크게, 본문은 왼쪽에 맞춥니다. 가장 눈에 띄는 요소는 새 기록을 읽을 때 바뀌는 편지입니다.
- 기록은 실제 시간순이 아니라 아바타가 읽는 순서로 보여줍니다. 이 차이를 화면에 밝힙니다.
- 기존 시제품의 색과 캐릭터를 이어갑니다. 같은 크기의 요약 카드 여러 개를 나열하는 형태는 쓰지 않습니다.

## Interaction

1. 가상 인물 J·K를 고릅니다. 서로의 기록과 메모는 섞이지 않습니다.
2. 세 번에 걸쳐 기록을 더 읽습니다. 실제 발언, 설명용 요약, 해석을 구별합니다.
3. 근거를 펼쳐 영어 원문과 한국어로 풀어 쓴 내용을 봅니다.
4. 예시 해석을 직접 고쳐 씁니다. 이전 해석도 볼 수 있고 수정 내용을 지울 수 있습니다.
5. 한국어·영어를 바꿔도 같은 인물의 같은 장면을 봅니다.

메모는 탭의 메모리에만 남습니다. 원본과 개인 기준을 바꾸거나 서버에 보내지 않습니다.
화면의 문장은 고정한 가상 기록을 바탕으로 편집한 예시입니다. 방문할 때 AI를 부르지 않습니다.
일반 대화 가져오기 기능이 생긴 것처럼 설명하지 않습니다.

## Scope and checks

W-00000281의 로컬 예시 화면으로 구현합니다. 제품 변경은 기존 Avatar worktree 안에서 합니다.
인물 전환, 읽는 순서, 수정 내용 분리, 한국어·영어, 모바일 화면, 외부 요청 여부를 확인합니다.
개인 기록을 보는 기존 흐름도 유지되는지 확인합니다.

## Principles

Honesty: 고정한 가상 예시와 실제 분석을 구별합니다.
SSOT: 장면마다 연결한 원문을 보관합니다.
AHA: 동기화나 계정 없이 읽기와 수정 경험부터 만듭니다.
Completion: 코드 검사와 브라우저에서 보이는 모습을 함께 확인합니다.
