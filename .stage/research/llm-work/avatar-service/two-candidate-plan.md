# 조건 두 개 중 가리킨 것을 찾는 가상 실험

2026-10-08. W-00000280. 앞 실험은 각 부탁 앞에 조건이 하나뿐이었습니다.
이번에는 읽는 순서와 부록의 정리 순서를 함께 둡니다. 마지막 부탁이 말한
“제가 읽는 순서”는 가까운 부록 조건이 아니라 읽는 습관을 가리킵니다.

`two-candidate-fixture.json`의 Z와 ZR은 같은 가상 문장 세 개의 순서만
다릅니다. Z에서 읽는 습관 Z1은 첫 번째, 부록 조건 Z2는 두 번째입니다.
ZR에서는 이 순서를 뒤집습니다. 두 사례 모두 마지막 부탁 Z3은 Z1을
가리켜야 합니다. Z에서는 가까운 조건을 고르면 Z2가 나와 실패합니다.
ZR에서는 무조건 첫 조건을 고르면 Z2가 나와 실패합니다.

각 사례를 두 번씩 실행합니다. 총 네 번, 문구 12개입니다. Z1은 사용자의
자기 보고, Z2는 지금 일에 붙인 직접 조건, Z3은 앞의 읽는 순서를 이번
본문에 적용해 달라는 부탁으로 기대 판정을 먼저 고정합니다. 문장과 작성자
역할, 검사할 문구는 모델에 주지만 기대 판정은 주지 않습니다. 앞 실험과
같은 Sonnet low, 같은 분류 지침을 씁니다. 실제 CLI 인자도 실행 기록에
남깁니다.

형식이 틀리면 그 호출은 채점하지 못한 실패로 남깁니다. 형식이 맞으면 모델이
고른 종류와 참조를 기대값과 비교합니다. 네 번 모두 맞아도 실제 대화의
정확도를 입증하지 않습니다. 개인 기준을 만들지 않고 실제 대화나 DB를
읽지 않습니다. 정가 기준 사용량은 실제 청구액과 구별합니다.

Honesty: 후보를 실제로 고른 결과와 코드가 채운 값을 나눕니다.
SSOT: 기대 판정과 실행 원본을 각각 고정해 둡니다.
AHA: 후보의 순서만 바꿔 단순한 선택 규칙을 시험합니다.
