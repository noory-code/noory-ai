# Avatar 첫 체험 버전

2026-10-07. W-00000281.

## Purpose

Avatar에 쌓인 선택과 이유를 읽고 자신을 돌아봅니다. 닮고 싶은 작업 방식은 AI와 써볼 규칙으로 내려받습니다.

## Working experience

1. 예시 기록을 둘러보거나 Avatar에서 내보낸 JSON을 가져옵니다.
2. 자주 참조한 기준과 당시 이유, 달랐던 선택, 기준의 변경 이력을 봅니다.
3. 분석할 기록을 고르고 전송할 내용을 확인합니다. 동의하면 Claude가 읽습니다.
4. AI 해석과 다른 설명의 가능성을 읽습니다. 각 해석에서 근거가 된 선택을 엽니다.
5. 자신의 생각을 메모하고 리포트를 내려받습니다.
6. 개발자의 공개 글이나 Avatar 자체 원칙에서 작업 방식을 고릅니다. 규칙과 적용 범위를 확인하고 파일로 가져갑니다.

배지는 기록에서 확인할 수 있는 이력을 기념합니다. 성격을 점수로 매기지 않습니다.
예시 기록과 가져온 기록은 화면에 구별해서 표시합니다.

## Run

소스: `/Users/woogis/.codex/worktrees/avatar-service/noory-ai`의 `codex/avatar-service`.
로컬 주소: `http://127.0.0.1:4173/`.

```text
python3 avatar/scripts/avatar_web.py --ai claude
```

기본 실행에는 Python만 필요합니다. AI 분석에는 설치하고 로그인한 Claude CLI가 필요하며 해당 계정의 사용량을 씁니다.
개인 저장소를 읽으려면 `--home`으로 명시해야 합니다. 이번 검증에서는 실제 개인 저장소를 연결하지 않았습니다.

## Verification

- Avatar Python 검사 42개, 플러그인 계약 검사 7개, Node 검사 16개가 통과했습니다.
- 실제 Claude Sonnet으로 예시 기록 8개를 두 번 분석했습니다. 가짜 응답을 실제 분석 증거로 쓰지 않았습니다.
- 별도의 브라우저 검사는 응답을 가정해 메모 교체와 늦은 결과 처리를 확인했습니다. 이 검사는 실제 모델 호출 검사와 구별했습니다.
- 실제 CLI가 만든 임시 JSON, 깨진 JSON, HTML처럼 보이는 문구, 빈 기록을 각각 확인했습니다.
- 리포트와 규칙 파일을 내려받아 출처·메모·적용 범위를 확인했습니다.
- 390px·1280px 화면, 모달 닫기와 초점 복귀, 콘솔 오류를 확인했습니다.
- 독립 리뷰의 전체 원문, 실제 분석 리포트와 브라우저 검사 결과는 [검증 자료](evidence/2026-10-07-web/)에 있습니다.
- Claude Opus의 두 차례 수정 요청을 처리했고, 마지막 리뷰에서 남은 네 가지 지적의 수정 여부에 PASS를 받았습니다.

## Limits

첫 로컬 체험 버전입니다. 커밋·병합·공개 배포는 하지 않았습니다. 로그인 서비스와 결제도 없습니다.
가져온 기록·분석·메모는 탭에만 남습니다. 새로고침하기 전에 리포트를 내려받아야 합니다.
AI가 근거 ID를 정확히 가리키는지 검사하지만 해석이 옳다고 보증하지는 않습니다.
작업 방식 파일은 대화에 첨부해 사용할 수 있습니다. 자동으로 Claude·Codex 설정을 바꾸지 않습니다.
macOS에서 실행했습니다. Windows·Linux 실제 실행은 이번에 확인하지 않았습니다.
실제 기록으로 분석했을 때 도움이 되는지와 유료 리포트의 수요는 아직 검증하지 않았습니다.
