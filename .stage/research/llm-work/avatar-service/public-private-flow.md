# 공개 예시에서 내 기록까지

2026-10-08. W-00000280·W-00000281. 현재 시제품과 앞으로 정할 운영 방식을 구별합니다.

## What works now

공개할 파일에는 가상 이야기와 로컬 뷰어 안내만 담았습니다. 개인 기록을 여는 코드는 별도 로컬 뷰어에 둡니다.
이렇게 나누면 공개 화면에 광고를 붙이더라도 개인 기록이 있는 화면에 광고 스크립트를 넣을 필요가 없습니다.
다만 사용자가 로컬 뷰어를 준비해야 하므로 시작하기 어려워집니다. 현재는 소스와 Python이 필요합니다.

| 화면 | 하는 일 | 처리하는 자료 | 현재 상태 |
|---|---|---|---|
| 가상 이야기 | J·K·R의 기록과 해석을 한국어·영어로 읽습니다 | 직접 만든 가상 자료 | 정적 파일로 만들었고 로컬에서 확인했습니다 |
| 시작 안내 | 로컬 뷰어 실행과 JSON 가져오기를 설명합니다 | 개인 자료를 입력받지 않습니다 | 한국어·영어로 동작합니다 |
| 개인 기록 뷰어 | 명시적으로 기록한 선택·기준을 읽고 메모·리포트를 만듭니다 | 사용자가 고른 JSON 또는 명시한 로컬 DB | 한국어 시제품입니다 |
| 선택한 AI 분석 | 확인한 기록만 Claude CLI에 보냅니다 | 선택한 원문과 그에 연결된 기준 | 옵션으로 켜고 전송 전에 확인받습니다 |

일반 대화 파일을 자동으로 가져와 분석하는 기능은 아직 없습니다. 가상 이야기의 해석은 직접 편집한 문장입니다.
현재 운영자가 받는 개인 데이터용 서버는 없으며, 공개 배포·광고 연결도 하지 않았습니다.

## Data paths

1. 공개 파일 → 브라우저: 가상 예시만 읽습니다. 입력창과 파일 선택기를 제공하지 않습니다.
2. 안내 링크 → 로컬 뷰어: 사용자가 눌러야 새 탭을 엽니다. 로컬 서버가 켜져 있는지 자동으로 탐색하지 않습니다.
3. 선택한 파일 → 로컬 탭: 기록 가져오기는 AI 전송을 뜻하지 않습니다. `--home`으로 명시한 DB만 별도 요청 후 읽습니다.
4. 고른 기록 → 로컬 서버 → Claude: `--ai claude`로 켰을 때만 가능합니다. 보낼 내용을 보여주고 동의받습니다.
5. 분석과 메모 → 내려받은 리포트: 원문을 담을 수 있습니다. 사용자 확인 없이 개인 규칙이나 DB로 되돌려 쓰지 않습니다.

정적 파일을 만드는 명령은 정해진 파일 목록만 복사합니다. 기존 출력 폴더가 있으면 중단합니다.
DB나 개인 기록용 모듈을 담지 않고, 두 HTML에는 스크립트의 네트워크 연결을 막는 CSP를 넣습니다.
이는 현재 묶음에서 확인한 경계입니다. 미래의 호스팅 설정이나 추가한 광고 코드까지 보장하지 않습니다.

## What remains to decide

- **쉽게 시작하기:** 배포할 설치물이 없습니다. 웹에서 버튼 하나로 개인 기록을 읽을 수 있는 서비스라고 소개하면 안 됩니다.
- **다시 열기:** 가져온 기록과 수정 메모는 탭을 닫으면 사라집니다. Markdown 리포트는 저장할 수 있지만 작업 상태를 복원하지는 못합니다.
- **영어 사용자:** 공개 예시는 두 언어로 읽지만 개인 뷰어는 한국어만 제공합니다.
- **광고 위치:** 가상 콘텐츠에만 두는 안을 검토합니다. 설치 안내는 광고용 콘텐츠로 가정하지 않습니다. 실제 배치·심사·단가는 미정입니다.
- **비수집의 뜻:** 운영자가 업무 원문과 개인 분석을 받지 않는다는 목적을 지킵니다. Claude 전송과 호스팅·광고망의 기술 정보 처리는 별도로 설명해야 합니다.

2026-10-08에 작업 파일을 직접 저장하고 다시 여는 흐름을 가상 자료로 시험했습니다.
사용자는 원문과 이력이 담길 수 있음을 확인한 뒤 내려받습니다. 자세한 결과는 `resume-results.md`에 있습니다.
남은 큰 빈틈은 일반 대화를 Avatar 기록으로 바꾸는 경로입니다. 현재 입력은 Avatar의 명시적 선택·기준 기록입니다.
