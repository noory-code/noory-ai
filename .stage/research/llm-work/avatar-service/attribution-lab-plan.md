# 가상 대화에서 누구의 말인지 가리는 실험

2026-10-08. W-00000280. 이전 비교 실험은 발언자와 인용의 주인을 작성자가 미리 표시했습니다.
이번에는 사용자가 붙여 넣은 글이나 다른 사람의 인용을 자기 기준으로 읽지 않는지 봅니다.

## Input and scope

`attribution-fixtures.json`의 가상 사례 다섯 개를 사용합니다. 사례 안의 메시지 작성자는
실험 입력이 제공하지만, 문장 안에 인용된 말의 주인은 모델이 가립니다. 검사할 문장 범위도
입력에서 미리 지정합니다. 따라서 이번 실험은 **문장 추출 능력을 시험하지 않습니다**.
실제 Claude·Codex 대화 파일의 형식을 읽는 기능도 아닙니다.

모델에 전달하기 전에 코드가 작성자가 `assistant`나 `unknown`인 문장은 분류합니다.
`assistant`는 `assistant_content`, 작성자 미상은 `unknown`으로 둡니다. 이 두 경우에는
모델을 호출하지 않습니다. 작성자가 `user`인 문장의 대상 범위에만 Sonnet을 부릅니다.
모델은 `direct_request`, `direct_report`, `quoted_other` 가운데 하나를 고릅니다.
직접 말하거나 요청했다고 분류해도 확인한 개인 기준으로 올리지 않습니다.

## Fixed run

각 사례를 두 번씩 실행합니다. 모델을 부르는 사례 A·B·C·E는 8번 호출하고,
작성자 미상인 D는 두 번 모두 코드에서 판단을 보류합니다. 목표 범위는 전체 11개이고
두 번씩 22개를 판정합니다. 순서는 A·B·C·D·E를 한 번 돌고 다시 반복합니다.
모델은 Sonnet, low, 도구·커스터마이징·MCP를 끈 Claude CLI를 사용합니다.
결과에는 대상 ID와 분류만 받습니다. 코드가 원문의 목표 범위를 그대로 붙입니다.

아래 기대 판정은 호출 전에 고정하고 모델에게 보내지 않습니다.

| 대상 | 기대 판정 | 이유 |
|---|---|---|
| A1 | direct_request | 회의 자료에 넣을 내용을 직접 부탁했습니다 |
| A2 | quoted_other | 동료의 말을 인용했습니다 |
| A3 | direct_report | 말 길이를 잰 기록이 없다고 직접 말했습니다 |
| B1 | assistant_content | AI가 쓴 평가입니다 |
| B2 | direct_report | 본인이 한 말이 아니라고 직접 반박했습니다 |
| B3 | direct_request | 휴대폰 알림의 분량을 직접 부탁했습니다 |
| C1 | quoted_other | 외부 문서에서 복사한 명령입니다 |
| C2 | direct_request | 그 명령을 검토해 달라고 직접 부탁했습니다 |
| D1 | unknown | 문장 작성자를 알 수 없습니다 |
| E1 | quoted_other | AI가 요약했다고 전한 문장입니다. 원문은 없습니다 |
| E2 | direct_request | 실제로 말했는지 확인해 달라고 부탁했습니다 |

모델이 낸 대상 ID가 빠지거나 늘면 구조 실패로 기록하고 재시도하지 않습니다.
원문의 인용을 자기 말로 바꾸거나, AI가 쓴 평가를 개인 성향으로 삼으면 의미 실패입니다.
코드가 거절한 결과도 보관합니다. 형식 통과와 의미 일치를 따로 셉니다.
시간과 CLI가 보고한 정가 기준 사용량을 기록하지만 실제 청구액이나 운영비로 쓰지 않습니다.

## Limits and decision

작성자 역할은 실험 입력이 제공했습니다. 실제 파일에서는 그 역할의 신뢰성과 대화 소유자를
별도로 확인해야 합니다. 인용의 경계가 애매한 글에서 모델이 맞혀도 이를 보편적인 정확도로
말하지 않습니다. 목표 문장을 작성자가 먼저 골랐으므로 자동 수집 기능을 만들었다고 하지 않습니다.

이 결과가 좋아도 다음 단계는 별도로 결정합니다. Claude와 Codex가 내보내는 자료를
사용자가 명시적으로 고른 경우에만 읽고, 출처가 없으면 사용자 발언으로 채택하지 않는
입력 계약이 필요합니다. 실제 개인 파일이나 Avatar DB를 자동으로 탐색하지 않습니다.

Honesty: 제공한 작성자·대상 범위와 모델이 판정한 인용을 나누어 봅니다.
SSOT: 원문과 기대 판정은 고정한 가상 자료가 소유합니다.
AHA: 대화 파일 전체 파서보다 작은 출처 문제를 먼저 시험합니다.
