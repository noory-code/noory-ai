# 앞 조건을 가리키는 부탁의 분류 시험

2026-10-08. W-00000280. 지난 A·B 실험은 고정 판정 12개 중 11개가
일치했습니다. A의 두 번째 실행에서 “본문은 제가 읽는 순서로 보여 주세요”를
직접 조건으로 분류했습니다. 이 결과는 그대로 둡니다.

이번에는 조건의 내용을 앞 문구 없이는 알 수 없다면, 앞 문구를 적용하는
부탁으로 먼저 분류하도록 지침을 고칩니다. 반면 “부록은 시간 순서로 정리해
주세요”처럼 조건 자체를 직접 말한 경우는 직접 조건으로 분류합니다.
가상 자료 `id-swap-fixture.json`의 문장·ID·기대 판정은 바꾸지 않습니다.
A와 B의 문구와 순서가 같고 ID와 기대 참조만 맞바뀌었는지 호출 전에
검사합니다.

A와 B를 각각 네 번 실행합니다. 여덟 번의 호출에서 고정 문구 24개를
채점합니다. 예상대로라면 A의 마지막 문구는 Z1, B의 마지막 문구는 Z2를
가리킵니다. 부록 문구는 양쪽 모두 직접 조건으로 분류합니다. 출력 형식이
틀리거나 어느 문구든 기대 판정과 다르면 실패를 그대로 기록합니다.
모델에는 기대 판정을 주지 않습니다. 도구와 개인 설정을 끈 Claude Sonnet
low의 실제 호출 인자와 응답, CLI 실행 시간, 정가 기준 사용량을 남깁니다.

같은 가상 자료를 반복하므로 실행들은 독립 표본이 아닙니다. 고정 자료의
결과로 실제 사용자의 대화 분석 정확도나 지침 변경의 일반 효과를 주장하지
않습니다. 실제 대화와 개인 DB는 읽거나 보내지 않고, 개인 규칙도 만들지
않습니다.
