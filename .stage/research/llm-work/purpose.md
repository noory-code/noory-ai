# 연구 목적과 질문

## 사용자가 원한 것

2026-10-04 대화에서 사용자는 다음과 같이 설명했습니다.

> 지금 LLM 들이 일하는 방식을 뜯어보고 그걸 강화하는 방식을 찾는거에요.
> 제가 LLM 을 직접 설계하지는 못하겠지만 말이죠.

또한 다음과 같이 범위를 바로잡았습니다.

> 내가 하고 싶은 건 Jev 가 하는 디시전 API 를 만드는게 아니라 그걸 왜 만들었냐 라는 동기입니다.

이 연구는 AI가 일하는 방식의 전제를 검토합니다.
어떤 기능을 만들지는 조사와 실험에서 얻은 근거를 보고 정합니다.

## 실제로 사용할 AI

연구 결과를 받은 뒤 사용자는 사용할 수 있는 AI가 Claude와 Codex뿐이라고 알려 주셨습니다.
따라서 실제 실험과 개선은 이 두 환경 안에서 수행합니다.
모델 내부를 바꾸지 않고 입력, 자료 전달, 작업 기록, 도구와 완료 확인 방식을 살핍니다.
새 모델이나 별도 AI 서비스의 도입을 개선의 전제로 두지 않습니다.
다른 회사와 Jev를 조사한 자료는 설계를 참고할 근거로 보관합니다.

앞선 실험 280건은 Claude CLI로 실행했습니다.
이후 시제품 여섯 가지를 Claude와 Codex에서 총 96번 비교했습니다. [시제품 시험 결과](findings/2026-10-05-ideas-lab.md)
OpenAI Agents SDK의 소스를 읽은 결과를 Codex 제품의 구조나 실행 결과로 취급하지 않습니다.
비교에서는 Claude와 Codex 각각에서 기존 방식과 바꾼 방식을 대조합니다.
실제 업무에 적용할 때는 완료율과 재작업, 전체 소요 시간, 사용량을 보고 개선됐는지 판단합니다.
이번 시제품 시험만으로 실제 업무의 완료율이 높아졌다고 판단하지 않습니다.

## 가장 먼저 물을 질문

**사용자가 맡긴 일을 수행하려면 무엇이 꼭 필요하며, 현재 시스템은 그것을 위해 무엇을 추가로 수행하고 있나요?**

이 질문을 다음처럼 나눕니다.

| 질문 | 필요한 증거 |
|---|---|
| 지금 어떤 일을 수행하나요? | 입력, 선택한 행동, 출력, 실행 뒤 상태 |
| 왜 그 일을 수행하나요? | 사용자 요구, 프로그램 조건, 명시된 지침; 모델의 설명은 보조 자료 |
| 그 단계는 꼭 필요한가요? | 그 단계를 제외한 실행과의 비교 |
| 같은 일을 다시 수행하나요? | 같은 자료와 상태에서 반복된 호출; 캐시 정보는 별도로 기록 |
| 일을 잘게 나누면 나아지나요? | 나누기 전후의 전체 결과와 단계 사이에서 누락된 정보 |
| 다른 방식으로 수행할 수 있나요? | 규칙, 검색, 모델, 도구를 바꿨을 때의 비교 |
| 무엇을 잃고 무엇을 얻나요? | 품질, 지연, 비용, 재작업, 유지보수 부담 |

## 첫 판에서 다룬 범위

- 공개된 모델·에이전트 문서와 연구논문을 검토했습니다.
- 요청 해석부터 결과 전달까지 동작을 나눴습니다.
- 실제 프로그램의 절차와 분석을 위해 붙인 동작 이름을 구별했습니다.
- 이 대화의 한 사례를 분석했습니다.
- 반박할 수 있는 가설과 비교 실험을 작성했습니다.

모델 내부의 모든 계산을 알 수 있다고 전제하지 않습니다.
API 문서만으로 소비자용 앱의 전체 구조를 확정하지 않습니다.
이번에는 상용 모델 비교 호출, 모델 학습, 플러그인 변경을 수행하지 않았습니다.

## 알아내야 할 경계

- 모델이 할 수 없는 일인지, 필요한 정보를 못 받아서 못 한 일인지 구별합니다.
- 선택이 틀렸는지, 선택을 실행하는 프로그램이 잘못됐는지 구별합니다.
- 증거가 부족한지, 충분한 증거를 잘못 해석했는지 구별합니다.
- 대화에서 적응한 것인지, 외부 기록을 읽은 것인지, 가중치를 학습한 것인지 구별합니다.
- 한 번 좋아진 결과인지, 여러 조건에서도 유지되는 개선인지 구별합니다.

## 우리가 바꿀 수 있는 범위

현재 연구에서는 입력 구성, 도구 인터페이스, 외부 기억, 작업 순서, 검증과 재시도 방식을 우선 살핍니다.
처음에는 다른 모델 선택과 작은 모델의 추가 학습도 후보로 생각했습니다.
사용 환경이 정해졌으므로 이제 Claude와 Codex에서 바꿀 수 있는 방법을 우선합니다.
특정 방식이 필요하다는 결론을 먼저 정하지 않습니다.

## 첫 판을 읽고 할 수 있어야 하는 일

1. 주장에 어떤 출처가 있는지 찾아갑니다.
2. 하나의 작업을 작은 동작으로 표시합니다.
3. 관찰한 사실과 아직 검증하지 않은 설명을 구별합니다.
4. 후보 하나를 골라 같은 조건에서 비교할 실험을 정합니다.
