# 남은 연구를 판단하는 기준

사용자는 남은 다섯 가지와 진행 순서를 확인한 뒤 계속하자고 동의했습니다.
먼저 목표와 검사를 맞추고, 낡은 정보·근거 선택·판단 기준·판단 재사용·실제 작업 인계를 확인합니다.
이 계획을 작성할 때는 Avatar / Clone 구현을 보류했습니다.
이후 사용자가 Stage·Distill·Avatar 구현을 요청했습니다. 현재 진행은 [구현 작업 묶음](../../work/current/W-00000272/_epic.md)에서 확인합니다.

## 이번에 확인할 범위

| 질문 | 이번에 얻을 근거 | 이 근거만으로 주장하지 않을 것 |
|---|---|---|
| 목적과 완료 검사가 같은 일을 요구하나요? | 기존 결함 두 개의 전체 검사를 수정 전·후에 실행하고, 요구한 API를 카드에 모두 적습니다. | 테스트 통과가 요구사항 전체를 빠짐없이 증명한다는 주장 |
| 관찰한 상태를 언제 다시 확인해야 하나요? | 인계 때 읽은 파일임을 표시하고 실제 CLI가 어떻게 사용하는지 기록합니다. | 자료를 만들었다는 이유만으로 AI가 읽고 적용했다고 보는 주장 |
| 필요한 근거를 스스로 찾나요? | Stage 카드에서 대상 소스와 전체 테스트를 찾아 수정을 끝내는지 확인합니다. | 자유 문서의 예외와 의존 관계까지 자동으로 완전하게 찾는다는 주장 |
| 프로젝트 기준을 새 상황에 적용하나요? | 합성 기록에서 각 AI가 기준을 뽑고 별도 상황 여섯 개에서 원문과 비교합니다. | 사용자의 개인적인 기준을 배웠거나 실제 재지시가 줄었다는 주장 |
| 실무에서 재사용할 판단이 얼마나 있나요? | 현재 보존된 실제 로그와 판정 파일에서 입력·기준·근거를 대조할 수 있는지 조사합니다. | 리뷰 제목 수를 호출 수나 재사용 가능한 비율로 바꾸는 주장 |
| 실제 작업을 다른 AI가 끝내나요? | 앞선 AI가 남긴 수정을 실제 CLI 파일 도구로 이어받고 독립 검증합니다. | 모든 Stage 훅·드라이버·리뷰·회고·승격까지 검증했다는 주장 |

실험 방법은 [실행 계획](experiments/stage-followup/README.md)에 고정했습니다.
첫 AI의 기존 수정을 재사용하고 이어받기 여덟 번을 비교합니다.
기준 추출은 두 번, 기준 적용은 24번입니다. 두 실험의 모델 호출은 겹치지 않습니다.

## 결과를 어떻게 판단하나요

- **적용 후보:** 해당 범위의 동작이 확인됐고, 실제 사용 경로에서도 얻을 이점과 비용을 설명할 수 있습니다. 제품 적용의 승인은 별개입니다.
- **보류:** 효과를 재는 데 필요한 자료가 없거나, 다음 실행에서 확인해야 할 조건이 남았습니다.
- **기각:** 시험한 방식이 목적을 충족하지 못하거나, 기록·검색·재검사 비용을 합치면 이점이 사라집니다.

한 조건을 한 번 비교한 시간 차이를 안정적인 성능 향상으로 보지 않습니다.
입력 토큰과 도구 호출 수는 작업 품질·완료율과 함께 봅니다.
효과가 없다고 나온 후보도 그대로 보고하며, 점수를 올리려고 문제나 원본을 바꾸지 않습니다.

## 아직 운영 검증으로 남는 것

실제 사용 중 반복되는 판단의 비율은 그 시점의 입력과 근거가 남아야 계산할 수 있습니다.
과거 로그에 그 정보가 없으면 사후에 만들어 넣지 않습니다.
필요한 기록 항목을 제안하되 제품에 수집 기능을 넣거나 장기 측정을 시작한 것으로 보고하지 않습니다.

Stage의 모든 실행 경로를 검증하려면 드라이버와 독립 리뷰, 작업 종료까지 연결해야 합니다.
이번 임시 프로젝트의 코드 수정 완료와 Stage 작업 카드의 공식 종료를 구별합니다.
효과를 확인하지 못한 범위는 최종 판단에서 보류하고 후속 조건을 남깁니다.

## 현재 진행 상태

[업데이트 후 실행](findings/2026-10-05-stage-after-update.md)에서 남은 비교 16번을 마쳤습니다.
기준 적용은 두 호스트에서 총 24번이며 모두 기대 답과 일치했습니다.
관찰 시점 비교 12번과 실제 인계 여덟 조건의 결과도 확보했습니다.
출처 단위를 명시한 Codex 추출은 원래 요청과 구별합니다. 앞선 서버 오류와 형식 검사 실패는 그대로 보존했습니다.

관찰 파일을 제공한 네 실행 모두 해당 파일을 열지 않았습니다.
짧은 기록에서 기준을 추출해도 판단은 같고 입력이 늘었습니다.
작업 카드를 사용한 실제 인계는 여덟 조건에서 수정과 전체 검사를 마쳤습니다.

이제 남은 연구는 Stage 전체 운영 검증과 실무 재사용률 관측입니다.
완료한 비교와 아직 확인하지 않은 운영 효과를 구별하며 연구 전체를 완료했다고 표시하지 않습니다.
