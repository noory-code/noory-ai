# 코드 리뷰에 전달할 자료를 좁혀 봅니다

## 실행 전에 정한 목적

필요한 자료를 고르는 비용까지 포함해도 입력·보고 금액·시간이 줄고, 명시한 동작의 판정이 유지되는지 확인합니다.
사용자는 비용 보고서를 읽고 “네 계속 해보세요”라고 답했습니다.

## 과제와 조건

앞선 [판정 재사용 시험](../review-reuse/README.md)의 실제 결함 두 개를 다시 사용합니다.
마일스톤 기준 여러 개를 보존하는 동작과 회고 번호가 다른 작업에 속할 때의 처리입니다.
과거 수정 전후 코드를 고정된 회귀 테스트로 다시 확인합니다.
이전에 사용한 과제이므로 새로운 과제에서 일반화한 결과로 보고하지 않습니다.

| 조건 | 전달할 자료 |
|---|---|
| full | 대상 파일의 전체 본문 |
| selected | 지정한 함수와 같은 파일에서 참조하는 함수, 모듈 수준의 문장 |

선택은 Python AST로 수행합니다. 모델로 요약하지 않고 원문 줄을 그대로 가져옵니다.
마일스톤 명령은 `main`, 회고 처리는 `write_driver_retrospective`를 시작점으로 지정합니다.
시작점은 연구자가 과제에서 읽어 지정했습니다. AI가 자동으로 관련 함수를 찾았다는 주장은 하지 않습니다.
참조 관계를 따라가다 모든 함수가 필요해지면 원문 전체를 반환합니다.
시작점 누락, 문법 오류, 중복 함수 이름, 함수 데코레이터, 명시한 동적 조회 구문에서는 전체 본문으로 돌아갑니다.
입력 파일이 아예 없으면 두 조건 모두 없는 상태를 전달하고 모델이 불확실하다고 답하는지 확인합니다.

정적 참조만으로 Python의 모든 실행 경로를 증명하지는 못합니다.
외부 모듈과 템플릿은 앞선 실험과 같은 정상 환경을 가정합니다.
이 한계가 있는 상태에서 일반 코드 리뷰 도구에 바로 적용하지 않습니다.

## 완료 기준

- 로컬 검사에서 선택한 코드의 함수 호출 결과가 원문과 같고, 참조한 함수·전역값을 빠뜨리지 않습니다.
- 수정 전후 두 상태와 자료가 없는 상태의 응답을 전부 보존합니다.
- 같은 호스트·과제·반복 안에서 시간·입력·캐시·금액을 비교합니다.
- 판정이 달라지면 그대로 실패 사례로 남깁니다. 맞힐 때까지 호출하지 않습니다.
- 자료 선택 시간과 CLI 시간, 저장 시간을 따로 기록합니다.

## 호출 계획

정상 입력은 결함 두 개 × 수정 전후 두 상태 × 조건 두 개 × 호스트 두 개 × 반복 두 번으로 **32번** 호출합니다.
회고 처리 파일을 통째로 뺀 입력도 조건 두 개 × 호스트 두 개로 **4번** 호출합니다.
합계 **36번**입니다. 독립적인 결함은 두 개입니다.

같은 과제·호스트·반복의 두 조건을 연달아 실행하고 선후 순서를 교대로 바꿉니다.
호스트별로 한 호출만 진행합니다. 두 호스트는 병렬로 실행할 수 있습니다.
입력에 수정 시점, 정답, 커밋 메시지, 회귀 결과를 넣지 않습니다.
한 요청의 결과를 다른 요청에 넘기거나 판정을 재사용하지 않습니다.

기존 [CLI 실행기](../ideas-lab/run_models.py)를 수정 없이 씁니다.
Claude는 Sonnet을 요청하고 Codex는 CLI 기본 모델과 low effort를 요청합니다.
실제 모델 버전까지 양쪽 모두 고정한 비교는 아닙니다.
호출당 120초, Claude 보고 금액은 호출당 $0.20입니다. 18번의 상한 합계는 $3.60입니다.
Codex 금액은 추정하지 않습니다.
CLI 오류가 발생하면 그 호스트의 후속 호출을 멈추고 원인을 기록합니다.

임시 디렉터리에서 도구 사용을 제한한 읽기 전용 판단을 받습니다.
제품 코드와 사용자 데이터는 수정하지 않습니다. 실제 개발 전체의 완료 시간을 재는 실험은 아닙니다.
선택기를 만드는 시간과 시작점을 사람이 고른 시간은 요청 시간에서 제외합니다.

## 자료

- `selector.py`, `test_selector.py`: 원문 선택과 누락·변경·예외 검사
- `prepare.py`, `fixtures.json`, `regression-results.json`: 원본과 회귀 검증
- `run.py`, `runs/manifest.json`, `runs/*.json`: 고정한 순서와 모든 호출
- `summarize.py`, `summary.json`: 원본과 대조한 집계
