# 실제 코드 리뷰에서 같은 판정을 다시 쓰는 시험

기준과 코드가 같을 때 기존 판정을 다시 쓰면 반복 호출을 얼마나 줄일 수 있는지 봅니다.
비교할 일은 저장소에서 실제로 고친 결함 두 개의 코드 리뷰입니다.
모델이 더 정확하게 판단하도록 만드는 실험은 아닙니다.

**상태: 2026-10-05에 계획한 요청 64번을 모두 처리했습니다.**
실제 모델 호출은 48번, 판정 재사용은 16번입니다. 기준별 판정은 모두 기대값과 일치했습니다.
자세한 해석은 [결과 보고서](../../findings/2026-10-05-review-reuse.md), 수치는 [집계 원본](summary.json)에 있습니다.

## 실제 관측과 이번에 정한 조건

[실제 비용 관측](../../../../state/observations/O-00000024.md)에서는 리뷰가 많은 토큰을 썼습니다.
다만 최근 실제 로그 세 개에는 입력 전체의 해시가 없었습니다.
실무에서 완전히 같은 입력이 얼마나 반복되는지는 계산하지 못했습니다.

이번에는 수정 전 코드, 같은 코드, 수정 후 코드, 같은 코드 순서로 요청합니다.
반복 비율은 실험자가 정했습니다. 실제 업무의 반복 비율이라고 주장하지 않습니다.
작업이 끝났는지는 요청한 기준의 리뷰 결과를 저장했는지로 확인합니다.
그 판정이 코드 동작과 맞는지는 기존 회귀 테스트를 실행한 결과와 대조합니다.
코드를 실제로 고치는 작업 전체를 모델에 맡긴 시험은 아닙니다.

## 실행 전에 정한 방법

- 실제 과거 결함 두 개를 Git에 남은 수정 전후 코드로 복원합니다.
- 같은 회귀 테스트에서 수정 전 코드는 실패하고 수정 후 코드는 통과하는지 먼저 확인합니다.
- 모델에는 코드와 기준만 줍니다. 수정 시점, 커밋 메시지, 테스트 결과와 기대값은 주지 않습니다.
- 기본 조건은 요청마다 모델을 호출합니다. 재사용 조건은 입력이 모두 같으면 저장한 답을 반환합니다.
- 코드·기준·정책·리뷰 환경을 키에 넣습니다. 파일 추가·삭제·수정도 키를 바꿉니다.
- 키에 넣은 코드는 모델에 제공한 대상 파일입니다. 가져온 모듈을 포함한 저장소 전체를 추적하지 않습니다.
- 잘못된 형식과 불확실한 답은 캐시에 넣지 않습니다. 답이 정답인지 보고 저장 대상을 고르지는 않습니다.
- 두 CLI에서 각각 두 번 반복합니다. 두 번째 반복에서는 조건의 실행 순서를 바꿉니다.
- 총 요청은 64번입니다. 모든 응답이 저장 가능한 형식이면 실제 CLI 호출은 48번입니다.
- 두 작업씩 병렬로 진행합니다. 각 작업 안의 네 요청은 순서대로 실행합니다.
- Claude는 `claude-sonnet-5-5`, Codex는 CLI 기본 모델과 낮은 reasoning effort를 요청합니다.
- CLI 한 번은 120초로 제한합니다. Claude 한 번의 보고 비용 한도는 0.20달러입니다.
- Codex 비용은 CLI가 반환하지 않으므로 금액으로 바꾸지 않습니다.
- 실행 오류가 나면 기록을 보존하고 원인을 확인합니다. 틀린 판정을 맞을 때까지 다시 호출하지 않습니다.

## 시간을 재는 범위

요청마다 자료 읽기, 해시 계산, 캐시 조회·저장, 필요한 모델 호출과 결과 파일의 첫 저장을 포함합니다.
Git 원본을 꺼내고 회귀 테스트로 기준을 확인하는 일은 공통 준비 작업으로 별도 기록합니다.
이번에 시제품을 만든 개발 시간과 실제 운영에 연결할 비용은 실행 시간에 포함하지 않습니다.
입력 읽기부터 재므로 앞선 시험에서 빠졌던 자료 준비 비용 일부를 포함합니다.
호출이 섞여 실행되고 서버 상태도 달라질 수 있어 작은 시간 차이를 인과 효과로 해석하지 않습니다.
요청별 시간을 더한 값은 병렬 실행 전체의 실제 경과 시간과 다릅니다.

## 재사용을 허용하는 범위

현재 판정을 다시 조회하는 경우만 허용합니다.
새 관점의 독립 검토, 이전 판정의 정확성 검사, 새 결함 탐색을 대신하지 않습니다.
이전 답이 틀렸다면 같은 잘못을 그대로 돌려줄 수 있습니다.
파일 밖 상태, 현재 권한, 외부 서비스에 의존하는 판단에는 이번 키만으로 충분하지 않습니다.
실제 모델 버전을 고정하지 못했으므로 캐시는 이번 작업 한 번 안에서만 사용합니다.
이 시제품은 누락된 의존 관계나 서버의 모델 교체를 자동 감지하지 않습니다.

## 자료와 실행

사례와 출처는 `fixtures.md`, 복원한 입력은 `fixtures.json`에 둡니다.
회귀 실행은 `regression-results.json`, CLI와 캐시 결과는 `runs/`에 둡니다.
`cache-verification.md`는 로컬 테스트에서 무엇을 확인했는지 설명합니다.

저장소 루트에서 실행합니다. `run.py`는 계정 사용량을 쓰고 기존 결과가 있으면 중단합니다.

```text
python3 .stage/research/llm-work/experiments/review-reuse/prepare.py
python3 -m unittest discover -s .stage/research/llm-work/experiments/review-reuse -p 'test_*.py' -q
python3 .stage/research/llm-work/experiments/review-reuse/run.py
python3 .stage/research/llm-work/experiments/review-reuse/summarize.py
```

CLI 호출은 [앞선 실행기](../ideas-lab/run_models.py)를 수정 없이 재사용합니다.
CLI 옵션은 [OpenAI 공식 문서](https://developers.openai.com/codex/noninteractive)와 로컬 도움말을 확인했습니다.
기존 원본 기록은 바꾸지 않습니다.
