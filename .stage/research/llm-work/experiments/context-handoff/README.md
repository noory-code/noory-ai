# 세션을 이어받을 때 읽는 자료를 줄이는 시험

**상태: 2026-10-05에 자료 확인과 모델 비교 24번을 마쳤습니다.**
[결과 보고서](../../findings/2026-10-05-context-handoff.md)와 [집계](summary.json)에 근거와 한계를 남겼습니다.

## 실행 전에 정한 범위

원래 연구의 후속 시험입니다. Avatar / Clone 구현과 구분합니다.
Stage 소스와 실제 작업 기록을 복사본에서 읽습니다. 현재 작업 카드와 제품 코드는 바꾸지 않습니다.

첫 단계는 열린 작업 여섯 건의 자료를 확인하는 것입니다.
Stage의 세션 문맥을 생성한 뒤 대상 작업과 상위 작업의 원문을 붙여 기본 입력을 만듭니다.
비교 입력에서는 전체 작업 구조·진행 인덱스·리뷰 인덱스 세 부분만 뺍니다.
대상·상위 작업의 원문과 나머지 공통 문맥은 그대로 둡니다.
문자 수 감소를 토큰·시간·비용 감소로 바꾸어 보고하지 않습니다.

두 번째 단계는 실제 Plainly 릴리스 작업 한 건을 읽는 작은 시험입니다.
두 호스트에서 두 질문을 세 조건으로 각각 두 번 실행합니다. 총 24번입니다.

| 조건 | 주는 자료 |
|---|---|
| baseline | 세션 문맥과 대상·상위 작업의 전체 본문 |
| selected | baseline에서 전체 작업을 보여 주는 세 부분만 제거 |
| evidence | selected에 현재 매니페스트와 같은 상위 작업의 후속 작업 본문을 추가 |

질문은 현재 버전을 확인할 다음 행동과 사람이 한국어 품질을 확인했는지입니다.
모델에는 과거 릴리스 기록과 현재 매니페스트 관찰을 구분하라고 명시합니다.
따라서 복잡한 추론이나 자율 검색 능력을 시험하는 과제가 아닙니다.
현재 근거를 추가한 조건에서만 버전을 확정할 수 있습니다.
나머지 조건에서 자료를 더 읽어야 한다고 답하는 것은 올바른 결과입니다.

추가 근거는 연구자가 골랐습니다. 자동 검색이나 관련도 판별에 성공했다고 주장하지 않습니다.
작업 한 건의 질문 두 개를 독립적인 실제 작업 두 건으로 세지 않습니다.
사용자 평가가 아직 없다는 판정은 제공한 기록의 범위에서만 내립니다.
사용자가 다른 곳에서 이미 평가했는지는 이 자료로 알 수 없습니다.

## 호출과 기록

기존 [CLI 실행기](../ideas-lab/run_models.py)를 수정 없이 사용합니다.
Claude는 `claude-sonnet-5-5`, Codex는 CLI 기본 모델과 low effort를 요청합니다.
도구 사용을 막거나 비활성화하고 임시 디렉터리에서 실행합니다.
현재 저장소에서 실제 작업을 수행하거나 파일을 수정하는 실험은 아닙니다.
호스트별 조건 순서는 고정 시드로 섞고 두 번씩 실행합니다.
틀린 답은 고쳐질 때까지 반복하지 않습니다. CLI 오류는 남기고 추가 호출을 멈춥니다.

한 호출의 제한은 120초입니다. Claude의 보고 비용은 호출당 0.20달러로 제한합니다.
Codex가 금액을 반환하지 않으면 비용을 추정하지 않습니다.
자료 복사·조립 시간은 audit에, 모델 요청과 응답 저장 시간은 각 실행에 따로 남깁니다.
근거를 찾는 사람의 시간과 실제 재개 전체의 비용은 측정하지 않습니다.

## 자료 위치

- `snapshot.json`: 생성한 문맥, 원래 작업 본문, 비교 입력과 소스 해시
- `audit.json`: 문자 수와 지정한 기록 항목이 비어 있는지 확인한 결과
- `runs/manifest.json`: 실행 전에 정한 질문·조건·순서·버전·소스 해시
- `runs/*.json`: 공개 응답, 사용량, 시간과 판정
- `summary.json`: 기록 수·입력 해시를 검사한 뒤 집계한 결과

실행 명령은 다음과 같습니다. 기존 결과를 덮어쓰지 않습니다.

```text
python3 .stage/research/llm-work/experiments/context-handoff/audit.py
python3 .stage/research/llm-work/experiments/context-handoff/probe.py
python3 .stage/research/llm-work/experiments/context-handoff/summarize.py
```

전체 작업 인계의 성공 여부는 이 작은 시험으로 판단하지 않습니다.
빠진 기록, 낡은 근거와 입력 길이를 구별해 후속 실험을 고르는 데 사용합니다.
