# 아이디어 여섯 가지를 시험하는 시제품

사용자가 여섯 아이디어를 모두 시험하자고 요청했습니다.
각 기능을 작은 Python 시제품으로 구현하고 Claude와 Codex에 결과를 전달해 비교했습니다.
제품에 설치한 효과와 긴 실제 업무의 완료율은 이 시험의 범위와 구별합니다.

**상태: 2026-10-05에 1차 시험을 마쳤습니다.**
로컬 테스트 54개를 통과했고 본 비교 96번과 연결 확인 두 번을 마쳤습니다.
선택한 행동과 대상은 96번 중 95번에서 기대값과 일치했습니다.
차이 한 건은 기본 조건에서 대상 목록을 빠뜨린 사례입니다.
결론과 한계는 [결과 보고서](../../findings/2026-10-05-ideas-lab.md), 수치는 [집계 원본](summary.json)에 있습니다.

## 무엇을 끝내야 하나요

1. 여섯 기능이 실제 임시 파일이나 명시된 상태를 처리해야 합니다.
2. 테스트가 실패하는 모습을 먼저 보고 구현한 뒤 통과 결과를 남깁니다.
3. 정상 사례와 실패·예외 사례를 모두 보존합니다.
4. Claude와 Codex 각각에 기본 자료와 시제품이 정리한 자료를 주고 판단을 비교합니다.
5. 개선 효과, 차이가 없는 결과, 실패와 한계를 아이디어별로 보고합니다.

## 비교 전에 정한 방법

- 각 아이디어에 사례 4개씩, 총 24개를 준비합니다.
- 사례마다 기본 조건과 시제품 조건을 두 CLI에서 각각 한 번 실행합니다. 본 비교는 총 96건입니다.
- 연결 확인 2건은 비교에서 제외합니다.
- 기본 조건에도 판단에 필요한 원본 자료를 제공합니다. 시제품 조건은 함수가 계산한 관찰값을 전달합니다.
- 일부 함수는 정해진 규칙으로 답을 계산합니다. 그 결과를 읽고 맞힌 것을 모델의 추론 능력 향상으로 보지 않습니다.
- 기대값은 모델에 전달하지 않습니다. 입력과 기대값을 저장하고 해시를 고정한 뒤 실행합니다.
- 입력과 기준은 별도 에이전트가 검토합니다. 사람이 검토한 자료나 독립된 실제 업무 자료라고 주장하지 않습니다.
- 같은 사례를 여러 번 반복하지 않습니다. 작은 탐색 시험이며 통계적 유의성이나 일반적인 개선율을 주장하지 않습니다.

Claude는 앞선 연구와 같은 `claude-sonnet-5-5`를 요청합니다.
Codex는 설치된 CLI의 기본 모델을 요청하고 reasoning effort를 `low`로 지정합니다.
응답에서 실제 모델명이 확인되지 않으면 미확인으로 남깁니다.
두 CLI의 시스템 입력과 내부 처리량은 같지 않습니다. 모델 사이의 순위는 매기지 않습니다.

CLI 하나의 시간 제한은 120초입니다. 최대 4개씩 실행합니다.
Claude는 실행당 보고 비용을 0.20달러, 본 비교의 합계를 5달러로 제한합니다.
Codex에서는 토큰 사용량을 보관합니다. CLI가 비용을 반환하지 않으므로 금액으로 환산하지 않습니다.
CLI의 오류나 예상하지 않은 도구 호출이 발생하면 기록을 남기고 원인을 확인한 뒤 이어갑니다.

## 구현과 모델 판단을 나눕니다

시제품 테스트는 실제 파일 변경, 적용 조건, 복구와 재현 동작을 검사합니다.
CLI 비교는 그 관찰값을 받은 모델이 요청한 행동을 고르는지 검사합니다.
모델이 직접 모든 도구를 실행하거나 MCP 연결을 통해 장기 작업을 끝낸 시험은 아닙니다.
특히 작업 재개 시제품은 분류된 사용자 지시를 처리합니다. 일반 대화가 자동으로 재개되는 효과를 입증하지 않습니다.

## 자료와 명령

- `evidence.py`: 근거 변경과 질문의 적용 조건을 처리합니다.
- `recovery.py`: 일부 완료된 파일 작업과 진행 상태를 처리합니다.
- `replay.py`: 실패 당시 자료를 재시험하고 정해진 절차를 수행합니다.
- `build_cases.py`: 시제품을 실행해 입력과 별도 기대값을 저장합니다.
- `run_models.py`: 두 CLI의 공개 응답과 사용량을 보관합니다.
- `summarize.py`: 원본 기록을 다시 호출하지 않고 집계합니다.

저장소 루트에서 다음 명령을 실행합니다. 모델을 호출하는 명령은 기존 계정의 사용량을 씁니다.

```text
python3 -m unittest discover -s .stage/research/llm-work/experiments/ideas-lab -p 'test_*.py' -v
python3 .stage/research/llm-work/experiments/ideas-lab/build_cases.py
python3 .stage/research/llm-work/experiments/ideas-lab/run_models.py
python3 .stage/research/llm-work/experiments/ideas-lab/summarize.py
```

결과가 이미 있는 입력 파일은 덮어쓰지 않습니다. 입력을 바꾸려면 별도의 시험으로 보관합니다.
이미 마친 비교는 원본 기록을 재사용합니다. 새로 비교하려면 입력·실행기·결과를 별도로 보관해야 합니다.
모델을 다시 호출하지 않고 결과를 확인하려면 마지막 `summarize.py` 명령만 실행합니다.
