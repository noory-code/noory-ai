# 세션 시작에 싣는 층과 기억을 꺼내 쓰는 구조

[M-00000006](../../roadmap/milestones/M-00000006.md) 의 (나)를 다루는 W-00000400 의 연구 자료입니다.
여기의 해석은 가설이고 공식 결정이 아닙니다. 고른 것과 누가 골랐는지는
[DE-00000100](../../decisions/pending/DE-00000100.md) 에 있습니다(2026-11-23, 추천대로).

| 자료 | 내용 |
|---|---|
| [잰 것](measurements.md) | 세션 시작에 지금 실리는 글의 크기와 구성, 기록의 양, 색인이 담고 있는 것. 2026-11-23 에 이 저장소에서 직접 잼 |
| [설계안](design.md) | 맨 위 층에 무엇을 실을지의 선택지 넷, 그에 딸린 질문 셋(상한, 원본과 외부 자료의 자리, 규칙 후보 정리), 각각의 근거와 반대 관점, 추천 |

## 한눈에 보기

- **맨 위 층은 이미 작습니다.** SessionStart 훅이 싣는 글은 6,484자(61줄)입니다. Claude Code 가 자기 기억 파일에 두는
  상한(200줄 또는 25 KB)의 4분의 1쯤입니다. 크기를 더 줄이는 것만으로는 얻을 것이 적습니다.
- **그 글에 기억이 거의 없습니다.** 절반(3,373자)은 매번 같은 규칙 문장이고, 기록을 가리키는 부분은 폴더마다
  가장 오래된 번호 셋과 개수뿐입니다. 무엇이 결정되어 있는지는 한 줄도 실리지 않습니다.
- **색인에 제목이 없습니다.** 결정 색인과 작업 보관 색인은 번호, 상태, 링크만 가집니다. 주제로 결정을 찾으려면
  결정 96건의 본문을 뒤져야 합니다.
- **클라우드 세션에는 이 층이 아예 없습니다.** 훅이 돌지 않아서 `CLAUDE.md` 와 첫 메시지(브리핑)만 받습니다.
  보관된 카드 가운데 53장이 클라우드에서 돌았고, W-00000378 부터 W-00000404 까지 닫힌 25장은 모두 클라우드에서 돌았습니다.
- **추천:** 기록에서 만들어 내는 색인 하나(결정 제목, 올라간 규칙, 열린 규칙 후보)를 맨 위 층으로 삼고,
  훅과 클라우드 세션이 같은 색인을 읽게 합니다. 전체 상한은 10,000자에서 시작합니다. 까닭과 반대 관점은
  [설계안](design.md) 에 있습니다.
