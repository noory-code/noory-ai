# Stage 를 Claude 의 지금 능력에 맞추는 연구

## 네 글이 함께 말하는 것

- 하네스의 장치마다 '모델이 혼자서는 못 한다'는 가정이 들어 있고, 모델이 나아지면 그 가정은 낡습니다.
  Managed Agents 와 장기 실행 하네스 글이 같은 예(Sonnet 4.5 의 context anxiety 때문에 넣은 컨텍스트 리셋이
  Opus 4.5 에서 쓸모없어진 일)를 듭니다.
- 원본 기록은 되돌릴 수 없게 요약하지 말고 남겨 두고, 매 세션에 싣는 층은 작게 둡니다(기억 글, Managed Agents 글).
- 일한 쪽과 판정하는 쪽을 나누고, 판정은 실제로 실행해 보는 검사에 기댑니다(C 컴파일러 글, 장기 실행 하네스 글).

## 이 글들로 다 말할 수 없는 것

- 네 글 모두 Anthropic 이 자기 모델과 제품을 두고 쓴 글입니다. 수치는 그쪽이 고른 과제에서 나왔고
  Stage 같은 기록 중심의 작업 관리에 그대로 옮겨진다는 근거는 없습니다.
- 네 글은 한 모델 계열만 다룹니다. M-00000006 은 venue 중립(codex, agy 교차 리뷰)을 깨지 않는다는 전제를
  두므로, 'Claude 가 이제 혼자 한다'는 판단이 다른 실행자에게도 맞는지는 따로 봐야 합니다.
- 장치를 빼 봐야 안다는 말은 빼는 실험의 비용(실패한 카드, 사용자의 검토 시간)을 세지 않습니다.
