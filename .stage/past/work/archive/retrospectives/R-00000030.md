# R-00000030 이 저장소에서 Stage 플러그인 로컬 비활성화

## Work

`.claude/settings.local.json`의 `enabledPlugins`에 `"stage@noory-ai": false`를 추가해, 이
저장소에 한해 Stage 플러그인(훅·세션 컨텍스트)을 끈다. 전역 사용자 설정은 건드리지 않아
다른 프로젝트(banas 등)의 Stage는 그대로 유지된다.

## Decision points

- 전역이 아닌 프로젝트 로컬로만 비활성화 (스코프 최소화).
- 플러그인 on/off는 세션 시작 때만 반영되므로, 실제 효력은 사용자의 다음 리로드부터다.

## Principles applied

- Fail Fast: C4가 살아있는 게이트를 잘못 건드려 커밋이 잠기는 사고를 사전에 차단하는
  안전망.
- Honesty: 게이트가 세션 중 hot-reload되지 않는다는 사실을 사용자에게 명시.

## Context that helped

- 지난 세션에서 이 편집이 게이트에 막혀, 게이트가 이번 세션에도 살아있음을 확인.

## Context that was missing

- 없음.

## Next changes

- C4~C8을 게이트 없이 진행한 뒤, `.stage` v4 마이그레이션(도그푸드)과 함께 Stage를 다시
  켜고 최종 감사한다.
