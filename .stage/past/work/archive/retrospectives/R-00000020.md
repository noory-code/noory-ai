# R-00000020 Cross-venue delegation and review contract

## Work

Formalized dual-agent operation in the Stage plugin docs: delegated execution (venue = the
executing surface, not the hosting window) in stage-handoff, cross-venue review (executor and
reviewer must differ) in operations/review.md, and the cardless board-upkeep doctrine in
operations/before.md. Wired the project's review gate to a measured verdict command.

## Decision points

- Venue semantics under delegation: venue names the executor; the host monitors and reviews.
- Review rotation: codex output reviewed by claude at close; claude output bound to codex
  review through the close_work gate; promotion review stays off (human-owned).
- Cardless doctrine placed in plugin operations (owner: Stage must behave this way — agent
  memory is not a governance surface).
- P2 review finding rebutted (language=ko is the owner's choice); P1/P3 accepted and fixed.

## Principles applied

- SSOT: doctrine lives once, in plugin operations; agent memory only points at it.
- Fail Fast: review command measured before binding — raw exit 0 on P1 would have made a
  fail-open gate; the wrapper closes it.
- MECE: executor/reviewer roles disjoint by contract.

  genuine board defects.
