# 세션에 붙일 수 있는 자리와 지금 붙은 것

이 문서는 이 저장소의 훅 배선 인덱스를 소유한다 — 호스트가 부르는 자리 아홉, 그중 지금 무엇이
붙어 있고 빈 자리에 무엇을 붙일 수 있는지.

막는 자리 열넷이 각각 무엇을 지키고 어떻게 풀리는지는 `stage/hooks/README.md` 가 소유한다.
스테이지 훅의 규칙 자체는 플러그인의 `operations/hooks.md` 가 소유한다. 여기 옮겨 적지 않는다.

## 자리 아홉

호스트가 훅을 부르는 시점은 아홉이다. 다섯이 차 있고 넷이 비어 있다.

| 자리 | 언제 도나 | 지금 붙은 것 | 막을 수 있나 |
|---|---|---|---|
| `SessionStart` | 세션 열릴 때 | stage — 열린 관측·진행 중 작업·리뷰 후보·호스트 규칙 목록·열린 질문 셋·지난 인계를 싣는다 | 아니오 |
| `UserPromptSubmit` | 사람이 말 걸 때마다 | plainly — 답변 문체 지침을 넣는다 | 예 |
| `PreToolUse` | 도구 쓰기 전 | stage — 막는 자리 열넷을 검사하고 통과해도 카드 목적을 덧붙인다 · 사용자 개인 설정 — 셸 명령을 `rtk` 로 갈아 끼운다 | 예 |
| `PostToolUse` | 도구 쓴 뒤 | stage — 통행증 예약을 실제 실행 뒤에 확정한다 | 아니오 |
| `Stop` | 턴이 끝날 때 | stage — 다음 세션이 이어받을 인계문을 쓴다 | 예 |
| `SubagentStop` | 팀원 하나가 마칠 때 | **비어 있음** | 예 |
| `SessionEnd` | 세션이 닫힐 때 | **비어 있음** | 아니오 |
| `PreCompact` | 대화가 요약되기 전 | **비어 있음** | 아니오 |
| `Notification` | 사람에게 알림이 갈 때 | **비어 있음** | 아니오 |

자리 이름과 호출 시점은 호스트가 정한다. 이 표의 아홉은 플러그인 개발 안내가 나열한 것을
옮긴 것이고, 이 저장소가 호스트 문서로 직접 확인한 것은 아니다.

## 빈 자리 넷에 무엇을 붙일 수 있나

각 줄은 이미 열려 있는 기록에 걸린다. 근거 없는 자리는 없다고 적는다.

| 자리 | 붙일 만한 것 | 걸린 기록 |
|---|---|---|
| `SubagentStop` | 팀원이 끝났을 때 워크트리·브랜치·실행 보고가 실제로 생겼는지 보고, 없으면 감독에게 알린다. 지금은 감독이 손으로 `git worktree list` 를 친다 | O-00000038, O-00000043 |
| `SessionEnd` | 인계문을 여기서 쓴다. 지금은 턴이 끝날 때마다 쓰는데 세션당 한 번이면 될 일이다 | 없음 — 아직 아프다는 실측이 없다 |
| `PreCompact` | 요약에서 빠지면 안 되는 것을 파일로 먼저 밀어낸다 | 없음 |
| `Notification` | 쓸 자리가 안 보인다 | — |

## 어느 파일이 무엇을 거나

| 건 쪽 | 등록 파일 | 실행 파일 |
|---|---|---|
| stage | `stage/hooks/hooks.json` | `stage/hooks/stage_guard.py` — 네 자리를 한 파일이 인자로 갈라 받는다 |
| plainly | `plainly/hooks/hooks.json` | `plainly/hooks/inject_style.py` |
| 사용자 개인 설정 | `~/.claude/settings.json` | `~/.claude/hooks/rtk-rewrite.sh` |

## 개인 설정의 rtk 훅

이 저장소가 소유하지 않는다. 사용자 계정 설정에 걸려 있어 이 프로젝트뿐 아니라 모든
프로젝트의 셸 명령에 붙는다.

하는 일은 하나다 — 셸 명령을 `rtk rewrite` 에 넘겨 같은 일을 더 적은 출력으로 하는 명령으로
바꾼다. 판단은 안 한다. 늘 통과를 내므로 무엇을 막지도 통과시키지도 않고 명령 글자만 갈아
끼운다. `jq` 나 `rtk` 가 없거나 `rtk` 가 0.23.0 보다 낮으면 경고 한 줄을 내고 아무것도 안 한다.

**셸 스크립트라 윈도우에서는 안 돈다.** 이 저장소의 이식성 규칙은 저장소 산출물에 걸리므로
개인 설정 파일이 그것을 어긴 것은 아니다. 다만 이 프로젝트를 다른 OS 에서 열면 이 훅만
빠진 채로 돈다.

## 훅이 볼 수 있는 것의 경계

훅이 받는 것은 도구 호출 하나다. 그래서 **프로그램이 실행된 뒤에 하는 일은 훅 밖이다** —
스크립트가 `.stage/official/` 을 열어 쓰면 통행증 없이 지나가고, 통행증을 소비하는 걸음도
안 뜬다. 드라이버가 서브프로세스로 내는 커밋이 커밋 게이트를 안 지나는 것도 같은 이유다.

이것은 결함이 아니라 경계다. DE-00000065 가 들이는 명령의 자격을 훅이 아니라 명령 자신의
거절 조건으로 둔 근거가 이것이다.
