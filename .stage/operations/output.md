# Output

This document owns the rules for user-visible responses.

## Rules

- Lead with the conclusion in the first sentence; keep a status explanation to one paragraph.
- Do not use analogies.
- Make conclusions and questions explicit (state the question or the decision, not just context).
- When presenting options, list 2–3 and give each one time, cost, and risk.
- State uncertainty explicitly: name what is unverified and how you would verify it.
