# W-00000034 C5: lifecycle CLIs v4-aware + stage-work milestone question

## Purpose

C5 per SCHEMA_V4.md: make the lifecycle CLIs (register_work.py, start_work.py, close_work.py, archive_work.py) v4-aware using the C4a active_topology dispatch — on a v4 project they create/move cards through work/planned, work/current, official/work/archive, decisions/pending, etc.; on v3 they behave byte-for-byte as today. Add the W-card milestone: field to registration and the conditional stage-work milestone question (ask 'does this belong to a milestone?' only when at least one open milestone exists in roadmap/milestones). Milestone creation/closure semantics are C6. v3 unchanged; STAGE_SCHEMA_VERSION stays 3.
