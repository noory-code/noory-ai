# W-00000003 Untrack .stage/.runtime/ from git

## Purpose

`.stage/.runtime/` holds per-session runtime data (session handoff summaries,
promotion intents) that is machine- and session-local. It must not be tracked
in git. Two session files had been committed before the ignore rule existed.

## Scope

Remove `.stage/.runtime/` contents from the git index (`git rm -r --cached`) so
the existing `.gitignore:59` rule takes effect. Scope covers `.gitignore` only;
the `.runtime/` deletions themselves live under `.stage/`, which is
governance-excluded.

## Success criteria

- `git ls-files .stage/.runtime/` returns nothing.
- `.gitignore` matches `.stage/.runtime/` for new files.

## Verification

Executed this session (commit a4add0a7); the prior commit 79c86ee9 asserted these without
running them:

- `git ls-files .stage/.runtime/` returns nothing.
- `git check-ignore -v .stage/.runtime/sessions/...` matches `.gitignore:59`.
- `python3 stage/scripts/audit_stage.py` — WORK005 for this item cleared.
