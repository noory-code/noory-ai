# W-00000029 v4 migration delivered as a user-facing skill; no version strands a v3 user

## Purpose

Fold Daewook's 2026-07-13 requirement into the frozen v4 design: (1) the v3-to-v4 migration is delivered as a user-facing stage-migrate skill (not a bare script), since real projects use Stage; (2) no shipped plugin version enforces schema v4 unless that same version also ships the migration skill and a completed migration path, so a v3 user pulling an intermediate version is never stranded. C3-C6 stay v3-compatible/dormant; the v4 cutover and the migration skill ship together. Amend SCHEMA_V4.md and record the decision.
