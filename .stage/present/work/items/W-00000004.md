# W-00000004 Add complete Claude Code and Codex plugin support

## Purpose

Make every local plugin in this repository installable and usable from both Claude Code and
Codex, with host-correct manifests, marketplace metadata, runtime behavior, documentation, and
verification.

## Scope

The root plugin catalogs and development instructions plus all six local plugin packages:
Evonest, RAG, Stage, Plainly, Flutter Cask, and Pencil M3 Flutter.

## Success criteria

- Codex loads the repository marketplace without errors and lists all six plugins.
- Every plugin carries matching Claude Code and Codex manifests.
- Host-dependent runtime and skill instructions use explicit Claude Code/Codex branches or a
  shared portable contract.
- Evonest can launch either Claude Code or Codex as its agent backend.
- Contract tests cover marketplace registration, manifest parity, and host-specific runtime
  assumptions; relevant package tests pass.
- User-facing documentation contains working install and usage instructions for both hosts.

## Related truth

No `.stage/past/` artifact changes are planned; this work updates product and repository files.

## Progress

Registered before modifying governed product files. Added the Codex marketplace, completed all six
dual manifests, implemented Evonest and RAG runtime support, made host-dependent skills portable,
updated versions/changelogs/docs, and added contract CI.

## Verification

- Root plugin contracts: 5 passed.
- Plainly: 26 passed.
- Evonest: 438 passed; full ruff passed; strict mypy passed for 44 source files.
- RAG: 134 passed; explicit Codex workspace-cwd probe resolved to the test workspace.
- Stage: 235 hook tests and 85 script tests passed.
- All six Codex manifests passed the plugin-creator validator.
- Fresh isolated Codex marketplace discovery listed all six release versions.
- All six plugins installed in an isolated Codex home; five changed plugins were reinstalled with
  temporary cachebuster versions and the repository manifests were restored to release SemVer.
- Pencil and Flutter Python helpers compiled successfully.
- `git diff --check` passed.
