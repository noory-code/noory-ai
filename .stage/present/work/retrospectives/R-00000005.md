# R-00000005 Archiving completed work — two gates, and literal paths

## Work

Moved W-00000001..W-00000004 from `present/work/` to `past/work/archive/`: each item copied to
`archive/items/` with `status: archived`, its retrospective copied to `archive/retrospectives/`,
and a row added to `archive/index.md` recording the `completed` final status. Removed the present
copies and cleared them from `review.md`.

## Decision points

Archiving needed a dedicated open work item (W-00000005). `past/work/archive/` writes pass TWO
independent gates: the registration gate (an *open* work item whose `scope` covers the target)
and the promotion gate (a pending *archive intent* per path). Satisfying only the intent gate is
not enough — the present-flow edits done earlier were ungated only because present flow files are
not governed source, whereas `past/work/archive/` is.

## Principles applied

- SSOT — `archive/index.md`'s `Final status` cell preserves the terminal state (`completed`) that
  the `archived` status overwrites on the item itself.
- Completion / Honesty — each item carried a closed verification and a completed retrospective
  before it was archived; archiving is record keeping, not a shortcut past those gates.

## Context that helped

`stage/scripts/audit_stage.py` confirmed archive consistency (index rows, moved retrospectives,
status rule) with errors=0. `hooks/stage_runtime.py` documents the per-item intent and the
path/ref matching the gate enforces.

## Context that was missing

Two assumptions were wrong and surfaced by fail-fast denials: (1) that no work item was needed
(the registration gate fired because `past/work/archive/` is governed source); (2) that a shell
command could use variables for the target paths — the hook parses the raw command text, so
`$AI/W-...` reached the gate unexpanded and matched nothing.

## Next changes

To archive completed items: register one open work item scoped to `.stage/past/work/archive`, then
create one archive intent per item covering its `items/<id>.md`, `retrospectives/<ref>.md`, and the
shared `index.md`. Write `past/` targets with literal paths, never shell variables, so the gate
sees the real target.

## Promotion decision

`promotion: not_applicable` — archiving is record keeping, not a promotion of new `past/` canon.
