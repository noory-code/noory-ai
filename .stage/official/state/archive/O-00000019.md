# O-00000019 드라이버가 "안 하고 보고했다"를 실패로 센다

## Observation

DE-00000051 이 정한 대로, 만든 쪽은 고칠 파일 목록 밖에 할 일이 보이면 **하지 않고 보고한다.**
그러면 저장소가 그대로다.

드라이버는 저장소가 그대로면 그 시도를 실패로 센다. 계약을 지킨 결과가 실패로 기록되고 시도
횟수를 하나 깎는다.

## Evidence

- 2026-07-31, W-00000170 첫 바퀴. 만든 쪽이 새 프로젝트가 받는 설정 틀
  (`stage/templates/v4/project-stage/settings.jsonc`)에도 같은 지시가 들어 있는 것을 찾았고,
  카드의 목록 밖이라 손대지 않고 보고했다.
- 보고 내용은 계약 그대로였다 — 무엇을 왜 못 했는지, 무엇이 필요한지.
- 드라이버 판정: `executor left repository state unchanged` → `failed, retry (attempt 1/3)`.

## Impact

계약을 지킬수록 시도가 깎인다. 세 번 깎이면 사람에게 넘어가는데, 사실 첫 번째부터 사람이 정할
일이었다. 그리고 기록만 보면 만든 쪽이 실패한 것처럼 읽힌다.

## Status

열림. 이번에는 사람이 목록을 넓혀 다시 돌린다.
