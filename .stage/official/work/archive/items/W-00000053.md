# W-00000053 .stage/ 안내 문서를 한국어로 전환

## Purpose

프로젝트 언어 설정이 ko인데도 .stage/의 안내·인덱스 문서가 영어로 남아 있는 상태를 해소한다

## Scope

`.stage/`의 안내·인덱스 문서를 현재 한국어 템플릿으로 맞춘다. 사람이 쓴 과거 기록(작업 항목,
회고, 보류 결정)은 건드리지 않는다. 기록의 `_template.md`도 대상이 아니다 — 본문이 frontmatter와
섹션 제목뿐이고 섹션 제목은 언어와 무관하게 영어로 고정이다.

## Success criteria

- 프로젝트 언어 설정(`ko`)과 `.stage/` 안내 문서의 언어가 일치한다.
- 프로젝트가 소유한 내용(아카이브 행, 계획된 카드 행, 프로젝트 kind 기준, venue 의미)은 보존된다.
- `python3 stage/scripts/audit_stage.py` 오류 0.

## Related truth

- 이 문서들은 언어만 낡은 것이 아니라 내용이 스키마 v3 시절 것이었다. `work/planned/README.md`는
  "Backlog Items"와 `B-00000001` 파일명을, `work/planned/index.md`는 `../../future/backlog/captured`
  같은 깨진 상태값을 담고 있었다. v4 마이그레이션이 안내 산문을 갱신하지 않았고, 감사는 산문을
  검사하지 않아 오류 0으로 지나갔다.
- 플러그인의 ko 로케일 템플릿 중 `operations/verification.md`의 planning·design 행은 v3 경로
  (`present/state/questions/`, `present/work/decisions/`)를 그대로 담고 있다. 프로젝트 파일에서는
  v4 경로로 고쳤고, 플러그인 템플릿 수정은 별도 항목이 필요하다.

## Progress

- 손대지 않은 뼈대 문서를 현재 ko 템플릿으로 교체.
- v3 어휘가 남아 있던 안내 문서(`work/planned/README.md`, `work/views/README.md`,
  `roadmap/*`, `decisions/pending/README.md` 등)를 현재 ko 템플릿으로 교체.
- 프로젝트 내용을 담은 문서는 병합: 아카이브 인덱스 51행, 계획된 작업 인덱스 1행,
  `operations/verification.md`의 프로젝트 kind 4종, `official/canon/vocabulary.md`의 venue 의미.
- 승격 게이트가 셸 실행 스크립트를 막지 못하는 결함을 W-00000054로 캡처.
