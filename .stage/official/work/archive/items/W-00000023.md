# W-00000023 archive_work.py silently overwrites an existing archive retrospective on id collision

## Purpose

Archiving copies present retrospectives into past/work/archive/retrospectives/<ref>.md without checking for an existing file. Observed 2026-07-13: a colliding R-00000008 clobbered another item's archived retrospective; recovery needed git history.

## Source

Observed while operating the Stage harness in novel-workspace (2026-07-12/13); details in that
project's memory note stage-plugin-defects-observed.

## User value

Refuse to archive when the target retrospective exists with a different work_item; test the collision path.

## Scope

### Included

- stage/skills + a regression test per the fix note above.

### Excluded

- Behavior changes beyond the defect.

## Dependencies

None.
