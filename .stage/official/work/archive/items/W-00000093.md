# W-00000093 Stage 0.44.0 — 오늘 아크를 릴리스로 묶는다

## Purpose

2026-07-26 하루에 패치 일곱 개(0.43.8 → 0.43.16)가 쌓였다. 내용은 패치가 아니라 아크다 —
드라이버가 사람 커밋을 지키고, 빈 실행과 빈 리뷰에 속지 않고, 카드 기준으로 판정하고,
카드 하나를 직접 받는다. 이것을 minor 릴리스 0.44.0 으로 묶어 공식 버전으로 올린다.

## Source

사용자 지시 (2026-07-26): "메인에 푸시하고 공식 버전 올리기로 가자."

## User value

마켓플레이스 사용자에게 이 아크가 하나의 릴리스로 보인다. 패치 번호 일곱 개를 읽는 대신
0.44.0 항목 하나로 무엇이 달라졌는지 안다.

## Scope

### Included

- 두 manifest(`stage/.claude-plugin/plugin.json`, `stage/.codex-plugin/plugin.json`)의
  version 을 `0.43.16` 에서 `0.44.0` 으로 올린다.
- `stage/CHANGELOG.md` 맨 위에 `## 0.44.0 — 2026-07-26` 절을 추가하고, 0.43.9 부터
  0.43.16 까지의 아크를 서너 문장으로 요약한다: 실행자 인덱스 격리(사람 커밋 보호), 무변경
  실행 실패 판정, 리뷰 계약(카드 기준 판정·기준 밖 관찰 분리·전 리뷰 명령 fail-closed·전
  실행 자리 카드 경로 전달), 단일 카드 드라이버 대상, 무인 차단 출력 보존. 기존 패치 절들은
  그대로 둔다.

### Excluded

- 코드·문서·스킬 변경 없음. 버전과 체인지로그만.

## Dependencies

- 0.43.9~0.43.16 카드 전부 닫힘 (2026-07-26 완료).

## Risks

- 없음에 가깝다. 잘못돼도 두 파일 되돌리면 끝.

## Success criteria

- 두 manifest 의 version 이 `0.44.0` 이고 서로 같다.
- `stage/CHANGELOG.md` 맨 위에 0.44.0 절이 있고 아크 요약이 위 Included 의 다섯 가지를
  담고 있다. 기존 절 무변경.
- `python3 -m unittest discover -s stage/scripts/tests -q` 통과.
- `python3 -m unittest discover -s stage/hooks/tests -q` 통과.

제약:

- **커밋하지 않는다.** 작업 트리에 변경만 남기고 멈춘다.
- 저장소 산출물은 영어.
- scope 밖은 건드리지 않는다.

## Progress

### 드라이버 두 번째 실전 가동 — 실행·검증 통과, 리뷰는 인프라 결함으로 차단 (2026-07-26)

드라이버가 이 카드를 직접 받아 돌렸다. 실행자(codex)가 버전 범프와 체인지로그를 정확히
만들었고, 검증 두 벌(scripts 357, hooks 327)이 스텝 안에서 통과했다. 리뷰 단계에서
리뷰어(`claude -p`)가 입력 초과로 죽었고 — **이번에는 fail-closed 방벽(W-00000089)이 작동해
차단으로 멈췄다.** 조용한 통과는 없었다.

심어 둔 계측(`tee`)이 원인을 잡았다: 리뷰어의 stdin 이 9,016,382 바이트, 내용은 저장소
전체 962개 파일의 diff 였고 그중 956개가 "deleted file mode" — 리뷰어용 임시 인덱스가
사실상 비어 있어 git 이 전 파일 삭제로 읽었다. W-00000088 사고(2.16M 토큰)와 크기·성격이
일치한다. 진단은 Q-00000001(답변됨)과 수정 카드 W-00000094 로 옮겼다.
