# W-00000094 드라이버 한 바퀴를 역할 계약으로 다시 세운다

## Purpose

드라이버 한 바퀴가 설계된 적이 없다. 사고가 날 때마다 그 자리에 방어를 하나씩 덧댔고,
그 덧댐이 다음 사고를 불렀다. W-00000073, 90, 94(원래 형태), 92 는 전부 같은 전제 하나에서
나왔다 — 리뷰 자료를 `git diff` 로 만든다는 전제.

그 전제가 부른 연쇄: diff 를 뜨려면 인덱스가 필요하다 → 실행자가 만든 새 파일도 diff 에
보여야 한다 → 실행자 인덱스를 리뷰어에게 물려준다 → 환경이 샌다 → 인덱스가 빈다.

이 프로젝트는 PR 을 쓰지 않고, 이 리뷰는 PR 리뷰도 아니다. 루프 안에서 목적을 완성해 가는
중간 점검이다. 리뷰어는 저장소 안에서 돌고 파일을 직접 열 수 있다. diff 는 파일에 손이 안
닿을 때 쓰는 대용품인데, 그것을 기본값으로 깔고 시작했다.

한 바퀴를 역할 계약으로 다시 세운다. 도구 이름이 아니라 역할로 — 작업자, 리뷰어, 드라이버.

## Source

사용자와의 설계 토론 (2026-07-26). 사고 기록: W-00000073(리뷰어가 새 파일을 못 봄),
W-00000090(세션 환경 유출), Q-00000001(리뷰 입력 9MB), 그리고 이 카드의 원래 형태.

## User value

드라이버로 작업을 끝까지 돌릴 수 있다. 그리고 다음 사고가 새 카드를 만들지 않는다 —
지금까지 카드 열 장은 계약이 없어서 매번 그 자리에서 판단을 만들어 넣은 기록이다.

## Scope

### Included

- 세 역할이 무엇을 주고받는지 정한다. 결정 기록으로 남긴다.
- 그 계약에서 구현 카드를 뽑는다.

### Excluded

- 구현 자체. 이 카드는 설계만 하고 코드를 만지지 않는다 (`scope` 가 비어 있는 이유).
- 실행자 건강 확인(사전 점검·생존 감시)은 W-00000092 가 갖는다. 다만 인프라 실패를 시도
  상한에 태우지 않는 문제는 이 계약의 상한 규칙과 맞닿으므로 경계를 명시한다.

## Dependencies

없음.

## Risks

- 계약을 너무 크게 잡으면 구현이 한 번에 안 끝나고, 반쯤 바뀐 드라이버가 남는다. 구현
  카드를 쪼갤 때 각 카드가 그 자체로 돌아가는 상태를 남기도록 한다.
- 기존 방어(W-77, 81, 83, 89)를 걷어내다 잃으면 안 되는 것을 잃을 수 있다. 계약이 그
  방어들을 어떻게 흡수하는지 결정 기록에 대조표로 남긴다.

## Success criteria

- 세 역할이 주고받는 것이 결정 기록 하나에 정해져 있다 — 무엇을 주고, 무엇을 근거로
  판정하고, 언제 끝나고, 안 끝나면 어떻게 하는가.
- 지금까지 덧댄 방어 각각이 그 계약 안에서 어디로 가는지(흡수 / 유지 / 폐기) 표로 정리돼
  있다. 빠진 것이 없다.
- 구현 카드가 등록돼 있고, 각 카드는 그 자체로 완결된 상태를 남긴다.
- 계약은 도구 이름을 쓰지 않는다. 역할로만 쓴다.

## Next action

결정 기록을 쓴다. 그다음 구현 카드를 뽑는다.

## Progress

- 아카이브 카드 서른 장과 결정 기록 스물여덟 건을 훑어, 드라이버 관련 결정 열네 건이 전부
  "무엇을 하는가" 만 정했고 "무엇을 못 믿는가" 는 어디에도 없다는 것을 확인했다.
- 리뷰어 명령이 플러그인이 아니라 프로젝트 설정(`.stage/settings.json`)에만 있다는 것을
  확인했다. 리뷰 자료를 `git diff HEAD~1` 로 만드는 자리가 거기다.
- 사용자와의 토론에서 전제가 드러났다 — 이 프로젝트는 PR 을 쓰지 않고 이 리뷰는 PR 리뷰도
  아닌데, PR 리뷰 방식(diff)을 기본값으로 깔았다. 그 전제가 인덱스 물려주기를 필요하게
  만들었고 사고 연쇄를 낳았다.
- DE-00000034 로 계약을 확정했다. 세 역할, 오가는 것 열 단계, 불변 규칙 넷, 기존 방어 아홉
  개의 행선지 대조표.
- 구현 카드 셋을 계약의 층 단위로 등록했다: W-00000095(관찰이 리뷰 입력이 된다),
  W-00000096(로그가 공용 기록이 된다), W-00000097(남은 항목이 다음 바퀴로 흐른다).
