# R-00000320 Ubuntu 러너에서 Python 3.9 시험이 계속 돌게 한다

W-00000320. `ubuntu-latest` 가 Ubuntu 26.04 가 되면서 Python 3.9 를 받지 못해 Stage·Avatar·Plainly 의 Ubuntu 3.9 작업이 시험
