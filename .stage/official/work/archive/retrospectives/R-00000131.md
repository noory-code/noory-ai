# R-00000131 감독 경로 시도 계수 정렬 회고

## Work

감독 경로도 인프라 실패(시간 초과, 도구 없음, 시그널)에 시도를 안 쓴다 — 무인 경로와 같은
분류 함수 하나를 쓴다. 어제 낡은 플러그인 캐시가 카드 시도 하나를 먹었던 그 자리가 닫혔다.
O-00000003 의 남은 절반이다.

## Decision points

- 두 모드가 **같은 분류 함수**를 쓰는 것을 기준으로 박았다. 분류가 두 벌이면 오늘 정렬해도
  내일 갈라진다 — 같은 문장 여러 벌이 갈라지는 것을 오늘만 세 번 봤다(실행자 프롬프트, 리뷰
  명령, 처분 규칙).

## Principles applied

- MECE — 인프라 실패와 실질 실패를 가르는 자리가 하나다. 한쪽을 맞추다 다른 쪽이 풀리지
  않게 두 방향을 같은 테스트 묶음이 고정한다.

## Context that helped

- 리뷰어가 상한 계산·공짜 재시도 경계·기형 판정 처리까지 코드 줄 단위로 대조했다. 액션
  크기라서 리뷰가 이 깊이로 갈 수 있다.

## Context that was missing

- 없음. 스토리의 액션 셋이 전부 한 바퀴에 끝났다 — 크기가 맞으면 왕복이 사라진다.
