# R-00000091 세션 안에서 돌린 드라이버가 세션 환경을 리뷰어에게 흘린다 — 원인 조사

## Work

리뷰어 입력이 340만 토큰이 된 사고의 원인 가설 셋(세션 환경 변수 상속, 리뷰어 환경의 diff
팽창, codex 의 큰 미추적 파일)을 전부 실측으로 반증했다. 원인은 미상으로 남기고
Q-00000001 로 라우팅했다 — 재발 시 계측(리뷰 stdin 실측 + 환경 보존)으로 잡는다.
W-00000089 의 fail-closed 방벽이 있어 재발해도 조용히 통과하지 않는다.

## Decision points

- 카드 종류를 fix 에서 planning 으로 바로잡았다 — 원인이 재현되지 않으면 fix 의 통과 기준
  (재현 테스트)을 정직하게 채울 수 없다. 조사는 조사로 닫고, 고치는 일은 원인이 잡히면 fix
  카드로 잇는다.
- 제목의 가설("세션 환경을 흘린다")이 반증됐지만 제목을 고쳐 쓰지 않았다 — 카드는 등록 당시
  믿음의 기록이고, 반증 과정 자체가 이 카드의 산출물이다.

## Principles applied

- **Honesty** — "모른다" 를 결론으로 기록했다. 반증된 가설을 사실처럼 두지 않았다.
- **Fail Fast** — 원인을 모르는 채 안전한 이유를 명시했다: 방벽이 재발을 차단으로 드러낸다.
- **MECE** — O-00000001 지도의 마지막 줄이 이 카드로 정리됐다(해소 셋 + 질문 하나).

## Context that helped
