# R-00000408 리뷰어의 권한을 넓혔고, 남는 것은 리뷰어의 자기 보고다

## Decision points

- 대역 리뷰어가 어떤 셸 명령이든 실행할 수 있게 넓혔다. 스스로 고른 탐침은 미리 목록으로 적을 수 없기 때문이다. `git push` 와
  `git commit` 은 막았고, 프로젝트 파일을 고친 리뷰는 지금처럼 닫기가 실패시킨다. `sh -c` 나 스크립트 안에 숨은 명령과 저장소 밖의
  변경은 보지 못한다. DE-00000101 이 알고 고른 약점이다.
- 판정의 `method`(`ran`, `read`, `unable`)를 필수로 했다. 리뷰 명령을 고치지 않은 프로젝트는 고칠 때까지 모든 리뷰가 실패한다.
  이관 스크립트는 없다.
- "저장된 검사가 있는 카드는 `ran` 이 하나는 있어야 한다"는 바닥을 만들지 않았다. 그래서 전부 `read` 라고 적은 리뷰도 통과한다.
  판정 방법은 리뷰어의 자기 보고다.
- 위 셋은 작업 세션이 정했고 지휘 세션이 사용자의 위임으로 받았다. 사용자가 보고 뒤집을 수 있게 O-00000062 에 적는다.

## Context that was missing

- 이 카드의 닫기 리뷰가 바뀐 계약으로 도는 첫 리뷰다. 작업 세션은 대역을 버리는 사본에서 한 번, 한 모델로만 돌려 보았고
  Windows 의 PowerShell 규칙은 실행해 보지 않았다.
