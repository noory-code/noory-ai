# R-00000071 stage-drive 스킬 — 드라이버 진입점

## Work

드라이버를 플러그인 스킬 목록에 노출하는 진입점 `stage/skills/stage-drive/SKILL.md` 를 만들었다.
사양을 옮겨 적지 않고, 언제 이 스킬을 쓰는지와 조심할 것만 쓴 뒤 세부는 `docs/SCHEMA_V4.md` 와
결정 기록으로 링크한다.

이 산출물은 드라이버가 만들었다. W-00000069 의 감독 모드 실행이 이 카드를 골라 claude venue
실행자에게 넘겼고, 헤드리스 실행자가 카드만 읽고 작성했다.

## Decision points

**진입점을 스킬로 둘 것인가.** 드라이버는 코드로 완성돼 있었지만 `docs/SCHEMA_V4.md` 안에만
적혀 있었다. 다른 생애주기 흐름은 전부 스킬이므로, 플러그인의 스킬 목록만 읽는 에이전트에게
드라이버는 존재하지 않는 것과 같았다. 같은 자리에 두는 것이 일관된다.

**무인 모드를 스킬에 어떻게 적을 것인가.** 평범한 선택지처럼 적으면 읽는 사람이 검증되지 않은
자동 실행을 진짜 작업에 건다. 코드 리뷰와 테스트는 거쳤지만 실제 작업으로 끝까지 돌아본 적이
없다는 사실을 명시하고, 감독 모드가 기본 답이라고 못박았다.

## Principles applied

**SSOT** — 스킬은 계약을 소유하지 않는다. 규칙의 주인은 사양 문서와 결정 기록이고 스킬은
그리로 보낸다. 스킬에 규칙을 복사했다면 두 곳이 갈라졌을 것이다.

**Honesty** — 무인 모드의 미검증 상태를 스킬 본문에 남겼다. 도구가 자기 한계를 말하지 않으면
읽는 사람이 알 방법이 없다.

**Fail Fast** — 스킬은 두 설정 관문(실행자 설정, 반대 venue 리뷰어)이 모두 그 자리에서 멈춘다는
사실을 앞세운다. 조용히 대신 실행하지 않는다는 것이 이 도구의 성격이다.

## Context that helped

카드가 요구한 다섯 항목이 그대로 스킬의 뼈대가 됐다. 헤드리스 실행자는 카드 외에 아무 맥락도
받지 못하는데, 카드가 자기만 읽고 일할 수 있게 쓰여 있어서 그것으로 충분했다.

## Context that was missing

**감독 모드에서 리뷰어는 새 파일을 볼 수 없다.** 감독 모드는 커밋하지 않고, 이 프로젝트의
리뷰 명령은 git 변경을 본다. `git diff` 는 추적되지 않는 새 파일을 보여주지 않으므로, 실행자가
통째로 새로 만든 산출물은 리뷰어에게 빈 변경으로 보인다. 이번에는 리뷰어가 "스킬이 변경에
없다"고 지적해 드러났지만, 반대로 "문제 없음"으로 통과시켰다면 아무도 몰랐을 것이다. 별도
카드로 등록한다.

**헤드리스 실행자는 셸 명령을 못 돌린다.** 실행자가 검증 명령을 스스로 확인하려 했으나
승인 필요로 막혔고, 그 사실을 숨기지 않고 보고했다. 드라이버가 다음 단계에서 같은 명령을
다시 돌리므로 결과에는 영향이 없다 — 검증의 주인이 실행자가 아니라 드라이버라는 설계가
여기서 값을 했다.

## 세 라운드로 수렴했다

이 카드는 드라이버로 세 번 돌았고, 매번 독립 리뷰가 판정했다.

| 라운드 | 판정 | 무엇이 걸렸나 |
|---|---|---|
| 1 | BLOCK | 예시 경로가 이 저장소에서만 맞음 · 막히는 조건을 둘로 단언 · 진전 판정 설명 부정확 · "리뷰 두 번 통과" 과장 |
| 2 | BLOCK | 경로를 `${CLAUDE_PLUGIN_ROOT}` 로 바꿨으나 그 변수는 셸에 없음 · "지적 모두 반영" 여전히 과장 · 진전 판정 설명 아직 좁지 않음 |
| 3 | 통과 | 비차단 지적 하나(설치 경로에 공백이 있으면 깨짐) — 직접 반영 |

수렴했다는 사실 자체가 이번 실행의 성과다. 리뷰어가 매번 새 요구를 만들어 냈다면 이 되먹임
고리는 무인 모드에 쓸 수 없다. 세 번째에 통과했고, 마지막 지적은 비차단이었다.

**수렴시킨 것은 카드에 한도를 건 일이다.** 2라운드 지적 중 둘은 스킬이 아니라 드라이버 코드에
대한 것이었다. 그것까지 이 카드에 얹었으면 스킬 하나 쓰는 일이 드라이버 전체를 떠안았을
것이다. 카드에 "이번이 마지막 라운드, 이를 넘는 지적은 별도 카드로" 라고 못박고 코드 결함은
W-00000075 로 보냈다.
