# R-00000220 워크트리 실행 환경을 본 체크아웃과 같게 준비한다 (물림)

## Work

스토리의 전제 — 워크트리와 본 체크아웃의 실행 환경이 다르다 — 가 측정에서 무너졌다. 클로드
실행자는 어디서든 명령 실행 권한이 없고(acceptEdits 는 편집만 허용, 어느 허용 목록도 python3
를 안 덮는다), 그동안 claude venue 카드가 통과한 것은 드라이버가 인수 검사를 대신 돌리기
때문이다. 코덱스 쪽 환경 문제는 이번에도 재현되지 않았다.

## Decision points

- **스토리 통째 물림.** "같게 준비한다"는 이미 참(둘 다 같이 막힘)이라 할 일이 없다.
- **진짜 물음을 설계 카드로 넘긴다.** 클로드 실행자에게 필요한 권한을 줄 것인가, 클로드
  venue 실행을 에이전트 팀 방식으로 바꿀 것인가 — 사용자가 이미 에이전트 팀 선호를 밝혔고,
  이것은 사람이 정할 일이다. M-00000003 기준 ①의 "고쳐졌다"는 이 결정이 내려져야 움직인다.

## Principles applied

- **Fail Fast** — 전제가 무너진 순간 스토리를 세웠다. 한 바퀴 만에 끝났다.
- **Honesty** — 세 겹(실행자 정적 대조, 판정자 반려, 감독 대칭 탐침)이 서로를 교정했다.

## Context that helped

- 판정자의 적대적 반려. 이것이 없었으면 그럴듯한 원인("허용 목록 없음")이 확인된 원인으로
  굳었을 것이다 — 사실이지만 비대칭의 설명은 아니었다.

## Context that was missing

- 검증 안 된 전제가 카드 Source 에 사실처럼 들어갔다(R-00000218 참조).

## Next changes

- 측정 대상과 실행 venue 가 겹치는 카드는 드라이버에 넘기지 않고 감독이 직접 잰다.
