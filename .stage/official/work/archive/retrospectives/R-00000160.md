# R-00000160 다른 도구가 저장소에 깔아 둔 Copilot 지침을 지운다

## Work

MermaidChart 서버를 연결하자 저장소 `.github/` 에 Copilot 용 지침 파일 둘이 생겼다. 우리가 쓰지
않는 도구의 파일이라 지웠다. 원래 있던 `.github/workflows/` 는 그대로다.

## Decision points

**게이트를 우회할 것인가.** 안 했다. 지우려 하자 등록 게이트가 막았다 — 열려 있던 카드의 범위
밖이었다. 범위를 늘려 붙이면 그 카드의 목적과 상관없는 일이 섞이므로, 작은 카드를 따로 만들어
지웠다. 파일 둘 지우자고 카드 한 장이 무겁게 느껴졌지만, 게이트가 정확히 제 일을 한 자리다.

## Principles applied

- **Fail Fast** — 낯선 파일이 조용히 커밋에 섞이는 것을 게이트가 먼저 막았다.

## Context that helped

커밋하려던 순간 게이트가 이름을 대며 막아서, 그 파일이 언제 왜 생겼는지 바로 짚을 수 있었다.

## Context that was missing

**외부 도구가 저장소에 파일을 쓸 수 있다는 것을 안 세고 있었다.** MCP 서버를 붙이는 것은 설정을
바꾸는 일로만 봤는데, 연결하면서 작업 폴더에 파일을 쓰기도 한다.

## Next changes

**도구를 붙인 뒤에는 작업 폴더를 한 번 본다.** 오늘은 커밋 게이트가 잡아 줬지만, 게이트가 안 보는
자리에 쓰면 그대로 남는다.

## Promotion decision

`not_applicable`. 저장소에서 파일 둘을 지운 것이 전부다.
