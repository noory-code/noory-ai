# R-00000305 판 사이에 완료 기준이 바뀌면 전체 리뷰로 다시 판정한다

## Work

W-00000305. 감독 드라이버가 판정을 확정할 때 카드 완료 기준의 지문을 판정 파일 옆에 기록하고, 다음 판에서 지문이
다르면 좁은 재리뷰 대신 전체 리뷰를 돌린다. O-00000052 를 닫았다.
외부 결과: 리뷰 사이에 완료 기준을 다듬어도 승인이 버려지지 않고, 새 기준이 판정 없이 지나가지도 않는다.
내부 결과: scripts 전체 717개, hooks 393개가 통과하고, 새 시험은 고치기 전 드라이버에서 실패한다. 기준이 그대로인
좁은 재리뷰 시험도 그대로 통과한다.

## Decision points

- 판정의 기준 문자열을 맞추지 않고 카드 기준의 지문으로 정했다. 리뷰어는 기준을 더하거나 말을 바꿀 수 있다.
- 반려한 판정에도 지문을 남긴다. 다음 판이 다시 보는 것이 바로 그 반려다.
- 지문이 없는 예전 판정은 그대로로 본다. 이 변경 전에 시작한 실행은 좁은 재리뷰를 이어 간다.
- 실행자가 이전 실패 기준에 처분을 적는 의무는 그대로 두고 리뷰 방식만 바꿨다.

## Principles applied

Honesty: 승인된 결과가 실패로 보고되지 않게 한다.
만든 쪽 ≠ 보는 쪽: 실행 맥락이 없는 별도 Claude 세션이 판정했다. 같은 모델 계열이라 교차 venue 판정은 아니다.

## Context that helped

- O-00000052 가 원인 줄과 반대 방향의 위험까지 적어 두었다.
- 기존의 좁은 재리뷰 시험 도우미를 그대로 본떠 시험을 짰다.

  받아 둔 브랜치만 보므로, 작업 중에도 원격을 자주 받아야 한다.
