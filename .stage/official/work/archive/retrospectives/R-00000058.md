# R-00000058 플레인리 스타일에 한국어 문장 규칙 추가

## Work

한국어 답변이 영어 직역체로 나오던 문제를 프로젝트 스타일 파일에 규칙으로 박았다. 실패한
문장을 예시로 함께 남겨 규칙이 추상론으로 남지 않게 했다.

## Decision points

- 플러그인 기본 스타일을 고칠 것인가, 이 프로젝트 파일만 고칠 것인가 — 프로젝트 파일만 고쳤다.
  한국어 사용자에게만 해당하는 규칙을 모든 프로젝트의 기본값에 넣을 근거가 없다.
- 규칙만 쓸 것인가, 실패 사례를 넣을 것인가 — 넣었다. "직역하지 말 것"만으로는 무엇이 직역인지
  판정이 서지 않는다.

## Principles applied

- Fail Fast — 사용자가 뜻을 되물은 시점이 신호였다. 그 자리에서 규칙으로 고정했다.
- SSOT — 이 프로젝트의 대화 스타일은 `.plainly/style.md` 하나가 소유한다. 기억이나 관행에
  맡기지 않는다.
- Honesty — 스타일이 실제로 주입되는지 훅을 직접 실행해 확인했다. 파일을 고쳤다는 사실만으로
  동작한다고 말하지 않았다.

## Context that helped

- 플러그인의 설정 조회 명령이 어떤 스타일이 걸려 있는지 바로 보여줬다. 추측할 필요가 없었다.

## Context that was missing

- 스타일 파일이 저장소에 추적되는 파일이라는 점이 바로 보이지 않았다. 개인 설정처럼 보이지만
  Stage 등록이 필요한 governed 파일이다.

## Next changes

없음. 규칙의 효과는 다음 대화에서 사용자가 판단한다.
