# R-00000414 리뷰어는 닫기 전에 드러난 결함은 잡고 닫은 뒤에 드러난 결함은 못 잡았다

## Decision points

- 결함이 기록된 판 11개와 통과한 판 8개를 두 번씩, 38번 돌렸다. 결함판 22번 중 반려 19, 거짓 통과 3. 통과판 16번 중 승인 11,
  반려 5.
- 닫기 전에 이미 찾아낸 결함 7건은 14번 모두 그 결함으로 반려했다. 닫기를 통과한 뒤 드러난 결함 4건은 8번 중 한 번도 그 결함을
  짚지 못했다. 리뷰어의 탐침은 기준 문장이 이름으로 든 입력에 머문다.
- "실행이 필요한 기준에 ran 이 하나는 있어야 한다"는 바닥은 지금 넣지 않는 것을 추천했고, 지휘 세션이 사용자의 위임으로 그대로
  받았다. 걸렸을 판정이 38번 중 0번이고 거짓 통과 3번의 기준이 모두 `PASS ran` 이다.
- 잘못 고른 표본(W-00000335)을 결과를 본 뒤에 빼지 않고 그렇게 표시해 남겼다.

## Context that was missing

- 리뷰어가 과거 트리 밖을 세 번 읽었다. 한 번은 GitHub API 로 PR 의 지금 상태를 읽었고, 두 번은 이 컨테이너의
  `~/.claude/projects/` 의 세션 기록을 읽었다. W-00000408 이 리뷰어에게 셸을 열어 주면서 읽기를 막을지는 정하지 않았다. 닫기의
  앞뒤 비교는 쓰기만 본다.
- 이 재기의 정답은 과거 기록이고 사람의 판정이 아니다. 리눅스의 Claude 대역 하나만 쟀다.
