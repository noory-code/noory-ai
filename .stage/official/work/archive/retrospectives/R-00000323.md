# R-00000323 codex 없는 로컬 환경을 선언하면서 이미 있던 반려 기록을 뒤늦게 읽었습니다

## Work

[W-00000323](../current/W-00000323/_story.md)에서 DE-00000086 을 쓰고 확정했습니다. `environment_venues` 에 `local-no-codex` 한 줄을 더하고 `.stage/operations/claude-venue.md` 에 절차 절을 더했습니다. 외부 요청(codex 가 없는 동안 로컬 카드가 막히지 않게 하되 임시 상태가 기록에 남게 한다)은 충족했습니다. 내부적으로 플러그인 코드와 라우팅·리뷰 설정은 바꾸지 않았고, 공유 판정 함수를 네 입력으로 돌려 허용과 거절을 확인했습니다.

## Decision points

- 라우팅을 고칠지 환경을 더할지는 사용자가 정했습니다. 환경 이름도 사용자가 확정했습니다.
- 사용자가 초안을 확정한 뒤에 W-00000299 의 표본 재검토 결과를 찾았습니다. 선택한 방향은 그대로 두고 근거만 Reason 에 더했습니다. 그 결과가 가리키는 사람 확인 조건은 채택하지 않고 Follow-up 에 남겼습니다. 확정된 결정에 조건을 덧붙이는 것은 사용자가 정할 일입니다.
- 승격은 `deferred` 로 했습니다. 구독이 돌아오면 사라질 임시 정책이라 공식 진실로 올릴 대상이 아닙니다.

## Principles applied

- **SSOT**: 닫기 절차를 새로 쓰지 않고 `stage/operations/cloud-execution.md` 를 가리켰습니다.
- **Honesty**: 이 환경이 잃는 안전망과 그 안전망이 실제로 잡았던 사례를 결정 레코드에 적었습니다.
- **User intent**: 결정의 방향·이름·확정은 모두 사용자에게서 받았습니다.

## Context that helped

DE-00000082 가 환경 이름을 고정하지 않게 구현돼 있어 설정 한 줄로 끝났습니다. 판정 함수를 사본에서 돌려 본 것이 "코드 변경 없음"을 주장이 아니라 관측으로 만들었습니다.

## Context that was missing

DE-00000082 의 Follow-up 이 표본 검사를 예고했고 W-00000299 가 그 결과를 이미 갖고 있었는데, 초안을 쓸 때 결정 레코드만 읽고 그 Follow-up 을 닫은 카드는 읽지 않았습니다. 감독 세션이 첫 요약에서 W-00000308 을 낡았다고 잘못 말한 것도 같은 모양입니다 — 제목과 버전 번호만 보고 카드 본문을 읽지 않았습니다.

## Next changes

- 열려 있는 codex venue 카드 W-00000271, W-00000281, W-00000282 를 환경을 붙여 다시 시작할지 카드마다 정합니다.
- 권한 제한이나 닫기·검증 절차를 바꾸는 카드에 사람 확인을 닫기 조건으로 둘지 사용자가 정합니다.

## Rule candidate

결정 레코드를 근거로 삼을 때는 그 레코드의 Follow-up 을 닫은 카드까지 읽는다. Follow-up 은 "이 결정이 아직 확인하지 않은 것"의 목록이고, 그 답은 레코드가 아니라 뒤따른 카드에 있다. 이번이 한 번이라 후보로만 둡니다.

## Promotion decision

`deferred` 입니다. DE-00000086 은 codex 구독이 없는 기간에만 쓰는 정책이므로 `pending/` 에 둡니다.
