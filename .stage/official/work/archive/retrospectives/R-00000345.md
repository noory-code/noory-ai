# R-00000345 plainly 0.8.0 을 낸다

## Work

릴리스 명령 한 번으로 플레인리를 0.7.3 에서 0.8.0 으로 올렸다. 쌓여 있던 한 묶음(W-00000344 의
강제 적용과 평가 질문)에 버전 제목이 붙었고 매니페스트가 같은 값을 말한다. 카드 등록과 릴리스
커밋을 PR #51 로 main 에 합쳤다(`bf84812b`).

## Decision points

- **마이너 버전을 올렸다.** 스타일을 고르던 방식에서 켜면 적용되는 방식으로 계약이 바뀌었다.
- **새 세션을 한 번 띄워 확인했다.** `plugin list` 는 버전만 보여 준다. 이 릴리스가 바꾼 것은 스타일이
  적용되는 방식이므로, 사용자 설정 없이 플러그인만 켠 세션의 디버그 로그로 강제 적용을 봤다.
- **취소된 CI 작업은 다시 돌렸다.** macOS 러너가 모자라 작업을 받지 못하고 취소됐다. 테스트 실패가
  아니어서 그 작업만 다시 돌려 통과한 뒤 합쳤다.

## Principles applied

- Completion — 머지한 뒤 새 버전이 읽히고 스타일이 실제로 적용되는 것을 보고 닫았다.
- Honesty — 이 컴퓨터는 저장소 폴더에서 바로 읽어서, 다른 컴퓨터에서 받는 경우는 확인하지
  못했다고 적었다.
