# R-00000431 Stage 0.70.0 을 릴리스하고 기기에서 시험한다

## Decision points

- 올리는 자리: minor 로 올렸다. `--main-session` 이 `--po-session` 이 되고 옛 역할 이름을 거절하는 깨는 변경이 들어 있지만,
  1.0 전이라 0.69.0 과 같이 minor 로 올렸다. PO 세션이 사용자의 위임으로 정했다.
- 릴리스 커밋을 만든 세션: PM 세션을 띄우지 않고 PO 세션이 직접 만들었다. 릴리스 절차가 명령 한 번과 커밋·푸시 한 번이기
  때문이다.
- 닫는 때: 둘째와 셋째 기준은 사용자의 기기에서만 볼 수 있어서 카드를 열어 둔 채 병합했다. 두 기기의 세션이 각각
  `- Checked` 줄을 적은 뒤에 Mac 세션이 닫았다.
- 닫는 날의 `## Unreleased`: 첫째 기준은 릴리스 커밋 `3846e93c` 에서 본 것이다. 닫는 날에는 그 뒤에 병합된 W-00000432 의
  항목이 `## Unreleased` 에 있다. 릴리스 뒤에 쌓인 다음 판의 항목이라 기준을 다시 따지지 않았다.

## Context that was missing

- Mac 의 설치본은 저장소 폴더를 그대로 읽는다. 확인하려던 날 이 Mac 의 main 은 64개 커밋 뒤처져 있었고, 그대로
  `claude plugin list` 를 봤다면 앞 버전이 나왔을 것이다. main 을 당긴 뒤에 봤다.
- Windows 의 설치본은 저장소 폴더가 아니라 `plugins\cache\noory-ai\stage\0.70.0` 에서 읽는다. 두 기기의 확인이 서로 다른
  경로(저장소 폴더, 마켓플레이스 캐시)를 본다는 것이 카드의 기준에는 적혀 있지 않았다.
