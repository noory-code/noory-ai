# R-00000031 schema_version 디스패치 (C4a)

## Work

소비자(stage_guard, stage_work, stage_context, stage_records, audit_stage)가 프로젝트의
settings.json schema_version==4일 때만 stage_topology 레지스트리 경로를 쓰도록 재배선했다.
단일 active_topology() 헬퍼가 판정하며, 모든 변경은 기존 v3 코드 위에 명시적 v4 분기를
얹는 형태라 v3 동작은 문자 그대로 불변이다. 강제 계약 버전(STAGE_SCHEMA_VERSION)은 3 유지.
codex가 구현, claude가 리뷰·커밋(dd41ec75, 0.27.0).

## Decision points

- 설계의 단일 C4 행을 위험 격리를 위해 C4a(디스패치)/C4b(레거시 차단+뷰)로 분할.
- v3 상수를 레지스트리 호출로 대체하지 않고 명시적 분기 유지 → v3 회귀 구조적 불가능.
- active_topology는 정수 4에만 v4, 그 외(없음/깨짐/이전)는 전부 v3 폴백 (Fail Safe).

## Principles applied

- Fail Fast / Honesty: v3 회귀를 실증(기존 284+204 테스트 무수정 통과 + 라이브 v3 감사 클린 +
  v3/v4 픽스처 종단 테스트)으로 증명.
- SSOT: 토폴로지 판정이 active_topology 한 곳.

## Context that helped

- C2 레지스트리의 리졸버(card_location_for_status, retrospective_locations,
  resolve_artifact_reference 등)가 이미 있어 v4 분기가 얇게 끝났다.
- 플러그인을 이 저장소에서 끈 상태라, 게이트 수술 중 커밋 잠김 위험 없이 진행.
