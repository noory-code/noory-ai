# R-00000348 rag 플러그인에 개발을 멈췄다고 표시하기

## Work

rag 플러그인의 README, 변경 기록, 루트 README, Claude Code 마켓플레이스 설명에 개발을 멈췄다고 적었다.
코드는 그대로 두고 릴리스하지 않았다.

## Decision points

- 마켓플레이스에서 뺄지, 표시만 할지: 사용자가 표시만 하기로 정했다. 되돌리기 쉽고, 이미 설치한 사람에게
  영향이 없다.
- Codex 목록에 표시가 없는 것을 받아들일지: 그러려면 매니페스트를 바꾸고 릴리스해야 한다. 개발을 멈추는
  카드에서 릴리스하는 것은 앞뒤가 맞지 않아 받아들였다.

## Principles applied

- Honesty: Codex 마켓플레이스 파일에 설명 칸이 없다는 것을 성공 기준과 어긋난 점으로 적었다.
- KISS: 멈춤을 나타내는 새 필드나 상태를 만들지 않고 문서 문구만 바꿨다.

## Context that helped

- 7월 18일 플러그인 평가에서 정한 기준("릴리스하지 않고, 지우지 않고, 표시한다")이 그대로 쓰였다.

## Context that was missing

- 저장소에 플러그인 개발을 멈췄다고 표시하는 방식이 정해져 있지 않았다. flutter-cask 도 같은 기준으로
  정했지만 표시하지 않은 채 남아 있다.
- Codex 마켓플레이스 항목에 설명 칸이 없다는 것을 카드를 쓸 때 몰랐다. 성공 기준을 쓰기 전에 파일을
  열어 봤어야 했다.
