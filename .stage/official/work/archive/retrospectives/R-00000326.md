# R-00000326 일감마다 맞는 모델과 에포트 레벨을 Stage 가 고르게 한다

## Work

story 다섯 장으로 "A. 등급 표" 설계를 끝까지 넣었다.

- W-00000327: 설계와 실측 사실을 남겼다.
- W-00000328: 설정의 `model_tiers`·`tier_routing` 과 카드 `tier:` 를 만들었다.
- W-00000329: 드라이버가 `STAGE_MODEL`·`STAGE_EFFORT` 를 넘긴다.
- W-00000330: Agent 호출 훅이 빠진 값을 채우고 비싼 모델을 막고, 실제로 돈 값을 기록한다.
- W-00000331: 감사가 어긋남을 경고한다.

에픽 완료 기준 다섯 가지를 각 story 의 시험과 실측으로 확인했다.

1. 카드에 `tier` 가 남는다. 템플릿으로 만든 프로젝트에 등록해 보니 `tier: standard` 가 적혔다.
2. 드라이버가 실행기·리뷰어에 각 venue 의 값을 넘긴다. 드라이버를 실제로 한 판 돌리는 시험으로 확인했다.
3. 하위 에이전트 등급을 실제로 확인했다. 시험 프로젝트에서 `claude -p` 로 띄운 하위 에이전트는 부모가 haiku 인데도 카드 등급대로 `claude-sonnet-5-5`/`medium` 으로 돌았다. 이유 없는 opus 호출은 막혔고, 이유를 단 opus 호출은 이유와 함께 기록됐다. 백그라운드로 띄운 경우도 기록됐다.
4. 감사가 어긋남을 경고한다. 실측 기록으로 감사를 돌리자 직접 haiku/high 로 부른 호출에 TIER004 경고가 났다.
5. `model_tiers` 가 없는 이 저장소는 감사·시험·드라이버 동작이 그대로다.

## Decision points

- 사용자 결정: 등급 이름은 scout·standard·strong·lead 다. 빠진 값은 채우고, 비싼 모델의 이유는 `description` 의 `[over-tier: 이유]` 로 받는다. 마일스톤 없이 등록했다.
- 사용자 결정: Codex 실행기가 `gpt-6-astra` 를 ChatGPT 로그인에서 거부했다. 그래서 구현 story 넷을 `local-no-codex` 환경에서 Claude 가 실행했다. 닫기 리뷰는 Claude 대역 리뷰어로 돌린 같은 모델 리뷰다.
- 설계와 다르게 간 점: 템플릿에는 claude 칸만 넣었다. 확인한 codex·agy 모델 이름이 없어서다. 실제 값 기록은 PostToolUse(요청)와 `SubagentStop`(끝남) 둘로 나눴다.
- `stage_guard.py` 는 `handle_event` 에 넘기는 줄과 `current_leaves()` 만 더했다. 다른 세션이 줄이는 중인 `append_purpose_context` 는 건드리지 않았다.

## Principles applied

SSOT(등급 표와 공용 모듈 하나), Fail Fast(잘못된 설정은 등록 거부·감사 오류, 채울 값이 모호하면 막음), Honesty(같은 모델 리뷰·바이너리 문자열 근거·실측 버전을 그대로 적음), MECE(설정·드라이버·훅·감사를 겹치지 않게 나눔), SoC(감사 검사를 별도 모듈로).

## Context that helped

- 오케스트레이터가 넘긴 실측 덕분에 훅의 입력 모양을 가정하지 않았다.
- 독립 리뷰가 두 번 실제 결함을 잡았다. 하나는 템플릿 백틱이 기존 시험을 깨뜨린 것이고, 다른 하나는 백그라운드 하위 에이전트가 기록에서 빠진 것이다.

## Context that was missing

- 실행 환경(Codex 로그인과 모델)을 등록 전에 확인하지 않아서 드라이버 한 판을 버렸다.
- 설계를 바꿀 때 "대신 무엇을 잃는가" 를 실측하지 않아 리뷰에서 걸렸다(R-00000330).
