# R-00000043 상위 집계 게이트 회고

## Work

자율 실행 드라이버의 상위 집계(종료) 통제를 구현했다. `non_terminal_children` 질의(terminal = `WORK_FINAL_STATUSES` = {completed, archived, rejected})로 부모의 모든 자식이 결판났는지 판정하고, 부모는 비-terminal 자식이 하나라도 있으면 완료/close 불가다. 자식은 current·planned·archive 전 zone에서 수집한다. 강제는 네 지점 — `close_work`, 완료/커밋 게이트(`stage_completion_blockers`), `archive_work`, 감사(WORK024) — 이 모두 하나의 `non_terminal_children` 정의를 공유한다. 부모 자동 전진(자동 close)은 드라이버(W-47)에 남겼다. 실행은 Codex, 리뷰는 Claude + 독립 `claude -p` 패스.

## Decision points

## Principles applied

- SSOT — 부모의 완료 자격은 자식 집합에서 파생하고, 판정은 단일 `non_terminal_children`로 통일.
- MECE — terminal/비-terminal을 명확히 가름(open·planned = 비-terminal).
- Fail Fast — 미완 자식이 있으면 부모 완료를 조기 차단.
- AHA / SoC — 자동 전진은 드라이버 책임이라 분리.
- TDD — 신규 테스트(active/planned 자식 차단, archived/rejected 통과, 리프 무영향) + 감사 테스트 통과.
