# R-00000082 드라이버가 도는 중에 사람이 커밋하면 그 커밋이 되돌아간다

## Work

드라이버가 실행 전에 진짜 인덱스를 사본 떠 두고 끝나면 되돌리던 코드를 지우고, 실행하는
쪽에 처음부터 버리는 임시 인덱스를 주게 바꿨다(감독·무인 모두). 리뷰어는 실행하는 쪽이 쓴
임시 인덱스를 이어받고, 검증 명령과 무인 커밋은 진짜 인덱스를 그대로 쓴다. 사람이 스텝 중에
커밋해도 이제 되돌아가지 않는다 — 실제로 이 저장소에서 커밋 하나가 되돌아갔던 사고의 수정이다.

## Decision points

- 이 카드를 드라이버로 돌리지 않는다 — 돌고 있는 드라이버가 옛 코드를 들고 있어 고치는 커밋
  자체를 되돌린다. 드라이버 없이 Codex 에 직접 위임하고(venue 준수), 검증·리뷰는 반대
  venue 인 Claude 가 했다.
- RED 를 실행자의 보고만으로 믿지 않았다 — 저장소 밖 사본에 고치기 전 코드를 풀고 새 테스트를
  얹어 둘 다 실패하는 것을 직접 재현했다.
- 리뷰는 DE-00000032 방식의 첫 적용 — 기준 판정과 기준 밖 관찰을 갈랐고, 관찰 하나(인덱스
  복사 실패가 실행 전에 막히게 된 것)는 "받지 않음(변경 불요)" 으로 근거와 함께 남겼다.

## Principles applied

- **Fail Fast** — 임시 인덱스를 준비하지 못하면 실행하는 쪽이 돌기 전에 멈춘다. 되돌리기가
  사라져 "조용히 사람 작업을 삼키는" 경로 자체가 없어졌다.
- **SSOT** — 인덱스의 소유자가 명확해졌다: 진짜 인덱스는 사람 것, 임시 인덱스는 실행하는
  쪽 것, 리뷰어는 그 임시 인덱스를 이어받는다.
- **Honesty** — 실행자의 자기 보고(RED 했다, 테스트 통과했다)를 전부 직접 재확인했다.
- **Completion** — 카드의 성공 기준 아홉 항목을 하나씩 대 보고 전부 채운 것을 확인했다.

## Context that helped

  프롬프트가 짧았고 결과가 정확했다.
- W-00000073·W-00000077 이 만들어 둔 테스트가 리뷰어 동작의 회귀 그물이 됐다.
- 게이트가 셸 변수를 안 푼다는 기록(다음 세션 메모) 덕에 RED 재현 명령을 빨리 고쳤다.
