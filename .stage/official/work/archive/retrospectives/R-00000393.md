# R-00000393 release_plugin.py 가 Windows 에서도 UTF-8 로 출력하게 한다

## Decision points

- **재현을 `PYTHONIOENCODING=cp1252` 로 했다.** Windows 에서만 도는 시험이 아니라 모든 OS 의 CI 가 같은 종류의 실수를 잡는다.
- **두 모드(릴리스, 점검) 모두에서 stdout 과 stderr 를 UTF-8 로 맞췄다.** 둘 다 버전 제목이나 경로를 출력한다.

## Context that was missing

- W-00000392 서브세션은 리눅스에서만 확인했다. 브리핑은 Windows 확인을 메인 세션의 PR CI 로 넘기라고 했고(W-00000390), 그
  PR CI 의 windows-latest 잡 두 개가 이 실수를 잡았다. 메인 세션의 닫기(W-00000392)는 PR CI 전에 끝나서 이것을 보지 못했다.

## Rule candidate

- **텍스트를 출력하는 Stage 스크립트는 `main()` 에서 stdout 을 UTF-8 로 맞춘다.** R-00000354 와 R-00000356 이 같은 종류의
  인코딩 실수를 적었고, 이번이 세 번째다. 규칙은 루트 `CLAUDE.md` 의 Cross-Platform 표에 이미 있다(`encoding="utf-8"`). 그
  표에 "출력 스트림"을 더할지 본다.
