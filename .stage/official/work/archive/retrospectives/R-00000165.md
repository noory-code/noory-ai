# R-00000165 층마다 무엇을 물을지 정한다

## Work

DE-00000053 이 셋을 정했다. 목적은 층마다 한 문장이고 등록할 때 막는다. 층마다 묻는 것이 표
하나로 서 있다 — 에픽과 스토리는 자식을 나열하고, 액션은 대신 무엇에서 나왔고 무엇을 기다리는지를
묻는다. 일을 시작한 뒤 쓰는 그릇에도 사용자 가치 칸이 들어간다.

저장소 안의 한국어 카드 그릇 넷은 지운다.

## Decision points

- **한국어 그릇을 살릴 것인가 지울 것인가.** 지운다. 카드 만드는 명령이 영어 그릇만 읽는 것을
  코드에서 확인했고, 한국어판은 프로젝트를 처음 만들 때만 복사된 뒤 아무도 안 읽는다. 기록의 칸
  제목이 언어와 상관없이 영어라는 계약도 이미 있다.
- **글자 수를 셀 것인가.** 안 센다. 사용자가 정했다.

## Principles applied

- SSOT — 층마다 무엇을 묻는지가 결정 하나에 있다.
- MECE — 층이 서로 다른 것을 묻는다. 겹치면 아래층이 위층 말을 되풀이한다.
- Honesty — 있는데 아무도 안 읽는 파일을 남겨 두지 않는다.

## Context that helped

- **자리를 먼저 셌다.** 그릇 열 개(영어 여섯, 한국어 넷)와 그것을 읽는 코드 두 곳을 세고 시작했다.
  한국어 그릇이 죽어 있다는 것도 그러면서 나왔다.
- **오늘 겪은 것이 근거가 됐다.** 아래층이 위층 말을 되풀이한 카드 둘이 같은 날 나왔다. 짐작으로
  규칙을 만들지 않았다.

## Context that was missing

- 없다. 사용자와의 논의가 셋을 이미 정해 두었고, 실측이 필요한 자리는 코드에서 확인했다.

## Next changes

- 결정에 **"이 규칙이 틀렸다는 것을 무엇으로 알게 되나"** 절을 처음으로 넣었다. 앞선 결정이 세
  시간 만에 뒤집혔을 때 그게 없어서 근거를 다시 찾아야 했다. 다음 결정에도 넣는다.
