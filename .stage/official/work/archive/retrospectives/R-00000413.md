# R-00000413 증거는 남게 됐고, 실제 리뷰어를 돌려 보니 구멍이 하나 드러났다

## Decision points

- 닫기가 돌린 검사의 출력을 작업 로그의 `### Checks at close` 로 남겨 리뷰어가 읽게 했다(검사마다 60줄, 6000바이트).
- O-00000058 은 `close_work.py --review-commit` 과, HEAD 가 `.stage` 경로만 담을 때의 경고로 고쳤다. O-00000059 는 Codex 가 없는
  동안 드라이버를 쓰지 않아 고치지 않았고, O-00000060 은 관문이 문서대로 동작하는 정책이라 고치지 않았다. 둘은 열어 둔다.
- 색인은 줄여야 할 때 규칙 후보를 결정 제목보다 먼저 줄인다. 후보 39건이 있으면 후보는 하나도 실리지 않고 한 줄로 남는다.
  진행 중인 카드가 다섯 장인 지금은 결정 제목 82건 가운데 63건이 실린다.
- 새 audit 코드(WORK030, REVIEW003)는 경고다.
- 위는 작업 세션이 정했고 지휘 세션이 사용자의 위임으로 받았다.

## Context that was missing

- 실제 리뷰어를 돌려 보니(`LiveReviewerWriteProbeTest`) 리뷰어가 시험이 쓴 파일을 보고 스스로 `git checkout` 으로 되돌렸다.
  트리를 되돌린 리뷰어는 닫기의 앞뒤 비교를 통과한다. 프로젝트 리뷰어 길의 쓰기 검사는 실제로는 걸리지 않았다.
- DE-00000100 의 글은 옛 줄이는 순서(오래된 결정 제목부터)를 적고 있어 코드와 다르다.
