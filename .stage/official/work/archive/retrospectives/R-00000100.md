# R-00000100 드라이버가 끝날 때 자기가 띄운 실행자를 거둔다

## Work

바퀴가 밖에 띄운 프로그램을 바퀴가 끝날 때 거두게 했다. 거두는 방법은 venue 별 선택 명령으로
설정에서 받는다 — 드라이버에는 도구 이름이 하나도 없다. 못 거두거나 설정이 없으면 출력과 공용
로그에 남는다. 밖에 띄우는 것이 없는 venue 는 `null` 로 밝혀 조용히 지나간다.

## Decision points

- **거두는 방법을 어디에 둘 것인가.** 드라이버에 박으면 도구마다 예외가 생긴다(계약 규칙 4).
  실행자·리뷰어와 같은 모양으로 설정에서 받았다.
- **경고를 어떻게 다룰 것인가.** 처음엔 설정이 없으면 무조건 경고했는데, 동기로 도는 도구는
  거둘 게 없어 매번 경고가 났다. 항상 나는 경고는 사람이 무시하게 만들고 진짜 경고까지 묻는다.
  "없다고 정한 것" 과 "아무도 안 정한 것" 을 구분해 앞은 조용하고 뒤는 계속 경고하게 했다.

## Principles applied

- **DIP** — 상위 정책(드라이버)이 하위 세부(도구)를 따르지 않는다.
- **Fail Fast** — 못 거두면 그 사실이 남는다. 조용히 두고 가지 않는다.
- **MECE** — 세 경우를 다 덮었다: 명령 있음 / 없다고 선언 / 아무 말 없음.

## Context that helped

실제 사고가 증거였다. 실행자 여섯이 살아남아 저장소를 계속 쓰는 바람에 파일을 되돌려도 되살아났고,
같은 껍데기가 다음 위임을 전부 막았다. 막힌 쪽에는 "다른 작업이 돌고 있다" 만 보였다.

## Context that was missing

드라이버가 부르는 명령이 끝나도 그 안에서 띄운 작업은 안 끝난다는 것. 명령이 반환하면 다 끝났다고
가정하고 있었다.

## Next changes

경고를 설계할 때 "항상 나는 경고" 가 되는지 먼저 볼 것. 그런 경고는 없느니만 못하다.

## Promotion decision

FINAL: official 파일을 바꾸지 않는다.
