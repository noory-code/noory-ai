# R-00000297 드라이버가 닫을 때도 긴 리뷰 제한 시간을 쓰게 한다

## Work

W-00000297. 무인 드라이버가 닫을 때 리뷰에 3600초와 명령 제한 시간 가운데 큰 값을, 남은 실행 시간 안에서 준다.
`close_via_close_work()` 의 바깥 제한 시간은 모든 검사 시간과 리뷰 시간을 더한 값이다.
외부 결과: 드라이버로 닫는 카드도 생각이 깊은 리뷰가 검사용 제한 시간에 끊기지 않는다.
내부 결과: scripts 전체 709개, hooks 378개가 통과하고, 고치기 전 코드로는 새 시험 셋이 실패한다.

## Decision points

- 남은 실행 시간으로 제한했다. 무인 실행은 `max_wall_clock_seconds` 에서 멈춘다고 약속한다.
- 부모 카드 닫기는 실행 시간 정보가 없어 예전 한도를 쓴다.
- W-00000270 이 남긴 후속(드라이버는 한 한도만 쓴다)을 W-00000288 로 캡처했다가 main 의 W-00000288 과 겹쳐
  W-00000297 로 번호를 바꿨다.

## Principles applied

Fail Fast: 바깥 제한 시간이 안쪽 예산을 모두 덮어 `close_work` 가 리뷰 중에 끊기지 않는다.
만든 쪽 ≠ 보는 쪽: 실행 맥락이 없는 별도 Claude 세션이 판정했다. 같은 모델 계열이라 교차 venue 판정은 아니다.

## Context that helped

- W-00000270 의 실행 보고와 회고가 바깥 제한 시간 문제를 정확히 적어 두었다.

## Context that was missing

- 시험의 대역 함수 열 개가 새 키워드를 받지 않아 함께 고쳐야 했다.
