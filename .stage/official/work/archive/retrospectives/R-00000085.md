# R-00000085 리뷰 지적 처리 단계를 스킬 문서에 적는다

## Work

DE-00000032 의 마지막 조각. `stage-retrospective` 가 회고 확인 항목으로 "리뷰 판정이 있었으면
지적마다 받는다/안 받는다/미룬다 + 근거 한 줄" 을 요구하고, `stage-drive` 가 BLOCK 은 리뷰어의
목소리를 사람 앞에 세울 뿐 결정하지 않는다는 것과 처리 단계의 존재를 말한다. 같은 자리에서
낡아 틀려 있던 `NO-PROGRESS` 설명도 지금 동작에 맞게 바로잡았다.

## Decision points

- 확인 항목을 어디에 두나 — Required confirmations 의 한 항목으로 넣었다. 새 절이나 새
  스킬을 만들면 무거워져 안 쓰게 된다(DE-00000032 가 경고한 위험).
- 카드 목적 밖 변경 하나를 받았다 — `NO-PROGRESS` 문단이 W-00000073 이전의 동작을 사실처럼
  말하고 있었고, 처리 단계를 적으러 들어간 바로 그 자리였다. 틀린 문서를 알고도 두는 쪽이
  더 큰 위반이라 판단했고, 근거를 카드 Progress 에 남겼다 — 조용한 대체가 아니라 기록된
  확장이다.

## Principles applied

- **Honesty** — 안 받는 지적에도 기록을 남기게 하는 것이 이 카드의 본질이고, 낡은 문단을
  바로잡은 것도 같은 원칙이다.
- **KISS / AHA** — 항목 하나, 물음 둘. 훅 강제도 새 스킬도 없다.
- **SSOT** — 처리 기록의 자리는 카드 `## Verification` 하나로 못 박았고, 두 스킬이 같은
  자리를 가리킨다.
