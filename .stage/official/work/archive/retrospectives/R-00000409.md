# R-00000409 색인은 실렸지만 처음부터 상한에 닿았다

## Decision points

- 매번 같은 규칙 문장은 건드리지 않았다(이 카드의 제외 항목). 그래서 이 저장소는 첫 실행부터 상한에 닿았다: 9,928자이고 결정
  제목 82건 가운데 가장 오래된 3건이 빠진다.
- 색인의 효과를 잴 자리는 자기 보고뿐이다. 작업 브리핑이 "색인에 실려서 연 기록의 번호"를 묻고 지휘 세션이 카드의
  `## Sessions` 줄에 옮긴다. 훅이 재는 것은 없다.
- 규칙 후보 목록의 자리와 형식(`.stage/state/rule-candidates.md`)을 작업 세션이 정했다. DE-00000100 에는 없던 것이다. 파일은
  아직 만들지 않았다.
- 공식 결정 색인 67줄과 작업 보관 색인 330줄에 제목을 채웠다. 클라우드에는 훅이 없어 승격 의도 없이 고쳤다.
- 제목이 없거나 낡으면 audit 가 오류(DECISION005)를 낸다. 다른 프로젝트는 올린 뒤 색인 갱신 명령을 한 번 돌려야 한다.
- 위는 작업 세션이 정했고 지휘 세션이 사용자의 위임으로 받았다. O-00000062 에 적는다.

## Context that was missing

- DE-00000100 의 "닿는 자리" 표에 없던 색인 작성자(`manage_roadmap.py`)가 있었다. 낱말 찾기로 만든 표였다.
- 범위에 12개 경로를 적었지만 실제로는 53개 경로가 바뀌었다. 색인의 칸 하나가 템플릿, 이관, audit, 시험으로 퍼졌다.
