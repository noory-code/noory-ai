# R-00000338 등록 게이트도 같은 명령에서 정한 변수 경로를 풀어서 판정한다

## Work

열린 카드가 없을 때 등록 게이트가 `S=/tmp/x && cat > "$S/a.md"` 를 프로젝트 쓰기로 보고 막던 것을
고쳤다. 범위 알림이 이미 쓰던 변수 풀기를 게이트 앞에서도 쓴다.

## Decision points

- **범위 알림과 같은 함수를 썼다.** 새로 만들지 않고 W-00000332, W-00000335 가 다듬은
  `expand_leading_shell_variable` 을 그대로 불렀다. 두 자리가 같은 규칙으로 판정한다.
- **풀 수 없는 변수는 막는 쪽에 두었다.** 게이트는 틀려도 막는 쪽으로 틀려야 한다.

## Principles applied

- Fail Fast — 깨지는 테스트를 먼저 보고 고쳤다.
- SSOT — 변수 풀기 규칙을 한 함수에 둔다.

## Context that helped

- W-00000332 가 남긴 문서 문장("these exclusions apply to the report only"). 게이트에는 적용되지
  않는다는 것을 바로 알 수 있었다.

## Context that was missing

- 열린 카드가 늘 있는 동안에는 이 문제가 드러나지 않는다. 카드를 다 닫은 날 처음 보였다.
