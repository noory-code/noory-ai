# R-00000090 close_work 가 돌리는 리뷰에도 카드 경로를 준다

## Work

close_work 의 리뷰 실행 둘(자율 카드의 독립 리뷰 — 무인 모드가 타는 길 — 과 단계별 리뷰)에
닫는 카드의 절대 경로를 `STAGE_WORK_ITEM_PATH` 로 넘기게 했다. 감독 드라이버가 이미 하던
것과 같은 의미다. 이로써 O-00000001 전수 지도의 세 실행 자리가 전부 닫혔고, 리뷰 계약
(DE-00000032)이 어느 경로에서든 같은 입력을 받는다.

## Decision points

- 큰 결정 없음 — W-00000085 가 만든 선례를 남은 두 자리에 그대로 옮기는 카드였다. 전수
  지도(O-00000001)가 자리를 미리 확정해 둔 덕이다.

## Principles applied

- **MECE** — 지도의 마지막 줄이 닫혔다. 발견 시점 전수 열거(operations/discovery.md)의 첫
  완주 사례다.
- **Honesty** — RED 를 저장소 밖 사본에서 직접 재현했고, 전체 검증을 실제 저장소에서 다시
  돌렸다(사본에서 돌아간 첫 실행을 그대로 믿지 않았다).
