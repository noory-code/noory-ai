# R-00000306 사용량 한도로 끝난 리뷰는 시도를 쓰지 않는다

## Work

W-00000306. `infrastructure_failure()` 가 서비스의 사용량 한도 메시지를 인프라 실패로 알아본다. 한도로 판정 파일 없이
끝난 리뷰와 한도로 실패한 실행이 시도를 쓰지 않는다. O-00000053 을 닫았다.
외부 결과: 사용량이 많은 날 리뷰가 한도에 걸려도 카드의 남은 기회가 줄지 않는다.
내부 결과: scripts 전체 716개, hooks 378개가 통과하고, 새 표지와 감독 실행 사례는 고치기 전 코드에서 실패한다.

## Decision points

- 서비스 고유의 문구만 맞춘다. 같은 표지가 실행자 실패 출력에도 쓰이므로, 넓은 "rate limit" 은 실패한 rate-limit
  시험을 끝없는 무료 재시도로 바꾼다.
- 판정 파일을 쓴 리뷰는 여전히 시도를 쓴다는 기존 규칙을 그대로 탔다.
- 관측의 다른 생각(`--resume` 이 리뷰어만 다시 돌리기, 종료 이유 구조화)은 하지 않고 관측에 적었다.

## Principles applied

Fail Fast: 일을 하지 못한 판을 실패한 판과 가른다.
만든 쪽 ≠ 보는 쪽: 실행 맥락이 없는 별도 Claude 세션이 판정했다. 같은 모델 계열이라 교차 venue 판정은 아니다.

## Context that helped

- O-00000053 이 실제 메시지("You've hit your session limit · resets 5:10pm")와 원인 함수를 적어 두었다.
