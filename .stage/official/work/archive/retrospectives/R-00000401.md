# R-00000401 지금까지의 닫기 리뷰는 닫을 때 돌린 검사를 직접 돌릴 수 없었다

## Decision points

- 설계 선택 셋을 사용자가 하나씩 보고 고르지 않았다. 사용자가 2026-11-23 에 묻지 말고 진행하라고 맡겼고, 지휘 세션이 작업 세션의
  추천안(1-가, 2-가와 2-다, 3-가)을 골랐다. 성공 기준의 문장도 그 사실에 맞게 고쳤다.
- 사용자의 시간이 드는 3-나(카드 다섯 장을 보지 않고 판정)는 고르지 않고 사용자가 나중에 정할 일로 남겼다.
- M-00000006 완료 기준의 "카드의 검사를 직접 실행"을 "실행이 필요한 기준을 직접 실행해서 판정"으로 읽기로 했다. 마일스톤 문서는
  고치지 않았다.

## Context that was missing

- 대역 리뷰어는 `python3 -m unittest` 만 실행할 수 있어서, 닫을 때 `audit_stage.py` 를 돌린 34장의 리뷰어는 그 검사를 직접
  돌리지 못했다. 이 카드를 계획할 때는 알려지지 않았고 조사에서 나왔다. 이 카드 자신의 닫기 리뷰도 같은 한계 안에 있다.
- 리뷰어가 무엇을 실행했는지는 커밋되지 않는 판정 파일의 `reason` 에만 있다.
