# R-00000340 닫기 도구가 승격을 나중에 쓰는 순서를 게이트에 맞게 안내한다

## Work

닫기 도구와 스킬에 승격을 나중에 쓰는 순서를 적었다. 동작은 바꾸지 않았다.

## Decision points

- **동작이 아니라 안내를 고쳤다.** 게이트가 `deferred` 를 받게 하는 길도 있었다. 하지만 그것은
  "무엇이 승격을 허락하는가"라는 게이트 규칙을 바꾸는 일이다. 오늘 두 번 실제로 통한 순서가
  있으므로 그것을 적었다.

## Principles applied

- Honesty — 안내가 실제 동작과 맞게 했다. 잠깐 감사 오류가 나는 상태가 있다는 것도 숨기지 않았다.

## Context that helped

- 같은 날 두 번(DE-00000082, DE-00000073) 같은 순서로 올린 경험.

## Context that was missing

- 세 도구(닫기 도구, 게이트, 감사)가 승격 값을 각자 다르게 본다는 것이 어디에도 한 번에 적혀 있지
  않았다.

## Next changes

- 게이트가 `deferred` 와 `promotes` 가 적힌 카드를 받게 할지는 따로 정할 일이다. 정하려면 사용자
  결정이 필요하다.
