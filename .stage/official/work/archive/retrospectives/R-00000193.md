# R-00000193 코덱스가 판정할 때 판정 파일을 쓸 수 있게 한다

## Work

코덱스 판정이 판정 파일을 쓴다. 전에는 읽기 전용으로 돌아 아무 카드도 판정하지 못했고, 그래서
설계·문서 카드를 드라이버로 못 돌렸다.

같이 고친 것 — **설정의 지시문에 백틱이 있으면 셸이 그 안 단어를 지운다.** 오늘 넣은 승격 값
다섯 단어가 실행자에게 빈칸으로 가고 있었다. 배포하는 설정 틀의 검사도 파일 전체를 본다.

## Decision points

- **판정하는 쪽에 쓰기를 줄 것인가.** 준다. 판정 파일을 못 쓰면 판정 자체가 성립하지 않는다.
  다만 열리는 범위가 작업 공간 전체라 그대로 적었다.
- **백틱을 어떻게 막을 것인가.** 검사로 막는다. 지시문은 사람이 쓰는 글이라 다시 들어올 수
  있고, 들어오면 조용히 단어만 사라진다.

## Principles applied

- **Fail Fast** — 조용히 단어가 사라지는 것을 검사가 시끄럽게 만든다.
- **Honesty** — 열리는 쓰기 범위가 필요한 것보다 넓다는 것을 숨기지 않고 적었다.

## Context that helped

- **병렬을 처음 써 봐서 드러났다.** 하루 종일 카드가 코덱스 몫이라 판정을 늘 클로드가 맡았고,
  클로드 몫 카드를 처음 돌린 그 자리에서 바로 터졌다. **한 방향으로만 돌리면 반대 방향이
  깨진 것을 모른다.**
- **판정이 백틱을 찾아냈다.** 내가 만든 자리가 아니라 오늘 다른 카드가 넣은 자리였고, 그
  카드의 실행자 자신도 깨진 지시로 돌았다.

## Context that was missing

- **연결이 다섯 번 끊겼다.** 코드는 2바퀴에 다 됐는데 마지막 확인까지 다섯 바퀴가 더 들었다.
  전부 클로드 실행자가 API 에 못 닿아서였다. 재시도 말고 할 수 있는 것이 없었다.
- **양쪽 방향을 다 돌려 보지 않았다.** 이 구멍이 몇 달 열려 있었는지 모른다.

## Next changes

- **새 계약을 만들면 양쪽 방향으로 한 번씩 돌려 본다.** 코덱스가 실행하고 클로드가 판정하는
  쪽만 돌리면 반대가 깨진 것을 못 본다.
- **설정의 명령 문자열이 셸을 거친다는 것을 어디에도 안 적어 뒀다.** 검사는 넣었지만 왜
  그런지는 여전히 문서에 없다.
