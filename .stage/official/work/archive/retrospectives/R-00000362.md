# R-00000362 Stage 0.67.0 과 evonest 1.2.1 을 낸다

## Work

2026-11-20 에 머지한 Windows 고침들을 릴리스했다. Stage 는 0.66.6 에서 0.67.0 으로, evonest 는 1.2.0 에서 1.2.1 로
올렸다. PR #73 으로 머지했고 맥북의 `claude plugin list` 가 Stage 를 0.67.0 으로 읽는다.

## Decision points

- Stage 를 올리는 폭: minor 로 골랐다. 새 스크립트 `run_review.py` 와 설정 문서의 새 명령 형태가 들어간다.
- evonest 를 올리는 폭: patch 로 골랐다. 고침만 있다.
- 카드 한 장에 두 플러그인을 담고 커밋은 플러그인마다 나눴다. 두 릴리스가 같은 날의 같은 고침 묶음을 낸다.
- evonest 변경 기록: 맨 위에 있던 `## Unreleased` 절을 소개 문장 아래로 옮기고 `## [1.2.1]` 로 제목을 붙였다.
  앞선 릴리스들과 같은 자리다.

## Principles applied

- SSOT: evonest 버전은 `pyproject.toml` 에서 고치고 매니페스트와 `uv.lock` 을 같은 커밋에서 맞췄다.
- Honesty: 닿을 수 없는 성공 기준을 통과로 적지 않고 고친 까닭을 카드에 남겼다.

## Context that helped

- W-00000355(Stage 0.66.6 릴리스 카드)가 카드의 모양과 확인할 것을 보여 줬다.
- `evonest/CLAUDE.md` 의 `Version Management` 가 고칠 파일 다섯 개를 정해 줬다.

## Context that was missing

- 이 맥북에 evonest 플러그인이 설치되어 있지 않다는 것을 성공 기준을 적은 뒤에 알았다.
- evonest 의 `.venv/bin` 실행 파일은 예전 폴더 경로를 가리킨다. `uv run mypy` 가 실행되지 않아
  `uv run python -m mypy` 로 실행했다.

## Next changes

- Windows 세션이 Stage 0.67.0 을 받아 훅과 닫기 리뷰가 실행되는지 확인한다.
- 새 리뷰 명령으로 맥북에서 실제 카드를 닫아 본다. 리뷰가 필요한 다음 카드에서 처음 실행된다.

## Rule candidate

- 성공 기준에 "이 기기에서 보인다" 를 적기 전에 그 기기에서 한 번 실행해 본다. `stage-work` 의 "전제를 실행해 볼 것"
  과 같은 내용이라 새 규칙으로 올리지 않는다.
