# R-00000290 커밋 본문의 실행 보고를 작업 로그로 옮기는 도구를 둔다

## Work

W-00000290. `stage/scripts/import_executor_report.py` 가 커밋 하나의 본문에서 실행 보고를 찾아, 줄바꿈으로
나뉜 칸을 한 줄로 잇고, 계약 순서로 다시 쓴 뒤, 그 커밋이 바꾼 경로와 대조해 검증하고 작업 로그에
덧붙인다. 검증에 실패하면 로그를 만들지도 바꾸지도 않는다.
외부 결과: 클라우드 세션의 결과를 로컬에서 닫을 때 실행 보고를 손으로 옮기지 않는다.
내부 결과: 인수 시험 3개(거절 네 경우 포함), scripts 전체 687개, hooks 378개가 통과한다. 오늘 실제 클라우드
커밋 넷(`3ce38592`, `40063650`, `558ac6e7`, `2fdd7a58`)의 보고를 옮겼고, `3ce38592` 는 W-00000287 을 닫을
때 손으로 이은 결과와 칸 길이가 같다. 이 카드의 실행 보고도 이 도구로 옮겨 닫았다.

## Decision points

- 문장 대신 도구: 계약 문장을 엄격하게 바꾸는 것만으로는 다시 줄을 바꿀 수 있다. 도구는 줄바꿈된 본문과
  안 된 본문을 모두 받는다.
- 경로 대조: 클라우드 세션의 보고는 정확히 커밋 하나를 설명하므로 그 커밋이 바꾼 경로와 맞춘다.
- 재사용: `close_work` 의 보고 표지 찾기와 검증기를 그대로 쓴다. 두 번째 사본을 만들지 않는다.
- 보고의 끝: 칸도 이어지는 줄도 아닌 첫 줄, 또는 `Co-Authored-By:` 같은 꼬리말에서 멈춘다.

## Principles applied

User intent: 사용자가 승인한 다음 일(2번)이다.
SSOT: 보고 계약의 검증은 `close_work.executor_report_error()` 한 곳이 소유한다.
만든 쪽 ≠ 보는 쪽: 실행 맥락이 없는 별도 Claude 세션이 이 프로젝트의 codex 리뷰 프롬프트로 판정했다. 같은
모델 계열이라 교차 venue 판정은 아니다.

## Context that helped

- W-00000287 을 닫을 때 손으로 칸을 이은 결과가 남아 있어, 도구의 결과를 그것과 바로 비교할 수 있었다.

## Context that was missing

  실제 커밋으로 돌려 보고 빈 줄을 칸의 끝으로 다루었다.
