# R-00000047 무인 드라이버 루프 회고

## Work

무인 자율 실행 드라이버 루프(`drive.py --unattended`)를 구현했다. 승인된 서브트리를 격리 브랜치(`stage/driver/<target>-<ts>`)에서 완주시킨다: 준비된 말단 자식 선택 → executor 실행 → 브랜치 커밋 → 기계 생성 회고 → `close_work`(acceptance + 독립 리뷰 재실행)로 close → 자식 전부 terminal 시 부모까지 자동 close. 실패·BLOCK·무진전·시도상한 시 `escalate_work`(blocked + 결정)로 에스컬레이션(가짜 완료 없음), 전역 iteration·벽시계 초과 시 비영 종료. 무거운 부분은 이미 리뷰된 `close_work`/`escalate_work`를 subprocess로 재사용했다. 실행은 claude(DE-25 venue 예외 — Codex 위임이 권한 분류기에 차단됨), 독립 검토는 사람이 수행.

## Decision points

- DE-00000024: 무인 루프 안전 경계(격리 브랜치·한계 필수·기계 회고 auto-close), 완전 무인(A) 확정.
- DE-00000025: Codex 위임 차단으로 claude가 실행, 독립 판정은 사람 검토.

## Principles applied

- Safe completion > Speed — 격리 브랜치로 blast radius를 가두고 사람이 머지에서 최종 판정.
- Fail Fast — 한계 필수, executor/reviewer/한계 부재·malformed 시 fail-closed.
- Honesty / No partial completion — 실패·상한 = `blocked`, 가짜 완료 금지.
- DRY — `close_work`/`escalate_work`를 재구현 없이 재사용.
- TDD — 신규 테스트 5종(브랜치 격리·base 무수정·pass 시 close·fail 시 escalate·한계 정지) + 전체 스위트 통과.

## Context that helped

- DE-00000024/25 계약이 안전 경계와 실행/검토 방식을 고정.
- 앞선 네 primitive와 `close_work`/`escalate_work` 스크립트가 재사용 기반.

## Context that was missing

- 빌드 중 버그 1건: `blocked` 항목이 재선택돼 무한 재시도되던 것 → `status == active`만 선택하도록 수정(테스트 커버).
- 실물 executor 명령(codex headless)은 미검증이라 settings 미반영, 실제 무인 실행도 미시연(준비된 실제 작업 없음).
