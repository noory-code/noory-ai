# R-00000284 리뷰가 사례로 거부하면 그 종류 전체를 막도록 실행·리뷰 계약을 고친다

## Work

W-00000284. 다시나 R-00000031의 규칙 후보(2회차)를 Stage 플러그인으로 올렸다. `stage-drive` 스킬의 FAIL 처리 설명과 설정 템플릿의 실행·리뷰 명령 안내에 "리뷰어는 종류를 이름 짓고, 실행자는 종류 전체를 고치고 시험한다"를 더했다.
외부 결과: 새로 Stage를 설치하는 프로젝트는 이 문장을 담은 안내를 받는다.
내부 결과: hooks 시험 통과, 감사 errors=0. scripts 시험의 실패 6건은 이 카드 전부터 있던 것이다.

## Decision points

- 규칙을 `operations/` 문서에만 두지 않았다. Codex 실행자는 카드와 실행 명령 문자열만 읽어서 문서만으로는 행동이 바뀌지 않는다. 그래서 실행 계약(스킬)과 명령 안내(템플릿)에 넣었다.
- 이미 있는 프로젝트(noory-ai, 다시나)의 명령 문자열은 고치지 않았다. 프로젝트 설정은 사람이 정한다.

## Principles applied

SSOT: 계약 문장은 스킬 한 곳에 두고, 템플릿은 명령에 넣을 짧은 안내만 둔다.
Honesty: scripts 시험 실패 6건이 이 카드 전부터 있었음을 git stash로 확인하고 적었다.
