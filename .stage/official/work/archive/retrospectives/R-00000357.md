# R-00000357 evonest 의 mypy 검사가 Windows 에서도 통과하게 고치기

## Work

`tools/analyze.py` 와 `tools/evolve.py` 에서 `# type: ignore[attr-defined]` 주석 2개를 지웠다.
Windows 에서 `uv run mypy src/evonest/` 가 오류 2개에서 통과로 바뀌었다. Linux 와 macOS 기준 검사는
고치기 전과 후 모두 통과했다.

## Decision points

- 주석을 지울지 `unused-ignore` 를 함께 무시할지: 지웠다. 호출이 `sys.platform == "win32"` 분기
  안에 있어서 mypy 가 다른 플랫폼에서는 그 줄을 검사하지 않는다. 주석을 남기고 오류 코드를 더하면
  필요 없는 주석이 하나 더 늘어난다.
- 다른 플랫폼을 어떻게 확인할지: 기기가 Windows 하나뿐이라 `mypy --platform linux` 와
  `--platform darwin` 으로 확인했다. 실제 기기에서 실행한 것과 같지 않다는 점을 카드에 적었다.
- 브랜치: W-00000356 과 같은 브랜치에 올렸다. 두 카드가 같은 `## Unreleased` 절을 고쳐서, 브랜치를
  나누면 변경 기록이 충돌한다.

## Principles applied

- Honesty: 실제 Linux 와 macOS 기기에서 실행하지 않은 것과 Python 3.11 로 확인하지 않은 것을 적었다.
- Fail Fast: 고치기 전과 후를 같은 명령으로 세 플랫폼 기준에서 비교했다.

## Context that helped

- R-00000356 이 이 오류 2개의 위치와 "Windows 에서만 나온다"는 사실을 남겨 뒀다.

## Context that was missing

- evonest 에는 CI 워크플로가 없다. 타입 검사와 테스트가 어느 OS 에서도 자동으로 실행되지 않아서,
  이 오류가 Windows 에서 얼마나 오래 있었는지 알 수 없다.

## Next changes

- evonest 에 CI 를 더할지 정한다. 더한다면 Windows 를 포함한다.
