# R-00000262 Plainly의 한국어 지침을 고치고 출시해 보니

## Work

Plainly의 공통 한국어 지침에서 비유와 불분명한 주어를 없앴다. 네 가지 스타일 설정 경로를
테스트했고 `0.4.2`로 출시해 Claude와 Codex에 설치했다.

## Decision points

- 프로젝트가 정한 말투와 공통 한국어 문법을 나누고, 공통 문법만 플러그인 훅에 남겼다.
- 사용자가 출시를 승인한 뒤 작업 범위를 두 버전 파일과 설치 확인까지 넓혔다.
- Claude 답변 한 번에서 어색한 표현이 나왔지만, 한 표본만으로 지침을 다시 바꾸지 않았다.

## Principles applied

- `SSOT` — 공통 문법은 Plainly 훅이 맡고 프로젝트 스타일은 말투와 사용자가 고친 표현을 맡게 했다.
- `MECE` — 기본값, 환경 변수, 프로젝트 설정, 외부 파일이라는 네 가지 경로를 모두 테스트했다.
- `Fail Fast` — 설치 뒤 Claude를 실제로 실행해 지침을 따르지 않은 표현도 바로 확인했다.
- `Completion` — 원본 테스트, 출시, 두 설치본의 실제 훅 출력까지 확인했다.
- `Honesty` — 지침이 설치됐다는 사실과 Claude가 늘 자연스럽게 쓴다는 주장을 구별했다.

## Context that helped

원본 저장소와 설치 캐시가 따로 있다는 점, 그리고 네 가지 스타일 설정 경로가 이미 테스트 구조로
나뉘어 있던 점이 도움이 됐다.

## Context that was missing

Claude가 같은 지침을 여러 번 얼마나 잘 따르는지 재는 반복 검사가 없었다. 실제 답변 한 번에서는
“설정 경로 네 가지를 다 눌러 봤고”라는 표현이 나왔다.
