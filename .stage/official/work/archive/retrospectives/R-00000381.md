# R-00000381 Windows 에서 검사와 리뷰의 시간 제한이 실제로 끊게 한다

## Decision points

- **서브세션(session_018VXR6QNJ7Rrr2EULVp6Bqg)이 만들고 메인 세션이 닫았다(DE-00000094).** 서브세션은 Windows 에서
  돌릴 수 없어서, 메인 세션이 squash 한 뒤 PR #100 을 열고 그 PR 의 windows-latest 잡으로 확인했다. 서브세션은 PR 을
  열 수 없으므로, Windows 확인이 필요한 카드는 메인 세션이 PR 을 연 뒤에 닫아야 한다.
- **고칠 자리마다 따로 고치지 않고 `hooks/stage_process.py` 하나로 모았다.** close_work 와 drive_parallel 이 이미
  `hooks/` 를 가져다 쓴다.
- **시험이 리눅스에서도 뜻이 있게 짰다.** 리눅스에서는 고치기 전에도 시간 안에 돌아오므로, 손자 프로세스가 남긴 표식이
  없어야 한다는 것까지 본다. 고친 곳을 되돌리면 리눅스에서도 실패한다.

## Context that was missing

- 서브세션 브리핑에는 "Windows 확인은 메인 세션이 PR 로 한다"는 말이 없었다. 서브세션이 스스로 그렇게 판단해 보고했다.
