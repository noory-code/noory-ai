# R-00000045 자율 실행 드라이버 MVP 회고

## Work

자율 실행 드라이버의 supervised MVP(`drive.py`)를 구현해 다섯 번째 통제 장치를 완성했다. 드라이버는 대상 부모의 준비된 말단 자식(비-terminal·acceptance 보유·leaf)을 선택하고, 그 항목의 executor(신규 `executors` config) · acceptance · 반대-venue 독립 리뷰어 · 한계를 해석한다. dry-run이 기본이며 부작용이 전혀 없다. `--execute`는 executor → acceptance → 독립 판정을 정확히 1회 실행하고, `.runtime/driver/`(untracked)에 항목별 시도 수·무진전 지문을 기록한 뒤 권장 다음행동만 출력한다. 커밋·close·escalate·승격·항목 생성·부모 전진은 하지 않는다. 이로써 네 primitive(종료판정·독립판정·집계·에스컬레이션/한계)가 하나의 루프로 통합됐다. 실제 프로젝트 dry-run 스모크 테스트 통과(무부작용 확인). 실행은 Codex, 리뷰는 Claude + 독립 `claude -p` 패스(둘 다 승인).

## Decision points

- DE-00000023: 드라이버 아키텍처(executor config·루프·런타임 상태·무진전·한계)와 안전 불변식, supervised/dry-run 우선(범위 A) 확정. DE-00000013(드라이버/게이트 경계)의 구현.

## Principles applied

- SoC / DIP — executor를 config로 추상화(reviewers와 대칭).
- Honesty / No partial completion — `blocked` 불변식; 커밋/close/escalate를 자동으로 하지 않고 권고만.
- Fail Fast — executor/reviewer/한계 부재·malformed 시 fail-closed.
- SSOT / AHA — 런타임 상태는 `.runtime/`로 분리.
- Safe completion > Speed — 전면 무인 대신 supervised MVP를 먼저.
