# R-00000344 플레인리를 켜면 스타일이 바로 적용되게 하고 비교 실험을 기본 평가 명령으로 옮긴다

## Work

스크래치에만 있던 플레인리 비교 실험을 `claude plugin eval` 의 질문과 정규식 채점 기준으로
옮겼다. 평가가 출력 스타일을 고르지 않아서, 스타일 파일에 `force-for-plugin: true` 를 넣어
플러그인을 켜면 스타일이 바로 적용되게 했다. 이 계약 변경은 사용자가 정했다.

## Decision points

- **저장소에 옮기기 전에 시험 실행부터 했다.** 평가 설정에 출력 스타일 항목이 없다는 것을 보고,
  옮기기 전에 스크래치 복사본으로 한 번 돌렸다. 그대로 옮겼다면 두 쪽이 같은 점수를 내는 평가를
  만들 뻔했다.
- **계약 변경은 사용자에게 넘겼다.** `force-for-plugin` 은 "고를 수 있는 스타일"이라는 계약을
  바꾸므로, 두 방법의 비용과 위험을 보이고 정해 달라고 했다.
- **채점은 정규식만 썼다.** 비용이 들지 않고, 예전 스크립트가 세던 모양을 그대로 옮길 수 있다.
  뜻 보존은 재지 못한다는 것을 README 와 카드에 적었다.
- **실제 대화 기록을 세는 스크립트는 옮기지 않았다.** 사용자의 대화 기록을 읽기 때문이다.

## Principles applied

- Fail Fast — 옮기기 전에 시험 실행으로 전제를 확인했다.
- Honesty — 차이가 나지 않은 두 질문과 확인하지 못한 모델 이름을 그대로 적었다.
- SSOT — 비교하는 코드를 따로 두지 않고 Claude Code 의 평가 명령에 맡겼다.

## Context that helped

- Claude Code 실행 파일 안의 평가 작성 안내. 채점 종류와 frontmatter 키를 거기서 확인했다.

## Context that was missing

- 평가가 플러그인의 출력 스타일을 켜는지 문서에서 찾을 수 없었다. 시험 실행으로만 알 수 있었다.
