# R-00000330 Agent 호출의 모델과 에포트를 카드 등급에 맞추는 훅을 넣는다

## Work

`stage/hooks/stage_agent_tier.py` 를 만들었다. PreToolUse 에서 Agent 호출에 빠진 model·effort 를 카드 등급으로 채우고, 등급보다 비싼 모델은 `[over-tier: 이유]` 없이는 막는다. PostToolUse 에서 하위 에이전트가 실제로 돈 모델·에포트를 `.stage/.runtime/model-usage/` 에 남긴다. `stage_guard.py` 는 `handle_event` 에서 넘기는 줄과 `current_leaves()` 만 더했다.

## Decision points

- 처음에는 실제 값을 기록하는 자리를 설계의 `SubagentStop` 대신 PostToolUse 로 바꿨다. Codex 도 읽는 `hooks.json` 을 고치지 않으려는 것이었다. 그런데 백그라운드 호출의 PostToolUse 는 띄우는 순간에 와서, 끝난 기록이 빠졌다. 리뷰어가 이를 찾았고 나는 보고에 적지 않았다. 결국 설계대로 `SubagentStop` 을 더했다. PostToolUse 는 요청 기록만 맡는다. Codex 0.167.0 실행 파일 문자열에 `SubagentStop` 이 있는 것을 확인했다.
- `SubagentStop` 순간에는 마지막 assistant 줄이 아직 쓰이지 않아 모델이 비었다. 실측으로 이것을 찾았고, 요청 직전에 쓰이는 `api-request` 줄에서 모델을 읽게 했다.
- 모호해서 막는 경우에는 over-tier 기록을 남기지 않도록 기록을 판단 뒤로 옮겼다.
- 훅 표에 막는 검사가 하나 늘어서 README 의 개수와 표, 그 개수를 세는 시험을 함께 고쳤다. 그 시험은 `stage_guard.py` 안의 거부만 세서 이 검사를 잡지 못한다. 그래서 주석에 그 사실을 적었다.

## Principles applied

SSOT(등급 읽기는 공용 모듈, 현재 카드 고르기는 `active_work_chains` 재사용), Fail Fast(채울 값이 모호하면 막고 이유를 알림), Honesty(설계와 다르게 한 점과 실측 근거를 보고에 적음), KISS(새 이벤트 없이 이미 걸린 훅으로 기록).

## Context that helped

- 오케스트레이터와 이 세션의 실측 덕분에 `updatedInput` 동작을 가정하지 않고 썼다. 마지막에 이 worktree 의 훅을 건 시험 프로젝트에서 세 경로(채움·거부·이유 있는 통과)를 실제로 돌려 확인했다.

## Context that was missing

- 설계를 바꿀 때 "그 대신 무엇을 잃는가" 를 세지 않았다. 포그라운드만 실측하고 백그라운드 경우를 빼먹었다. 대신 쓰는 경로는 바뀌기 전 경로가 다루던 경우(여기서는 포그라운드·백그라운드)를 모두 실측해야 한다.
