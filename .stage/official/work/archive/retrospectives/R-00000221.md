# R-00000221 감독 모드의 claude venue 실행을 세션 팀원에게 맡기기로 정한다

## Work

측정(W-00000220)이 좁혀 준 갈림 — 비대화형 실행자에 허용 목록을 줄 것인가, 세션 팀원에게
맡길 것인가 — 에서 사용자가 팀원 쪽을 골랐고, 두 가지를 직접 정했다: 계약 문구는 그대로
물려주고, 팀원은 중간에 사람에게 물을 수 있다. DE-00000062 가 결정을, `.stage/operations/
claude-venue.md` 가 절차를 소유한다. 무인 모드는 codex 전용으로 남는다.

## Decision points

- **허용 목록(A) 대신 팀원(B).** 원인이 비대화형 구조이므로 구조를 우회하기보다 세션의
  권한과 대화 능력을 그대로 쓴다. 무인 claude 수요는 실제로 생길 때 다시 본다(AHA).
- **판정자 경로는 범위 밖.** 판정용 `claude -p` 는 읽기·쓰기만으로 돌아 오늘도 문제없었다.
  적용 자리를 세다가 갈라낸 경계다.

## Principles applied

- **User intent** — 방식 선호와 두 세부(계약 상속, 중간 질문)를 사용자가 정했다.
- **Truthfulness** — 대칭 탐침 측정 위에서 골랐다. 측정 전이었다면 "워크트리 준비를
  고친다"는 엉뚱한 자리에 힘을 썼을 것이다.
- **AHA** — 무인까지 덮는 일반해를 미리 만들지 않았다.

## Context that helped

- 같은 날의 측정이 선택지를 둘로 좁혀 놓아 결정이 짧았다. 측정 없는 설계 논의였다면
  가설끼리 싸웠을 것이다.

## Context that was missing

- 실측이 없다 — 설계가 로그 계약과 실제로 맞는지는 첫 팀원 실행이 확인한다. Follow-up 에
  남겼다.

## Next changes

  (stage-drive 문서·기본 설정)을 별도 카드로 제안한다.
