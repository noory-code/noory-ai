# DE-00000081 브랜치를 넘어 기록 번호를 고르는 고치기는 Claude Code 클라우드 세션에서 실행한다

## Question

W-00000291 은 `kind: fix` 라 정책상 codex 몫이다. 사용자는 이 클라우드 세션에서 "여기서는 코덱스가
하는 일을 니가 해야 한다"고 지시했고, 이 카드를 다음 일로 승인했다. **이 카드를 어느 자리에서
실행하는가.**

## Options

1. **로컬 codex 드라이버에 넘긴다** — 사용자 지시와 어긋난다.
2. **이 클라우드 세션이 실행한다** — DE-00000080 과 같은 모양의 예외를 한 장 더 세운다. (선택)

## Principles applied

- **User intent** — 사용자가 이 세션이 codex 몫까지 하라고 지시했다.
- **만든 쪽 ≠ 보는 쪽** — 카드에 `review: pending` 을 건다. 닫기 리뷰는 실행 맥락이 없는 별도
  세션이 한다.
- **Fail Fast** — 오늘 병렬 브랜치에서 W-00000286·DE-00000076 이 실제로 겹쳤다.

## Chosen direction

**2번.** W-00000291 은 Claude Code 클라우드 세션이 `claude/w268-cloud` 브랜치에서 실행한다. 이 결정은
W-00000291 한 장만 허가한다. 실행 계약은 DE-00000075 의 세 변경을 그대로 쓴다.

## Where this applies

| 자리 | 무엇을 하는가 |
|---|---|
| W-00000291 카드 `venue` · `decision_refs` | `claude` 와 이 결정을 가리킨다 |
| `.stage/work/active.md` W-00000291 행 | Venue 칸을 `claude` 로 둔다 |

`settings.json` 의 `venue_routing` 은 바뀌지 않는다. 카드가 보관될 때 이 결정도 함께 소진된다.

## Reason

등록 도구는 지금 체크아웃의 카드만 세어 번호를 고른다. 병렬 세션이 많을수록 같은 번호를 쓰는 일이
늘고, 오늘 실제로 두 번 겹쳤다.

## 이 규칙이 틀렸다는 것을 무엇으로 알게 되나

닫기 리뷰가 클라우드에서 놓친 것을 잡으면 이 경로의 비용이 이득보다 크다.

## Follow-up

- 카드마다 예외를 세우는 일이 오늘만 일곱 번째다(DE-00000075~081).
