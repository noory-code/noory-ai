# DE-00000075 보관 카드 고치기는 Claude Code 클라우드 세션에서 실행한다

## Question

W-00000268 은 `kind: fix` 라 정책상 codex 몫이다. 사용자는 이 카드로 클라우드 실행을
시험하기로 했다. 그런데 이 저장소의 codex 드라이버 명령은 이 컴퓨터에만 있는 경로
(`~/.claude/plugins/cache/openai-codex/...`)를 부르므로 클라우드에서 돌지 않는다.
**이 카드를 어느 자리에서 실행하는가.**

## Options

1. **정책대로 로컬 codex 드라이버에 넘긴다** — 클라우드 시험이 되지 않는다.
2. **Claude Code 클라우드 세션이 실행하고, 리뷰와 닫기는 로컬에서 한다** — 예외 결정을
   세운다. (선택)
3. **클라우드에 codex 를 설치하고 드라이버 명령을 클라우드용으로 바꾼다** — 설정 스크립트,
   Codex 로그인, 명령 여섯 개를 고쳐야 한다. 한 장을 시험하는 비용으로는 크다.

## Principles applied

- **User intent** — 사용자가 W-00000268 로 클라우드 실행을 시험하자고 했다.
- **Fail Fast** — 카드 한 장으로 먼저 재 본다. 통하는지 모르는 길에 드라이버 설정을 바꾸지
  않는다.
- **만든 쪽 ≠ 보는 쪽** — 클라우드의 Claude 가 고치고, 판정은 로컬의 codex 가 한다.
- **Honesty** — 클라우드 세션에는 Stage 플러그인이 설치되지 않는다(Claude Code 문서
  `settings.md` "Settings in cloud sessions": 저장소 `enabledPlugins` 는 클라우드 세션에
  설치되지 않는다). 범위 검사 훅이 없으므로 그 검사를 로컬에서 다시 한다.

## Chosen direction

**2번.** W-00000268 은 Claude Code 클라우드 세션(claude.ai/code 또는 `claude --cloud`)이
`claude/w268-cloud` 브랜치에서 실행한다. 이 결정은 W-00000268 한 장만 허가한다.

여기서 `claude` venue 는 `.stage/operations/claude-venue.md` 의 팀원 절차가 아니라 클라우드
세션을 뜻한다. 클라우드 세션은 Stage 훅과 `.stage/.runtime/` 없이 돈다. 그래서 실행 계약 중
아래 셋을 이 카드에서만 바꾼다.

- 커밋 금지 대신 **세션 브랜치에만 커밋하고 push 한다.** 로컬로 가져오는 `--teleport` 가
  push 된 브랜치를 요구한다. `main` 에는 push 하지 않는다.
- 공유 작업 로그(`.stage/.runtime/driver/logs/`)가 클라우드에 없으므로 `### Executor report`
  는 커밋 메시지 본문에 쓴다. 로컬에서 그 보고를 작업 로그로 옮긴다.
- 범위 넘음은 훅이 아니라 로컬에서 `git diff --name-only` 를 카드 `scope` 와 대조해 잡는다.

## Where this applies

| 자리 | 무엇을 하는가 |
|---|---|
| W-00000268 카드 `venue` · `decision_refs` | `claude` 와 이 결정을 가리킨다. 감사가 서로를 가리키는지 검사한다 |
| `.stage/work/active.md` W-00000268 행 | Venue 칸을 `claude` 로 둔다 |
| 로컬 마무리 | 가져온 뒤 범위 대조, 인수 명령과 scripts 전체 시험, codex 판정, 회고, 닫기를 로컬에서 한다 |

코드·설정·문서·실패 경로·게이트·감사 규칙 여섯 종류로 세었다. `settings.json` 의
`venue_routing` 과 드라이버 명령은 바뀌지 않는다. 이 결정은 정책을 고치지 않고 카드 한 장을
통과시킨다. 카드가 보관될 때 이 결정도 함께 소진된다.

## Reason

클라우드 실행이 이 프로젝트에 쓸모 있는지는 실제로 한 장을 돌려 봐야 안다. 드라이버 명령을
클라우드용으로 바꾸는 것은 그 답을 본 뒤에 정할 일이다.

## 이 규칙이 틀렸다는 것을 무엇으로 알게 되나

클라우드 세션이 카드만 읽고 실행하지 못하거나, 로컬에서 다시 하는 검사(범위 대조·전체 시험·
codex 판정)가 클라우드 결과를 자주 반려하면 이 경로는 비용만 늘린다. 그때는 클라우드 실행을
접고 1번으로 돌아간다.

- 시험 결과(카드만으로 실행됐는지, 로컬 검사에서 무엇이 걸렸는지)를 W-00000268 회고에 적는다.
