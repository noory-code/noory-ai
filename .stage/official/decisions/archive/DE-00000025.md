# DE-00000025 W-48 실행 주체 venue 예외 (claude)

## Question

W-00000048(kind development, 정책상 venue codex)을 누가 실행하는가? Codex 위임(codex:rescue 에이전트 스폰)이 Claude Code auto-mode 권한 분류기에 차단되었다.

## Options

- A. codex — 정책 기본이나, 위임이 분류기에 차단되어 불가.
- B. claude — 예외. claude가 직접 실행하고, 독립 판정은 사람이 수행.

## Principles applied

- User intent — 사용자가 B(직접 구현)를 선택.
- Honesty — 차단 사실과 그 결과(독립 판정 방식 변경)를 명시.
- Fail Fast — 막힌 위임 경로에 매달리지 않는다.
- DE-00000016(실행자 ≠ 검토자) — 실행이 claude이므로 독립 판정은 codex 또는 사람이어야 한다.

## Chosen direction

B. claude가 W-00000048을 실행한다. venue를 claude로 변경한다.

- Codex 위임 브리지(codex:rescue)가 무인-루프 구현 작업 내용으로 인해 auto-mode 분류기에 차단되었다.
- 실행자가 claude이므로, 이 항목의 독립 판정(DE-16/20)은 codex-companion이 아니라 **사람(사용자)의 diff 검토**로 수행한다(codex headless 미검증 + 위임 차단 상황). 빌드 후 커밋 전에 사용자 검토를 받는다.

## Reason

무인 루프는 위험도가 높아 독립 판정이 특히 중요한데, 자동 codex 판정 경로가 막혔다. 진행을 위해 claude가 구현하되, 실행자와 다른 주체의 판정을 유지하기 위해 사람이 독립 검토를 맡는다. 형제/후속 항목은 codex 경로가 복구되면 기본으로 되돌린다.

## Follow-up

- codex headless 실행/리뷰 경로 검증(막힌 원인·복구).
- 무인 루프의 실물 executor 명령 검증·반영은 라이브 실행 시.
