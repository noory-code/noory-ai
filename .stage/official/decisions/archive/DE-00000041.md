# DE-00000041 Venue exception: 릴리스 카드가 Claude 세션에서 돈다

## Question

플러그인 릴리스는 `kind: chore` 라 정책상 codex 로 가는데, 릴리스는 명령 실행 + 커밋 + 푸시가
한 몸인 사람의 일이다(CLAUDE.md 의 Plugin Changes 절, W-00000124 가 정함). 실행자는 계약상
커밋하지 않으므로 codex 위임이 성립하지 않는다. 감독 중인 Claude 세션이 직접 수행해도 되는가.

## Options

1. 예외를 허용한다 — 릴리스는 사람(감독 세션)의 일이라는 규칙 자체가 근거다.
2. codex 로 위임한다 — 실행자가 커밋을 못 하므로 릴리스가 두 동강 난다.

## Principles applied

- **Honesty** — 규칙(사람이 릴리스한다)과 정책(chore→codex)이 부딪히면 예외를 기록으로 남기고
  간다. 조용히 어기지 않는다.
- **SSOT** — 릴리스 절차의 소유는 CLAUDE.md 다. 이 결정은 그 절차를 따르기 위한 venue 예외일
  뿐이다.

## Chosen direction

**1.** 이 카드(W-00000137) 한 건에 한해 Claude 세션이 수행한다. 릴리스 카드가 반복되면 venue
정책에 release 류를 사람 몫으로 새기는 것을 그때 결정한다.

## Where this applies

이 카드 하나. 정책 파일은 안 바꾼다.

## Reason

DE-00000025·26 과 같은 모양의 소진성 허가다 — 카드가 닫히면 효력이 끝난다.
