# DE-00000031 스킬이 자기 플러그인의 스크립트를 가리키는 방법

## Question

스킬 문서가 같은 플러그인 안의 스크립트를 실행하라고 안내할 때, 그 경로를 어떻게 적는가?

## Options

**A. `${CLAUDE_PLUGIN_ROOT}` 변수** — 현재 일부 스킬이 쓰는 관행.

셸에 존재하지 않는다. 이 저장소에서 직접 확인했다: 에이전트가 명령을 돌리는 셸에서
`${CLAUDE_PLUGIN_ROOT}` 도 `${CLAUDE_PROJECT_DIR}` 도 빈 문자열이다. 이 변수는 훅 명령에
주입되는 것이지 에이전트 셸에 있는 것이 아니다 (`CLAUDE.md` 의 `Hook commands ... must use
python3. ${CLAUDE_PLUGIN_ROOT} is available in hook commands`). 빈 값으로 풀리면 명령이
`/scripts/drive.py` 처럼 절대 경로 앞부분이 잘려 실패한다. Windows `cmd.exe` 는 이 문법 자체를
확장하지 않는다.

**B. 저장소 상대 경로 (`stage/scripts/...`)** — 다른 일부 스킬이 쓰는 관행.

Stage 소스를 직접 체크아웃한 저장소에서만 맞다. 마켓플레이스로 설치해 자기 프로젝트에서 쓰는
사람에게는 없는 경로다. Stage 를 쓰는 프로젝트 대부분이 여기 해당한다.

**C. 스킬 자신의 위치를 기준으로 찾게 한다.**

스킬이 불려 나올 때 호스트가 그 스킬의 디렉터리를 함께 알려준다. 이 저장소의 세션에서 확인한
형태는 다음과 같다:

```text
Base directory for this skill: <절대경로>/stage/skills/stage-work
```

플러그인 안의 스크립트는 그 디렉터리에서 상대 위치가 고정돼 있으므로(`../../scripts/`,
`./` 등), 실행하는 쪽이 그 위치를 기준으로 절대 경로를 만들 수 있다. 설치본이든 소스
체크아웃이든 같은 방법으로 맞고, 셸 문법에 의존하지 않아 플랫폼도 가리지 않는다.

## Principles applied

**Honesty** — A 는 동작하지 않는 것을 동작하는 것처럼 적어 온 관행이다. 확인 없이 이어받지
않는다.

**SSOT** — 경로의 근거는 스킬 파일 자신의 위치 하나다. 호스트마다 다른 변수를 나열하면 근거가
여러 개가 된다.

**Fail Fast** — B 와 A 는 둘 다 조용히 실패한다. 없는 경로를 부르거나 잘린 경로를 부를 뿐,
"경로를 모른다"고 말하지 않는다.

## Chosen direction

**C.** 스킬 문서는 스크립트를 **자기 디렉터리 기준의 상대 위치**로 지목하고, 실행하는 쪽이
호스트가 알려준 스킬 디렉터리로 절대 경로를 만들어 부른다.

적는 방식:

- 스크립트의 위치를 스킬 디렉터리 기준으로 한 번 명시한다 (예: 드라이버는 이 스킬 디렉터리의
  `../../scripts/drive.py`).
- 명령 예시는 그 절대 경로를 넣을 자리를 `<driver>` 같은 이름난 자리로 남긴다. 어느 한 호스트나
  한 저장소에서만 맞는 문자열을 예시에 박지 않는다.
- 저장소 안에서 개발할 때 쓰는 형태를 함께 보일 수 있으나, 그것이 기본형이 아님을 밝힌다.

`${CLAUDE_PLUGIN_ROOT}` 는 훅 명령(`hooks.json`)에서는 계속 쓴다. 거기서는 실제로 주입된다.
금지되는 것은 **스킬 본문의 셸 예시**에 쓰는 것이다.

## Reason

셸에 없는 변수를 쓰는 것과 이 저장소에서만 맞는 경로를 쓰는 것은 둘 다 설치해 쓰는 사용자에게
동작하지 않는다. 스킬 디렉터리는 호스트가 스킬을 불러낼 때 실제로 알려주는 값이므로, 지금
확인 가능한 것 중 유일하게 두 경우 모두에서 성립한다.

## Follow-up

- `stage-drive` 스킬에 적용한다 (W-00000070).
- 다른 스킬의 같은 표기를 점검하고 맞춘다 — `stage-archive` 본문이 `${CLAUDE_PLUGIN_ROOT}` 를
  쓰고 있고, `stage-work` 와 `stage-archive` 의 명령 예시가 저장소 상대 경로를 쓴다. 별도 카드.
- 호스트가 스킬 디렉터리를 알려주는 형태는 Claude Code 에서 확인했다. Codex 에서의 형태는
  확인하지 않았다 — 다르면 스킬 본문의 표현을 두 경우 모두 성립하게 다듬는다.
