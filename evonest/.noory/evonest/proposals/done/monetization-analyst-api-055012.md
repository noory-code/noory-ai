# 제안: API 사용량 기반 미터링 — 대규모 조직 과금 모델

**우선순위**: medium  
**작성 페르소나**: monetization-analyst  
**사이클**: 0  
**상태**: 검토 대기

## 설명

현재 Evonest는 사용자의 Claude API 할당량을 직접 소비합니다. 대규모 조직의 경우 수백 명의 개발자가 동시에 evolve 사이클을 실행할 때 API 비용 추적 및 할당이 어렵습니다. 제안: Evonest가 선택적으로 자체 API 프록시를 통해 실행되도록 하여 조직 단위 사용량 추적 및 과금을 가능하게 합니다. 무료/Pro 티어는 기존과 동일하게 사용자 개인 Claude API 키 사용, Enterprise 티어는 Evonest 관리 API 풀 사용 + 사용량 기반 과금(예: $0.05/1000 토큰 + 10% 마진). 이를 통해 (1) 조직 전체 사용량 대시보드 제공, (2) 부서별 비용 할당, (3) 예산 제한 설정 가능. 구현은 선택적(opt-in)이므로 오픈소스 사용자는 영향받지 않습니다.
