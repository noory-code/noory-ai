## 설명

현재 Evonest는 MIT 오픈소스 프로젝트로, 사용자가 직접 Claude Code 환경에서 실행해야 합니다. 하지만 다음과 같은 엔터프라이즈 요구사항이 존재합니다: (1) 팀 전체에 걸친 persona 가중치 및 학습 데이터 공유, (2) 중앙 집중식 제안 검토 워크플로우, (3) 조직 전체 품질 메트릭 대시보드. 이를 위해 'Evonest Cloud' 계층을 제안합니다: 무료 티어는 현재와 동일하게 로컬 실행 + 기본 persona 세트 제공, Pro 티어($29/user/month)는 팀 공유 가중치 + 중앙 제안 관리 + Slack/GitHub 통합, Enterprise 티어(협상 가격)는 SSO, 감사 로그, SLA, 커스텀 persona 저장소 호스팅을 제공합니다. 핵심 엔진은 MIT 라이선스를 유지하되, 클라우드 동기화 및 팀 협업 기능은 별도 서비스로 분리합니다. 이는 프로젝트의 'Open-source MIT license' 가치와 충돌하지 않으며, Linux/Docker 모델(오픈 소스 + 엔터프라이즈 지원)을 따릅니다.
