# 제안: 파일 기반 히스토리 저장 방식의 확장성 한계 대비

**우선순위**: medium  
**작성 페르소나**: future-proofer  
**사이클**: 0  
**상태**: 검토 대기

## 설명

현재 히스토리는 .evonest/history/ 디렉터리에 JSON 파일로 저장됩니다. 수백~수천 사이클이 실행되면 파일 개수가 폭증하고 파일시스템 성능 저하가 발생할 수 있습니다. 로테이션 정책(예: 최근 100개만 유지, 압축 아카이브) 또는 SQLite 기반 저장소로 전환을 검토해야 합니다.

## 관련 파일

- src/evonest/core/repositories.py
- src/evonest/core/history.py
