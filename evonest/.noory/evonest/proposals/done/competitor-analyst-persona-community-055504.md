## 설명

ROADMAP.md의 'Persona Community' 섹션은 현재 컨셉 단계. 하지만 이는 Evonest의 가장 강력한 네트워크 효과 전략임. GitHub Copilot은 Microsoft 생태계에 종속되고, Aider는 개별 사용자 커스터마이징에 의존. Evonest가 'noory-code/evonest-personas' 저장소를 실제로 런칭하면 커뮤니티 주도 페르소나 라이브러리가 진입 장벽이 됨. 제안: (1) v0.4.0 목표로 `evonest_import` 툴 구현 (GitHub에서 페르소나 JSON 직접 다운로드). (2) 초기 3-5개 도메인별 페르소나 팩 공개 (startup/, security/, data-science/). (3) 기여 가이드라인과 품질 기준 문서화. 현재 이 비전이 '장기 목표'로 묻혀있으면 경쟁사가 먼저 구현할 위험.
