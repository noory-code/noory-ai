# Questions

This directory owns the SSOT of open questions.

## Rules

- One question has one file.
- A question has the decision it needs, the work it blocks, and the answer owner.
- Once answered, promote it to `official/decisions/` or the relevant truth.
- When it cannot move, state directly under its heading that it was answered and where the answer
  lives, then start its `## Status` section with the machine state token `answered`. Archived
  records that cite the question make it unmovable. The session's open-question view omits only
  records marked with that token; other derived views may still show the record in this directory.
