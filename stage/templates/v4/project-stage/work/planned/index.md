# Planned Work Index

This document owns the current index of planned work cards.

Card bodies live in `work/planned/`. This document manages only order, status, and links. A card that
starts work moves to `work/current/` (`scripts/start_work.py`) and its row leaves this
index for `work/active.md`.

## Planned work

| ID | Title | Kind | Status | Priority | Parent | Item |
|---|---|---|---|---|---|---|

## Status values

- `captured`: captured but not yet organized.
- `triaged`: purpose and impact confirmed.
- `ready`: concrete enough to be an execution candidate.
- `selected`: selected as current or next work.
- `deferred`: on hold.
- `rejected`: decided not to do.
