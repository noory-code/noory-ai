# 백로그 항목

이 디렉터리는 개별 백로그 항목의 SSOT를 소유한다.

백로그 항목은 기획, 설계, 개발, QA, 운영 등 프로젝트가 수행하는 모든 종류의 작업을 다룬다.

## 규칙

- 백로그 항목 하나는 파일 하나를 가진다.
- 파일명은 `B-00000001-short-title.md` 형식을 따른다.
- `index.md`는 항목 내용을 중복하지 않으며, 링크와 상태만 담는다.
- 항목은 frontmatter의 `parent` 필드를 통해 계층을 이룬다. 큰 작업은 하나의 평평한 목록으로 키우는 대신 하위 항목으로 분할해 분류 가능하게 유지한다.
- 실행하기로 선택된 항목은 작업 항목으로 실현된다. `realized_by`를 `W-*` ID로 설정하고, 해당 작업 항목의 `source`는 이곳을 다시 가리킨다. `realized_by`가 없는 `selected` 항목은 감사 경고 대상이다.
- 하지 않기로 한 이유는 항목 파일에 기록하고, 필요하면 `past/decisions/`에도 기록한다.
