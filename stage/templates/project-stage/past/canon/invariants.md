# Invariants

This document owns the index and core summary of conditions that must always hold.

The detailed SSOT of each invariant lives in `invariants/`.

- `future` content is never treated as official truth.
- `present` content is never promoted without verification and a retrospective.
- Official truth has exactly one owning location.
- Stage core artifacts stay Markdown, plain-file, and relative-path friendly.
- The Stage core must be usable on Codex, Claude, Windows, Linux, and macOS.
