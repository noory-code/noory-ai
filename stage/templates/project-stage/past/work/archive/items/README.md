# Archived Work Items

This directory owns the records of work items removed from the current work flow.

## Rules

- Work items here have `status: archived`.
- Nothing under current judgment, progress, or review lives here.
- The archive is a home for work records; official product truth lives in `past/canon/`, `past/model/`, and `past/decisions/`.
- The item's retrospective file is archived together into `past/work/archive/retrospectives/`.
