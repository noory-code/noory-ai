## 0.1.0

### Added

- Claude Code plugin (`pencil-material`) with 4 skills:
  - `init` — one-stop onboarding: creates app `.lib.pen`, sets seed color, logo, and generates project `design` skill
  - `design-guide` — M3 Expressive base rules + component ID reference + prompt generation methodology + optional Pencil MCP direct execution
  - `change-seed-color` — recalculates M3 palette and syncs both Pencil variables and Flutter Dart files
  - `change-logo` — replaces Logo reusable component (AI / image / initials)
- `pencil/md3calc/hct_palette.py` — seed color → M3 palette JSON via HCT algorithm
- `pencil/md3calc/gen_dart.py` — palette JSON → Flutter Dart files (`semantic_color_palette.dart`, `theme_colors.dart`, `theme.dart`, `tokens.dart`)
- `pencil/material-design-guide.lib.pen` — 166 M3 components + Color Scheme variables + M3 Expressive Guide frame with Context node
- `pencil/guide/` — 31 component guides + 8 token system guides (Markdown)
- Project `design` skill template — generated by `init`, outputs Pencil AI prompts for screen design

### Reference implementation (`lib/src/`)

- `semantic_color_palette.dart` — 3-layer color architecture Layer 1 (seed: #E91E63)
- `theme_colors.dart` — Layer 2, 6 ColorScheme variants (light/dark/mc/hc)
- `theme.dart` — Layer 3, AppTheme with M3 type scale
- `tokens.dart` — AppSpacing / AppRadius / AppElevation / AppIconSize / AppOpacity
